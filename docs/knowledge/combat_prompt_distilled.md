## 可执行规则

1. **动作因果**：每个节拍表达准备/起势、攻击或防守、接触与受力、重心或姿态变化、可见结果；不要用“快速连击”“强大能量”替代可拍摄动作。
2. **动作预算**：短镜头优先一条主要动作链；不把拔刀、转身、命中、收势等多个独立高潮压在同一瞬间。时长不足时保留最高影响的因果链，并明确压缩。
3. **开局可读**：战斗请求且时长允许时，前段尽早给出可辨的威胁、攻防接触或明确起势；只有用户要求铺垫时才延后冲突。
4. **动作与机位匹配**：小幅拳掌肘等用近景放大信息，大幅腾空/旋转/倒地用中景或全景交代空间；每个节拍只保留一个主运镜。
5. **空间连续**：锁定双方屏幕方向、站位、距离、朝向和关键道具；多镜头用上一镜结束状态作为下一镜起点，不重演上一镜。
6. **角色动作签名**：用户提供或项目状态已有角色打法时沿用其节奏、重心和招式偏好；没有资料时不凭空发明角色背景。
7. **效果有来源**：能量、尘土、碎片、布料和声音必须由身体/武器接触或环境运动触发；效果不是脱离主体的装饰层。
8. **失败修复**：针对站桩、跳轴、肢体漂移、背景消失、武器凭空变化、动作过载等问题，只添加能修复该问题的最小约束，不整包复制负面词。
