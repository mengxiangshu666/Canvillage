Canvillage · 村长无限画布

英文全称：Infinite Canvas for Village Chiefs

定位：面向 AIGC 内容制作的独立无限画布产品。

核心能力：
1. XYFlow 无限画布、节点、连线、历史、恢复和素材库。
2. 图片、视频、音频、文本、视觉和 Agent 节点。
3. 文本、视觉、生图、视频、向量、音频和 Agent 直连模型配置。
4. Agent 可以读取画布、调用 Skill、创建或修改节点并执行工作流。
5. 本地项目、生成任务和素材统一保存到“项目资产”。

唯一工作区：
当前检出或解压的项目目录。

唯一运行端口：
8784

启动方式：
- 双击“启动村长无限画布.vbs”静默启动。
- “启动村长无限画布.bat”是唯一环境配置源。
- “村长无限画布-Start.bat”仅保留为兼容入口。

目录原则：
- 源码、运行环境和项目资产都位于当前总文件夹。
- runtime、项目资产、node_modules、.venv 和缓存不进入 GitHub。
- 私人密钥只保存在“项目资产\state”。
- 最终迁移使用白名单便携包，不复制开发缓存。

源码安装与数据目录说明见 README.md。
