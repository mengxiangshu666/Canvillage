# 兄弟角色设定表工作流（金标准）

## 3大金标准

### 金标准1：先生成单图（人介入节点）

❌ 旧：1次写4视图提示词 → 4张图都失败 → 重写
✅ 新：1张单图 → 兄弟审核 → 通过=锚点

**目标：把批量失败风险前移；实际节省取决于模型报价、失败率和授权额度，不承诺固定比例。**

### 金标准2：参考图驱动

"我们可以直接引用这个人物的全身照写一个提示词：保持图中角色的外观、比例、颜色、细节完全一致"

- 参考图驱动的图生图能力档（`gpt-image` / `multimodal-image-edit`，见
  `village-canvas-character-consistency`）把身份从文字转移到像素，这是最有效的一招
- 提示词只负责"这次改什么"，身份由参考图承担

**不要在这里写死模型名。** 本技能此前写的 `Nebula Pro` 在本产品里不存在，
照着调只会失败或编造；用之前先核对当前可用模型目录。

### 金标准3：1/3 + 2/3布局（角色设定表标准）

"生成一张角色设定表，左侧1/3是角色正面大头照（头顶到胸口），右侧2/3是全身三视图（正面、侧面、背面并排站立）"

- 大头照 = 脸（最重要）
- 三视图 = 比例 + 服装
- 1张图含所有角度 = 后续视频引用1张就行

## 5步工作流

```
Step 1：写正面全身照提示词（纯白背景）
Step 2：用支持图生图的图像模型生成单图（先核对模型目录）
Step 3：兄弟审核（如果满意）
Step 4：用审核通过的图做参考图
Step 5：写"角色设定表"提示词（浅灰 #E8E8E8 背景）
```

**关键节点**：
- Step 1-2 = 单图试探（按真实报价计费）
- Step 3 = 人介入（避免整体失败）
- Step 4-5 = 参考图驱动的角色表（另行核对费用与授权）

## 提示词模板

### 提示词A：正面全身照（Step 1，试探图）

```
(正面全身站立:1.3)
(26岁中国男性极客, 175cm/65kg 瘦削身材)
(黑眼圈明显-重度熬夜标志, 皮肤偏黄暗沉-亚健康)
(黑色微卷头发抓乱自然定型)
(穿宽松黑色纯棉T恤无logo, 深灰色休闲裤, 赤脚)
(无首饰无眼镜, 肩膀微微内扣, 微前倾)
(目光锁定前方, 双手自然下垂)
(右手虎口有旧烟疤)

(纯白背景:1.0)
(平视角度, 全身完整入画, 头部到脚底)
cinematic, 照片写实风格
4K, ultra-detailed, sharp focus
主体占画面中心, 上下留白

--no 卡通, 动漫, 模糊, 错字, 装饰, 多余元素
```

### 提示词B：角色设定表（Step 5，参考图驱动）

```
(参考图: 刚才审核通过的 26岁中国男性极客正面全身照)
(保持图中角色外观、比例、颜色、细节完全一致:1.5)

角色设定表布局:
- 左侧 1/3: 角色正面大头照(头顶到胸口), 居中
- 右侧 2/3: 全身三视图(正面、侧面、背面并排站立)
- 三个角度角色比例完全一致, 像原地转身
- 三视图之间有 5% 间隔, 不要挤在一起

(浅灰背景 #E8E8E8:1.0)
(无任何杂色块, 纯灰, 干净, 抠图感)
cinematic, 照片写实风格
4K, ultra-detailed, sharp focus
布局工整, 边缘清晰, 抠图友好

--no 卡通, 动漫, 模糊, 错字, 装饰, 多余元素
```

## 为什么用 #E8E8E8

| 类型 | 细节 | 抠图 | AI聚焦 |
|------|------|------|--------|
| 纯白 #FFFFFF | ✅最清 | ⚠️容易 | ❌AI跑偏 |
| **浅灰 #E8E8E8** | **✅清** | **✅容易** | **✅聚焦** |
| 中灰 #808080 | ⚠️略吃 | ❌难 | ✅聚焦 |
| 深灰 #404040 | ❌吃光 | ❌难 | ✅聚焦 |

**#E8E8E8 = 4维度最优平衡**

## 落到村长

1. 先读取当前项目、角色节点和可用图像模型目录；不把历史模型名或外部 CLI 当成真实工具。
2. 用现有画布提案/生成合同创建一张试探图；是否启动媒体只看本轮 `task_authorization`。
3. 等用户确认唯一锚点后，才把该结果作为参考图生成角色设定表；没有结果回执不说“已生成”。
4. 每一步记录输入参考、产物节点、模型显示名、授权状态和失败原因；失败时只重做当前步骤。
5. 角色表继续交给 `village-canvas-character-consistency` 维护身份锁，分镜只引用通过的资产。

## 兄弟工作流 vs 旧工作流

| 维度 | 旧 | 兄弟新 |
|------|------|--------|
| 步骤数 | 1步 | 5步 |
| 人介入 | ❌无 | ✅ Step 3审核 |
| 参考图驱动 | 弱 | 明确绑定通过的锚点 |
| 失败重试成本 | 4张都失败 | 1张失败 |
| 成本 | 未知 | 由实际报价、失败率和授权额度决定 |
| 一致性 | 弱（4张独立）| 强（1张审核通过）|
