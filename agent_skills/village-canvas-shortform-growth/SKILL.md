# Village Infinite Canvas 短视频增长诊断

这个 Skill 面向短剧预告、口播、B-roll、产品演示和社媒切片。它分析的是结构、节奏与
信息密度，不复制参考片的具体台词、独特画面和可识别创意表达。

## 一、何时加载

- 前几秒没有信息张力或视觉理由；
- 完播率低、节奏断、信息重复；
- 需要从长片选切竖屏片段；
- 有对白却没有字幕、声音层次或 CTA；
- 需要分析参考片的钩子和节拍；
- 需要把横屏内容重构为 9:16，避免简单裁中间。

## 二、事实边界

- 有真实播放数据时，按真实指标诊断并标明时间窗口；
- 没有数据时，只做结构性诊断，不说“预计提升多少”；
- 参考片只用于提取“结构、节奏、构图关系”，不复制受保护表达；
- 不能识别音轨、字幕或关键帧时，明确说未验证，不靠想象补证据。

## 三、前三秒钩子

前三秒至少满足两项：

1. 出现一个必须解释的异常；
2. 提出一个观众想知道答案的问题；
3. 直接展示结果，再倒叙原因；
4. 给出明确损失、冲突或身份关系；
5. 用画面、声音或文字同时制造信息差。

不要用“大家好、今天分享、这是一个”等延迟信息。

### 钩子检查表

```text
第一画面是什么？
第一句话是否与第一画面重复？
观众三秒后知道要等什么吗？
是否存在无法从标题推断的信息？
声音是否比画面先泄题？
```

## 四、留存节拍

把片段拆成信息单元，而不是均匀切镜头：

| 时间点 | 新信息 | 情绪变化 | 视觉变化 | 声音变化 | 是否重复 |
|---|---|---|---|---|---|
| 0-3s | 钩子 | 疑问/冲击 | 异常画面 | 钩子声 | 否 |
| 3-8s | 背景 | 紧张上升 | 人物/空间 | 信息加速 | 否 |
| 8-15s | 第一次回报 | 满足一小部分 | 细节/证据 | 停顿或重音 | 否 |

每 3-8 秒至少发生一次“信息、情绪、空间或声音”的变化。变化不是必须换镜头，固定镜头
里也可以通过动作、焦点、台词和声音完成。

## 五、参考片重构

按以下顺序拆参考片：

```text
时间轴
  -> 每段叙事功能
  -> 景别 / 机位 / 运动
  -> 角色行动与信息增量
  -> 台词功能，不抄具体台词
  -> 音效与节奏点
  -> 转场机制
```

重构时只迁移结构：

- 新的主体、地点、台词和视觉资产；
- 保留“何时给信息、何时停顿、何时反转”的节奏；
- 不保留参考片标志性构图、口头禅、角色造型或独特特效组合；
- 若用户要求高度复刻具体作品，改为“结构借鉴 + 原创表达”的替代方案。

## 六、诊断矩阵

| 维度 | 失败信号 | 修复方向 |
|---|---|---|
| 钩子 | 三秒内无冲突/异常 | 把结果、问题和损失前置 |
| 清晰 | 观众分不清人物关系 | 用动作和字幕补一句关系 |
| 回报 | 信息只积累不兑现 | 每 8-15 秒给一次小回报 |
| 节奏 | 连续重复同景别 | 远中特交替，但服从轴线 |
| 表演 | 情绪和话语不对齐 | 先给反应，再给台词 |
| 字幕 | 与重音、动作不同步 | 按语音和情绪切分，不只按句号 |
| 声音 | 只有 BGM，没有空间声 | 补呼吸、脚步、物件和环境 |
| CTA | 突然出现或与内容无关 | 让结尾动作自然导向下一步 |

## 七、字幕系统

字幕先服务听清，再服务风格：

```text
安全区
最大行数
每行字符预算
基线位置
字体 / 字重 / 描边
关键词强调规则
进入 / 退出动画
与说话者和动作的绑定
```

重点词可以放大、变色或换位，但同屏最多保留一个主要强调。字幕不能遮脸、遮手、遮
产品接触点或越过平台安全区。

## 八、横竖屏重构

不要只做居中裁切。逐镜选择：

| 策略 | 适用 | 风险 |
|---|---|---|
| 主体跟随裁切 | 单主体、动作集中 | 丢失空间关系 |
| 生成式扩展 | 宽构图必须保留 | 背景可能漂移 |
| 拆成两个镜头 | 双主体或左右信息 | 节奏变快，需要新切点 |
| 上下分屏 | 对比、教程、前后变化 | 文字空间被压缩 |
| 重构构图 | 可重生成的关键帧 | 需要一致性引用 |

横转竖时逐镜检查：主体中心、视线空间、手部、道具、字幕安全区、平台 UI 区域。

## 九、输出合同

```text
目标观众与平台
片段目标
钩子诊断
节拍表
必须保留的信息
建议删除或前移的内容
逐镜修改表
字幕方案
声音与 CTA
无法验证的数据
```

修改表必须写成“原内容 -> 问题 -> 新动作/新台词功能 -> 影响时长”，不能只给原则。

## 十、验收清单

- [ ] 前三秒有明确信息张力。
- [ ] 每 3-8 秒至少有一次有效变化。
- [ ] 每 8-15 秒至少给一次可感知回报。
- [ ] 参考片只迁移结构，没有复制具体受保护表达。
- [ ] 字幕与语音、重音和动作同步。
- [ ] 声音包含对白、动作音和环境层。
- [ ] 横竖屏重构逐镜选择策略，没有只裁中间。
- [ ] 没有伪造播放、转化或留存数据。
