# 生图提示词成图纪律

一张图只解决一件事：**一个视觉中心**。画面脏、灰、锐、假，几乎都是因为没有中心，
或者把次要元素也画清楚了。

> 与相邻技能的分工：`village-canvas-prompt-framework` 是**分镜/视频**提示词；
> `village-canvas-lighting-director` 是**光影专项**；本技能是**单张图片**的成图纪律。

## 一、默认行为

- **默认只输出提示词，不调用生图工具**。除非用户明确要求生成、渲染或出图。
- 默认输出一份完整中文提示词；要求英文只给英文，要求双语先中后英。
- **输入少时直接补全**（镜头、场景、光线），不要频繁追问。
- 只有"写实/动漫/商品"这类方向**判断不出来、且不同选择会明显改变结果**时，才问一次。
- **不输出互相冲突的备选方案**——给一条能用的，不要甩三个方向让用户挑。

## 二、五步基础流程

1. 判断主要风格（见第三节）；
2. 明确主体、场景、动作或展示目的；
3. 补全合适的镜头、构图、光线、色彩；
4. 控制背景与次要细节，**突出一个视觉中心**；
5. 输出紧凑、连续、可直接使用的最终提示词。

## 三、三类风格分流

| 风格 | 适用 | 要点 | 避免 |
|---|---|---|---|
| **真人电影感** | 真人、写实、摄影、胶片、剧照、街景、建筑、自然 | 像摄影机捕捉到的真实瞬间而不是宣传海报；人物自然动作，不完全正面站定、不刻意摆拍；用明确现场光（窗光/阴天光/路灯/门洞光/侧逆光）；保留自然高光、干净阴影、柔和边缘 | 数码锐化、油腻 HDR、过度磨皮、死黑暗部、脏噪点、全画面均匀高清 |
| **动漫插画** | 动漫、二次元、插画、校园、冒险、幻想 | 清楚色块、明确轮廓、干净阴影；按题材选鲜明或克制，不要所有颜色同时抢眼；角色/动作/关键道具最清楚，背景适度简化 | 泥灰阴影、杂色、过度锐化、廉价高清壁纸感、碎纹理 |
| **电商产品** | 商品、产品摄影、白底图、详情页、商业展示 | 商品轮廓、比例、展示面、关键卖点清楚可读；材质反光真实，背景干净，道具不抢主体；柔和商业光 + 自然接触阴影 | 广角变形、杂乱反射、过暗氛围、遮挡、强烈色偏 |

**没有明确方向时的默认**：真实人物/建筑/自然 → 真人电影感；可爱角色/魔法/幻想 →
动漫插画；明确商品展示 → 电商产品。

## 四、画面组织七层

围绕视觉中心补全，**复杂画面不要平均展示所有内容**：

1. **主体**：身份、外观、材质、动作或展示面（最清楚）
2. **场景**：地点、时间、天气、必要环境
3. **镜头**：角度、景别、焦段倾向、景深
4. **空间**：前景 / 中景 / 背景的简洁层级
5. **光线**：一个主要光源 + 必要的环境反射
6. **色彩**：主色、辅色、少量点缀色
7. **细节**：主体区域更清楚，背景与次要元素适度退后

人群、粒子、装饰、碎纹理一律减配。

## 五、参考图处理

有参考图时，**先提取用户真正要保留的东西**：主体特征、姿态、构图、材质、颜色、
整体气质——把这些**可见特征**写进最终提示词。

多张参考图合并时，必须明确四件事：核心主体是谁、位置关系、每张继承什么、
统一成什么光线。**不要只写"保持原图风格"**——那是模型无法执行的空话。

## 六、修复表（用户说效果不好时按现象查）

| 现象 | 调整方向 |
|---|---|
| 太脏、太乱 | 减少背景碎纹理、粒子、杂色、无关细节 |
| 太锐、太数码 | 降低硬边、微对比、密集纹理，恢复自然边缘 |
| 太灰、没颜色 | 明确主色/辅色/点缀色，提高必要色块亮度或饱和度 |
| 暗部死黑 | 增加**来源合理**的环境反射，保留阴影层次 |
| 主体不突出 | 强化主体明暗/颜色/清晰度，简化背景 |
| 真人脸太假 | 取消过度磨皮和无来源正面补光，让脸服从现场光 |
| 动漫画面杂乱 | 减少颜色数量、背景碎纹理、随机粒子 |
| 商品不清楚 | 恢复商品轮廓、比例、材质反光、接触阴影 |

## 七、输出格式

默认 **1–3 段连续提示词**，不加字段标题，不展示分析过程。顺序：

1. 主体、动作或展示目的 + 镜头视角
2. 场景层级、光线、色彩
3. 细节控制 + 当前任务最相关的少数避免项

要求：开头写最重要的；用明确选择不写备选；只保留会明显影响画面的细节；
不堆砌空泛质量词（"8K 超高清""杰作"这类对结果无影响的不写）。

## 八、验收清单

- [ ] 明确了唯一视觉中心，背景与次要元素已减配
- [ ] 风格已分流到三类之一（或用户明确指定了方向）
- [ ] 写了主体/场景/镜头/空间/光线/色彩/细节七层（不必全写，但主体与光线必写）
- [ ] 有参考图时，提取的是可见特征而非"保持原图风格"
- [ ] 多图合并明确了主体/位置/继承/统一光线四件事
- [ ] 按修复表对应现象改写，不是笼统重写
- [ ] 输出是 1–3 段连续提示词，无字段标题、无分析过程
- [ ] 未在用户未要求时调用生图工具
