# 模型路由速查

## 图像

- 参考图一致性优先：使用身份图/三视图/场景参考，Prompt 保持短而精确。
- 文字、海报、版式优先：主体文字、版式关系和字体位置放前，避免复杂摄影描述淹没文字任务。
- 电影感场景：先锁定空间和光线，再补镜头、材质和胶片质感。
- 扩散/ComfyUI：可以使用标签、权重、LoRA、ControlNet，但只在目标模型真实支持时写入。

## 视频

- 首帧图生视频：把图片当作 t=0，只写之后的动作和镜头运动。
- 真人/表演：优先写微表情、视线、重心、手部和连续动作，不用抽象情绪词。
- 动作/战戏：减少同时发生的事件，写清方向、速度、碰撞和收势。
- 多参考/多机位：逐张标明引用职责，不能让风格图改写角色身份，也不能让身份图改写构图。

## 模型能力检查

在 Prompt 中使用模型专属参数前，先核对真实模型目录、API 模式、参考数量、时长、画幅和分辨率。模型不支持的参数写入“未知/待确认”，不要伪造能力。
