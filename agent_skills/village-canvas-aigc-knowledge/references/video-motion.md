# 视频动作链

## first-frame 合同

```text
可见起始帧 → 第一动作 → 连续动作 → 动作终点 → 镜头终点 → 环境声音
```

动作句必须回答：

1. 哪个主体在动？
2. 身体哪个部位先动？
3. 方向是什么？
4. 重心如何变化？
5. 动作完成后主体在哪里？
6. 摄影机如何配合？

## 禁止模式

- 先前进再后退；
- 先靠近再撤回；
- 左转再右转；
- 从静止帧开始描述已经发生的动作；
- 用“充满情绪、很有张力、非常震撼”替代可观察的身体和镜头行为；
- 在短片段内塞入多个互不相关的剧情事件。

## 推荐结构

用 2–3 个同方向动作延长运动持续时间，再用一个明确的摄影机终点收束镜头。对白镜头补充嘴部运动、手势、视线和声线，不把对白全文重复塞进动作段。
