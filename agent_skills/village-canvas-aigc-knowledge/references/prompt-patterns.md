# Prompt 模块与自检

## 七模块结构

1. **主体合同**：身份、数量、年龄、外观、服装和不可变化项。
2. **表演合同**：动作起点、身体部位、方向、重心、视线、潜台词和动作终点。
3. **摄影合同**：景别、机位高度、方位、焦段感、构图、运镜和镜头终点。
4. **场景合同**：地点、时间、天气、光线动机、材质、固定设施和道具。
5. **风格合同**：媒介、画风、色彩、光影、纹理、后期质感和参考作品语法。
6. **连续性合同**：前后镜头的角色位置、屏幕方向、道具状态、光线和动作承接。
7. **负向合同**：只列本镜高风险错误，如身份漂移、额外肢体、场景重构、字幕和水印。

## 主观词翻译

| 模糊表达 | 可执行表达 |

| 破败 | 木窗漆面脱落、灰色木纹外露、玻璃裂纹、门槛石缺角 |
| 温暖 | 室内右上方 3000K 钨丝灯，脸部有柔和金色补光 |
| 冷峻 | 左侧 6500K 冷白主光，低饱和蓝灰色阴影，硬轮廓 |
| 高级感 | 三层景深、非居中构图、单一视觉引导线、克制高光 |
| 潮湿 | 墙角深色霉斑、漆面起皮、地面局部反光、水痕沿墙根延伸 |

## 视觉 Prompt 最小自检

- 重要主体是否出现在第一句？
- 参考图职责是否清楚？
- 是否混入了无法观察或无法生成的抽象词？
- 光源是否有方向和色温？
- 材质是否写出颜色、状态和纹理？
- 负向约束是否与正向目标对应？
- 是否保留了项目指定的画幅和模型参数？
