## 一句话

## 涵盖领域

- AI 视频生成工具对比（Runway/Kling/Sora/Wan/LTX/Pika…）
- AI 图像生成（MJ/SD/ComfyUI/FLUX…）
- AI 音频音乐（Suno/Udio/ElevenLabs…）
- AI 语音 TTS（ElevenLabs/HeyGen/Fish Audio/ChatTTS…）
- 工作流自动化（n8n/ComfyUI/Dify…）
- 视频提示词工程（6 模块系统）
- 分镜脚本工具
- 后期剪辑工具
- 分发平台（抖音/B站/YouTube/TikTok…）
- 制片管线模板

## 核心洞察

**图像优先 > 文生视频：**
```
Script → Shot List → Image Prompts → Keyframes → img2vid → Edit
```
先出图再出视频，保证角色/场景一致性，省积分。

**提示词 6 模块系统：**
1. 舞台环境
2. 前景细节
3. 中景主体
4. 背景结构
5. 动态元素
6. 技术栈（灯光/摄影机/镜头/渲染）
