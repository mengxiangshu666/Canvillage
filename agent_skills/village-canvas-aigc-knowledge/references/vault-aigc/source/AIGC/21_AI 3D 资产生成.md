## 二、推荐工具详解

### 2.1 TRELLIS 2（微软研究院开源）— 首选

**核心优势：**
- 高斯泼溅（Gaussian Splatting）→ 照片级真实纹理
- 免费开源 → 无限本地生成
- 提供 Web App（trellis2.app），无需安装
- 仅需 8GB+ VRAM

**缺点：**
- 只有图生3D（不支持文字）
- 不支持多视角重建
- 高斯泼溅格式需要转换才能用某些工作流

**输出格式：** GLB（游戏引擎友好）、Gaussian Splatting

### 2.2 Tripo AI — 功能最全

**核心优势：**
- 完整管线：文字→3D、图片→3D、骨骼绑定、动画、编辑
- Smart Mesh P1.0：~2秒生成干净拓扑（2026年3月发布）
- AI 骨骼绑定 + 动画预置（500+）
- PBR 材质（albedo / normal / roughness）

**数据：**
- 融资 $50M+（阿里 + 百度）
- 650 万+ 创作者
- 9 万+ 开发者
- 生成近 1 亿个 3D 模型

**价格：** 免费 300 积分/月 → $19.90/mo Pro → $49.90/mo Advanced

### 2.3 Meshy AI — 3D 打印首选

**核心优势：**
- 原生 STL 输出，防水网格
- 3D 打印实测排名第一（Meshy 官方 2026 测试）
- 支持文字→3D 和图片→3D
- 多格式导出：OBJ / FBX / STL / GLB

**价格：** 免费 100 积分/月 → $20/mo Pro → $48/mo Studio

## 三、在 AIGC 电影中的应用

### 3.1 应用场景

| 场景 | 工具 | 工作流 |
|------|------|--------|
| 创建虚拟场景模型 | TRELLIS 2 | 参考图 → GLB → 导入场景 |
| 角色道具（武器/配饰） | Tripo AI | 文字描述 → 自动贴图 + 绑定 |
| 角色动画 | Tripo AI | 图片→3D → 自动骨骼 → 动画预设 |
| 实物转到电影中 | Hitem3D | 多角度拍摄 → 3D 重建 |
| 电影级 3D 资产 | Rodin AI | 干净拓扑 → VFX 管线 |

### 3.2 推荐管线

```
AIGC 导演 3D 管线：

剧本 → 2D 概念图（Seedream/Flux）
   ↓ TRELLIS 2（图生3D）
3D 基础资产
   ↓ Tripo AI（贴图 + 绑定）
可动角色/道具
   ↓ 合成到视频场景中
```

## 四、关键参数

### TRELLIS 2 参数

| 参数 | 推荐值 |
|------|--------|
| 输入 | 单张图片（512x512 以上，正面最佳） |
| 输出 | GLB / Gaussian Splatting |
| 生成时间 | ~15-30s |
| VRAM 需求 | 8GB+ |
| 形状精度 | 正面 80-95% / 背面 50-70% |

### Meshy API 参数

| 参数 | 值 |
|------|----|
| ai_model | meshy-5 / meshy-6 / latest |
| model_type | standard / lowpoly |
| 生成时间 | ~1 分钟（简单物体更快） |
