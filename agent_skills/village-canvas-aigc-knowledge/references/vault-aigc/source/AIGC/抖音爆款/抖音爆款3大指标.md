## 一、抖音爆款 3 大指标

### 指标 1：完播率 (Completion Rate)
- 完播率 = 看完人数 / 播放人数
- **爆款阈值**：> 40%
- **实战**：我们的禁毒微短剧完播率 > 50%
- **优化方法**：开头 3s 必须吸引人

### 指标 2：互动率 (Engagement Rate)
- 互动率 = (点赞+评论+转发) / 播放人数
- **爆款阈值**：> 5%
- **实战**：禁毒微短剧互动率 > 8%
- **优化方法**：结尾必须有钩子

### 指标 3：转化率 (Conversion Rate)
- 转化率 = 关注人数 / 播放人数
- **爆款阈值**：> 1%
- **实战**：禁毒微短剧转化率 > 2%
- **优化方法**：账号定位清晰

| 流量池 | 播放量 | 阈值 | 升级条件 |

| 爆款 | 100000+ | 完播率 70%+ | 互动率 12%+ |

### 机制 2：标签匹配 (Tag Match)
- 系统给视频打标签
- 标签 = 关键词 + 视觉 + 声音
- **实战**：我们的禁毒微短剧 = "禁毒" "感人" "亲情"

### 机制 3：发布时间
| 时间段 | 流量 | 实战 |
|--------|------|------|
| 7-9 点 | 中 | 早高峰 |
| 12-14 点 | 高 | 午高峰 |
| 18-20 点 | 极高 | 晚高峰 |
| 21-23 点 | 极高 | 晚高峰 |

**实战：发布 19-20 点 = 流量最大**

### 机制 4：粉丝增长
- 新视频流量 = 历史平均 + 算法权重
- **实战**：账号粉丝越多，新视频流量越大
