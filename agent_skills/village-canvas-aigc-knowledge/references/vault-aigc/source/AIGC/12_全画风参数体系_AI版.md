## 第 1 章：画风参数 8 层模型

每个画风 = 8 个可独立控制的参数层（来自 NovelAI + Neolemon 研究）：

| 层 | 参数 | AIGC 关键词 |
|----|------|------------|
| 1. **画幅格式**（Format）| 插图/3D渲染/漫画格/海报/角色表 | illustration, 3d render, comic panel, poster, character sheet |
| 2. **媒介**（Medium）| 水彩/油画/水墨/矢量/黏土/像素 | watercolor, oil painting, ink wash, vector, clay, pixel art |
| 3. **线稿**（Linework）| 粗细/有无/笔触类型 | thick outline, thin pencil, brush pen, lineless |
| 4. **着色**（Shading）| 平涂/渐变/排线/网点 | flat cel shading, soft painterly, crosshatching, halftone |
| 5. **色板**（Color Palette）| 色域/饱和度/色彩数量 | pastel, muted earth tones, neon, limited 3-color, monochrome |
| 6. **材质**（Texture）| 纸张/画布/噪点 | paper grain, canvas weave, screenprint noise, clean flat |
| 7. **光照**（Lighting）| 光源/氛围 | soft daylight, golden hour, moody neon, rim light |
| 8. **构图**（Composition）| 布局/视角 | storybook framing, centered, dynamic action shot |

## 第 4.5 章：结构 vs 风格解耦画风法（**2026 新方法论**）

> 创建日期：2026-07-01
> 来源：World Labs Marble Chisel 模式 + Adobe MAX 2025 GAiFF 6 部获奖短片
> 关键：**传统画风 prompt 是"结构 + 风格"混杂的一句话；2026 年的工业化做法是把两者解耦——先定结构、再切风格**

### 4.5.1 传统画风 prompt 的问题

```
错误示范（一句话混合）：
"一部日式枯山水庭院风格的赛博朋克霓虹街道场景，电影感构图，"
→ 模型在"日式/赛博"两个风格词之间摇摆，注意力 50%/50% 稀释
→ 最终输出哪个风格都不纯粹
```

### 4.5.2 解耦画风法（结构 + 风格分层）

借鉴 World Labs Marble Chisel 模式 + Adobe Firefly Boards 工作流：

```
结构层（摄影指导思维）：
- 场景几何：房间长宽比、墙体数量、窗户位置、地面材质
- 机位：水平 / 仰视 / 俯视 / Dutch angle
- 灯光位置：key light 来自哪个方向
- 主体位置：subject at left-third intersection

+
风格层（美术指导思维）：
- 画风词：sumi-e / cyberpunk / oil painting / cel-shaded
- 色彩词：muted earth tones / neon saturated / monochrome
- 质感词：rough canvas / smooth digital / film grain
- 时代词：1970s / 2099 / Edo period
= 结构 × 风格 = 可控的工业化画风生成
```

### 4.5.3 实战 prompt 模板

```yaml
style_decoupled_prompt:

  # 第一层：结构（摄影指导）
  structure:
    scene_geometry: "long rectangular room with 3 windows on the right wall"
    camera_position: "eye level, slight Dutch angle 5 degrees"
    lighting_setup: "single key light from upper left, soft fill from right"
    subject_position: "subject standing at left-third intersection, facing right"
    depth: "shallow DOF, subject sharp, background blurred"

  # 第二层：风格（美术指导）
  style:
    art_movement: "sumi-e Japanese ink wash painting"
    color_palette: "muted indigo and beige, off-white paper"
    texture: "rough washi paper texture, ink bleed at edges"
    era: "Edo period, 18th century"
    reference: "in the style of Hokusai watercolor sketches"

  # 第三层：技术参数（后期合成思维）
  technical:
    aspect_ratio: "16:9"
    resolution: "1080p"
    --no: "subtitle text, watermark, modern objects, color saturation"
```

### 4.5.5 与画风 8 层模型的关系

原第 1 章的画风 8 层模型：
```
① 媒介层 → ② 时代层 → ③ 流派层 → ④ 艺术家层 →
⑤ 色彩层 → ⑥ 灯光层 → ⑦ 质感层 → ⑧ 构图层
```

**解耦画风法的分层逻辑**：
```
结构层（不随画风变化） = ⑦ 灯光层 + ⑧ 构图层 + 主体位置
风格层（可一键切换） = ① 媒介层 + ② 时代层 + ③ 流派层 + ④ 艺术家层 + ⑤ 色彩层 + ⑥ 质感层
```

这样**结构层是摄影指导的工作（机位、灯光、构图）**，
**风格层是美术指导的工作（媒介、时代、画派、色彩、质感）**，
对应到工业化分工，效率提升 3-5 倍。

## 🌶️ 拉美魔幻现实主义画风包（Magical Realism Pack · 2026-07 学习新增）

> 来源：IS MUNI / YorkSpace / Wesleyan / EL PAÍS 2023 / Cuarón+Iñárritu+del Toro 三杰 + El Conde / Bardo / Liborio / Tragic Jungle / Birds of Passage 近年案例

### 核心视觉原则
**本体论平等**——超自然事件与日常事件享有同等的存在论地位。不强调奇观，让超自然事件被忽略或打断。

### 摄影参数

| 参数 | 取值 | 反奇观逻辑 |
|------|------|----------|
| **焦段** | 24-35mm + 14mm 偶尔用 | 反 Hollywood 50mm 标准化 |
| **镜头** | 14-40mm wide angle prime + handheld | Iñárritu 宽角哲学 |
| **机位** | 中景 + 中远景，**禁用大特写** | 避免"消费角色情感" |
| **构图** | 不强调对称，让画面"混乱的真实" | 边缘畸变作为不安信号 |
| **色彩** | 高饱和自然色（拉美本土色）+ 自然光 | 拒绝 de-saturated 欧洲作者电影 |
| **光线** | 强烈阳光 + 阴影对比（Cuarón）/ 室内暗淡自然光（del Toro）| 拒绝"摄影棚布光" |
| **运镜** | 缓慢推进 + 偶尔突发 handheld | 长镜头为主 |

### 12 大不可缺参数

1. **本体论平等** —— 不用 magical / supernatural 标签，用中性日常动词
2. **去熟悉化** —— 文学化比喻描述熟悉事物（ice = "transparent block with infinite internal needles"）
3. **反讽性并置** —— 神迹与洗衣 / 吃饭 / 走路同框
4. **拉美地理** —— 沙漠 / 雨林 / 安第斯山脉 / 加勒比海
5. **原住民 / 非裔拉美** —— 显式标注 ethnicity（不写"通用拉美人"）
6. **时间循环** —— 过去 / 现在 / 未来在同一画面共存
7. **家族史诗** —— 至少出现三代人（祖父母 / 父母 / 子女）
8. **政治寓言** —— 殖民 / 独裁 / 革命 / 流亡作为隐含背景
9. **低预算美学** —— 故意保留 grain / 噪点 / 失真
10. **暴力美学** —— 当出现暴力时不回避，用作"语言"（Rocha）
11. **无配乐或单乐器** —— 拒绝 Hollywood 配乐饱和度
12. **集体作者** —— 提示词不署个人，署 "collective"

### 核心视觉原则
**"24 帧/秒的枪 + 不完美美学 + 集体作者论"**——Third Cinema 是电影史上最激进的**政治电影理论**，其美学原则对 AIGC 短片有直接借鉴价值。

### 摄影参数

| 参数 | 取值 | Third Cinema 逻辑 |

| **机位** | 游击机位 / 即兴跟拍 | 拒绝摄影棚预设 |

### 12 大不可缺参数

2. **现场光** —— 拒绝专业布光
3. **同期录音** —— 拒绝后期配音
4. **不完美构图** —— 故意倾斜 / 模糊 / 边缘畸变
5. **保留 grain / 噪点** —— 故意用低分辨率 / 低码率
6. **故意保留 AI 痕迹** —— AIGC 的手崩 / 表情僵 / 光影错位 = 集体创作痕迹
7. **不署个人导演** —— 署 "collective" 或 "human-AI collaborative"
8. **游击放映** —— 不依赖商业平台
9. **政治内容** —— 殖民 / 革命 / 流亡 / 阶级 / 性别作为显性主题
10. **暴力美学** —— 暴力作为"语言"（Rocha）
11. **原住民 / 非裔视角** —— 显式标注
12. **no Hollywood gloss** —— 显式排除好莱坞质感
