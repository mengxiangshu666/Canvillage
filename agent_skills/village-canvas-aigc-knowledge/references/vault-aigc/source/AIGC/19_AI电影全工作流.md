# 19_AI电影全工作流：从剧本到成片

> 来源交叉验证：ImagineArt AI Filmmaking Guide (2026-06) + Kinovi Consistency Guide (2026-05) + Runflow Production Workflows (2026-05) + MindStudio Cost Analysis (2026)
> 重点不是"怎么生成一个视频"，而是"怎么从剧本到成片保持一致性"

---

## 一、核心原则：导演笔记 ≠ 剧本

写剧本没用，要写**导演笔记**。

对每场戏（8-15 场）记录：

| 维度 | 要求 | 示例 |
|------|------|------|
| **Subject** | 谁在场、穿什么 | 穿旧皮衣的侦探，肩上有雨水 |
| **Action** | 现在时、单一动作/镜头 | 他推开生锈的铁门 |
| **Camera** | 景别 + 运动 | 中景，轨道慢推 |
| **Mood/Style** | 色调 + 灯光 + 风格 | 高对比黑色电影，冷调 |
| **Audio** | 对白 + 环境 + 音乐 | 雨声，远处警笛渐弱 |

**提示词公式（每场 2-3 句）：**
```
[Subject] + [Action] + [Environment] + [Camera] + [Mood] + [Audio]
```

示例：
```
A detective in a worn leather coat steps into a rain-soaked alley at midnight,
camera tracking low at ankle height, high contrast noir lighting,
tension building in the underscore, distant sirens fading into silence.
```

## 二、15 分钟短片生产时间线

| 阶段 | 时间 | 关键交付物 |
|------|------|-----------|
| Phase 1 剧本与镜头规划 | Day 1 | 镜头清单（40-80 个，各 5-10s） |
| Phase 2 参考资产生成 | Day 1-2 | 主角色 10-15 张 / 配角 5-8 张 / 场景 3-5 张 |
| Phase 3 批量生成 | Day 2-4 | 每镜头 2-3 个变体，共 120-180 条原始素材 |
| Phase 4 一致性与重制审核 | Day 4-5 | 重制 15-25% 有漂移的镜头 |
| Phase 5 剪辑与编辑 | Day 5-6 | DaVinci Resolve 调色 + 过渡 + 音轨 |
| Phase 6 音频与最终细化 | Day 6-7 | 配音 + 环境音 + 配乐 + 最终输出 |

单人 solo 5-7 天，双人团队 3-4 天。
有预建角色包的话，60-90 秒短片 = 1-2 小时。

## 三、4 层角色一致性锁

这是整个管道中最关键的环节。从头到尾锁定同一张脸。

### Layer 1 — Character DNA（蓝图文档）

一张纸锁死所有角色特征：

```
CHARACTER NAME: 老陈 / Detective Chen
AGE + VIBE: 45岁，疲惫但警觉
SILHOUETTE: 窄肩，旧风衣，微驼背
FACE ANCHORS: 深眼窝、高颧骨、左眉疤痕、灰色胡茬
HAIR ANCHORS: 灰白短发、偏分、鬓角整齐
SKIN: 暗沉、毛孔粗糙、略微晒伤
SIGNATURE PROP: 旧皮夹、永远叼着烟（不点）
BASE OUTFIT: 深灰三件套西装 + 棕色旧皮鞋
STYLE LOCK: 电影现实主义 / 颗粒感
COLOR PALETTE: #2D2D2D #4A4A4A #8B7355 #C4A882
CAMERA RULES: 近景允许、避免特写手指、全身镜头锁中景
DO NOT ALLOW: smile, bald, hat, leather jacket (different), glasses
```

### Layer 2 — 角色照片包（视觉锚点）

6-12 张参考图：
- 全身正面、3/4 侧面、侧面
- 中性表情近景
- 6 种表情（愤怒、悲伤、警觉、疲惫、微笑、沉默）
- 3 种常见姿态（站立、行走、坐下）

新项目做一套约 20-40 分钟。

### Layer 3 — 镜头关键帧（每场锁定）

每个具体镜头之前，先生成一张静态参考帧：
- 锁定画面构图
- 锁定角色角度和状态
- 然后用它做图生视频

### Layer 4 — 生成 + 精修

关键帧输入图生视频模型，输出后在剪辑软件里：
- 统一调色（选最满意的一场作为颜色参考）
- 匹配剪辑淡化过渡
- 小漂移用转场/插入镜头掩盖

## 四、模型选择决策（2026 年中）

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| 多镜头叙事 | Seedance 2.0 | 原生多段生成 + 12 个参考资产 + 原生音频 |
| 角色一致性优先 | Kling 3.0 | 评分 9/10，角色身份保留 90%+ |
| 对白多 | Seedance 2.0 | 口型同步最佳，支持多语言 |
| 广角场景 | Wan 2.6 | 环境规模和定场镜头最强 |
| 写实近景表情 | Veo 3.1 | 最高电影质量，4K 上采样 |
| 动作场面 | Kling 3.0 | 物理精确动作，角色一致性高 |
| 预算优先 | Seedance 2.0 Mini | 480p 80-100 积分/条 |

## 五、常见问题与修复

| 问题 | 原因 | 快速修 | 高级修 |
|------|------|--------|--------|
| 面部漂移 | 运动过多 + 锚点不足 | 加参考图、降低运动强度 | 上一帧结尾作为下一帧起始 |
| 服装变化 | 模型脑补了细节 | 每套衣服锁独立参考包 | 训练服装 LoRA |
| 背景闪烁 | 环境幻觉 | 上传背景参考图 | 绿幕 + 统一调色 |
| 手/脚变形 | AI 解剖学盲区 | 避免手部特写 | 生成手部参考包 |
| 长视频衰减 | 漂移累积 | 定时刷新参考图 | 每 30-60s 插入"角色复位"定场镜头 |

## 七、关键提示词模板

### 拍摄公式

```
[场景+环境] 中 [主体] 在 [动作]，镜头[景别+运动]，[灯光+色调]，
[情绪/风格]，[声音方向]
```

### Seedance 人设锁定

```
@CharacterName in [环境], [动作], [镜头控制],
[灯光描述], [情绪], [音频: 对白/环境/配乐]
```

### 一致性提示词附录

写在每条提示词最后：
```
--no face morphing inconsistent face changing outfit wrong hairstyle
```

或者用否定列表：
```
DO NOT ALLOW: face distortion, warping, floating objects, morphing,
background shift, extra limbs, wrong clothing
```
