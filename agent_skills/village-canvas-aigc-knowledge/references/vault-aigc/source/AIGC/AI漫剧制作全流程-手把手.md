# 手把手: 从0到第一篇AI漫剧

> 写于 2026-06-18 · 给"啥也不会"的自己

---

## 第一步: 用DeepSeek写剧本 (10分钟)

**打开**: chat.deepseek.com 或者直接在 Coze 里调 DeepSeek

**把这段话复制进去**:

```
我要做一个AI漫剧,时长30-60秒,竖屏。

题材: 现代都市/逆袭/爽文方向
要求:
1. 一个主角(名字+外貌描述)
2. 一个冲突场景
3. 一个反转/爽点结局
4. 拆成6-8个画面,每个画面写清楚: 人物/动作/表情/背景/台词
5. 画面之间要有叙事逻辑

格式:
画面1: [场景描述] [主角在做什么] [表情] [台词,如果有]
画面2: ...
```

**DeepSeek会给你的** — 复制下来,这就是剧本。

**自己微调**: 台词改成口语化,画面改得更有视觉冲击力。

## 第二步: 用即梦AI生成角色(20分钟)

**打开**: jimeng.jianying.com (抖音即梦AI) 或用 Midjourney

### 2.1 定角色形象

把DeepSeek给的主角外貌描述,复制到即梦AI文本框:

```
年轻男子,22岁,短发,眼神坚定,穿着黑色卫衣,半身像,正面,写实动漫风格,高清
```

**点"生成"** → 选最满意的一张 → 这就是你的主角。

### 2.2 保持角色一致性(最关键!)

即梦AI有**"参考图"功能**:
1. 上传刚才选的主角图
2. 勾选"角色特征参考"
3. 后续所有场景都用它做参考 → 角色长相不会变

### 2.3 生成每个画面的角色图

按剧本,每个画面生成对应的角色状态:
- 画面1: "【主角名】站在公司门口,愤怒表情,身后是高楼大厦"
- 画面2: "【主角名】被老板指着鼻子骂,屈辱表情,办公室场景"
- ...

每个画面生成 3-4 张,选最好的。

---

## 第三步: 用可灵AI把图变视频(15分钟)

**打开**: kling.kuaishou.com

### 操作

1. 点"图生视频"
2. 上传即梦出的第1张角色图
3. 在文本框写动作描述: "主角抬头看天,握紧拳头"
4. 点"生成" → 等1-2分钟 → 得到一段视频

**重复**给每个画面做视频。

可灵AI的**运动笔刷**(重要):
- 在图上画圈标注想动的部位
- 可以控制"人物挥手"、"风吹头发"、"转身"等动作

**如果觉得贵**: 可灵免费额度用完了,换 Seedance 2.0 (硅基流动上有),效果差不多。

---

## 第四步: 用剪映合成(20分钟)

### 4.1 导入

1. 打开剪映 → 新建项目 → 选竖屏 9:16
2. 把所有可灵出的视频片段拖进去
3. 按剧本顺序排列

### 4.2 配音

方法A: **剪映内置文字转语音**
- 点"文本" → "新建文本" → 输入台词
- 点"朗读" → 选一个声音(推荐"男声-阳光"或"女声-温柔")
- 调整语速到 1.1 倍(更自然)

方法B: **自己录音**(你是播音专业!)
- 点"音频" → "录音" → 直接配音
- 你的专业优势在这最大化

### 4.3 加字幕(自动)

- 选中音频 → 右键 "识别字幕" → 自动生成
- 调整字体大小位置(竖屏中间偏下)

### 4.4 加BGM

- 点"音频" → "音乐" → 搜"燃向" / "逆袭" / "激励"
- 选一首配得上剧情情绪的
- 音量调低到 20-30% 别盖住配音

### 4.5 加转场/特效(别过度)

- 画面之间加"硬切"就是最好的(别加花哨特效)
- 开头3秒加分镜缩放(让人停住往下看)
- 结尾加"点赞+关注"引导文字

### 4.6 导出

- 分辨率: 1080P
- 帧率: 30
- 导出 → 得到你的第一部AI漫剧!

## 第五步: 发抖音(5分钟)

### 标题模板(直接改)

```
【逆袭】22岁被老板当众羞辱,他却一笑#AI漫剧 #爽文

文案:
被人看不起的时候,最好的回应不是解释。
关注我,每天一部AI漫剧 👇
```

### 关键设置

- 话题: #AI漫剧 #原创漫剧 #爽文 #逆袭
- 封面: 选最有冲突感的画面
- 发布时间: 中午12点或晚上8点(流量高峰)
- 合集: 创建「我的AI漫剧」合集,后续所有剧加进去

## 流水线效率(每人专攻一个环节)

```
你(编剧) → 同学A(即梦抽卡) → 同学B(可灵生视频) → 同学C(剪映合成)
   2小时        1.5小时             30分钟              20分钟
```

**一部剧从0到发布: 4-5小时**(熟练后2-3小时)

**你负责的环节最重要**: 剧本必须每30秒有一个冲突or反转点,否则观众3秒划走。

**出一部30秒的AI漫剧,哪怕很简单。**
