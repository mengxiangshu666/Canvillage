## 三、综合判断：4 种可能场景

### 场景 A：纯 AI 数字人（LoRA + 视频生成）⭐ 概率 35%

**判断依据**：
- 音频完全静音（典型 AI 数字人特征）
- 码率极低（AI 重编码）
- 面部和身体都有 AI 美化痕迹
- 用户观察"同脸同动作多视频"

**技术栈**：
```
1. 人脸 LoRA 训练
   - 工具：Stable Diffusion + Kohya_ss
   - 数据：模特 30-100 张不同角度照片
   - 训练时长：30-60 分钟（3090显卡）
   - 输出：face_lora.safetensors

2. 文生图/图生图（生成完美身材）
   - 工具：Stable Diffusion / ComfyUI
   - 模型：ChilloutMix / MajicMix Realistic（真人模型）
   - 提示词：1girl, long legs, slim waist, Korean idol...
   - ControlNet：OpenPose 锁定模特姿势

3. 图生视频（让模特动起来）
   - 工具：可灵 (Kling) / Runway Gen-3 / Vidu / Hailuo
   - 输入：第2步生成的图片
   - 提示词：simple dance, slow motion, looking at camera
   - 时长：9秒

4. 后期合成
   - 工具：剪映 (CapCut) / Premiere
   - 加 BGM / 字幕 / 调色
```

**优点**：
- 完全可控的身材比例
- 一致的"完美形象"
- 可批量生产

**缺点**：
- 视频清晰度受限（可灵等都有上限）
- 动作幅度小，复杂动作会崩
- 服装细节依赖训练数据

---

### 场景 B：真人拍摄 + AI 局部增强 ⭐ 概率 30%（最可能）

**判断依据**：
- 帧间运动**平滑、线性**（0.77 比率）—— 这是真人拍摄的核心证据
- 身体运动自然（虽然小）
- 视频整体有真实拍摄感
- 但皮肤过于光滑符合"AI 美颜"或"重度磨皮"

**技术栈**：
```
1. 真人拍摄
   - 工具：手机（iPhone/华为）+ 支架
   - 场景：影楼/家里，简单背景
   - 模特：真人（请来的或自己）
   - 服装：商家寄样（带货模式）
   - 多角度拍：1-2 套衣服 × 3-5 个角度 = 15-30 分钟

2. 后期美颜/AI 增强
   - 工具：剪映"美妆"/"滤镜" / WINK / 醒图
   - 操作：磨皮/瘦脸/美白/大眼（10-30% 强度）
   - 这一步让皮肤"过于完美"

3. 后期剪辑
   - 工具：剪映
   - 操作：变速、卡点、加 BGM、字幕
```

**优点**：
- 动作自然流畅
- 服装真实（不会"穿模"）
- 视频清晰度高

**缺点**：
- 需要真人模特和拍摄
- 同一模特拍多套衣服成本高

---

### 场景 C：AI 数字人 + 真人参考视频 ⭐ 概率 25%

**判断依据**：
- 用户说"动作是一样的"——意味着参考同一段舞蹈视频
- 脸是固定的——LoRA 训练过
- 但身体完全 AI 生成

**技术栈**：
```
1. 找一段热门舞蹈视频（参考动作）

2. 训练人物 LoRA
   - 模特脸部 30-100 张图
   - 训练得到 face_lora.safetensors

3. 用参考视频驱动 AI 人物
   - 工具一：Wan2.1-Animate / MusePose / MagicAnimate
     - 输入：参考视频 + 人物图片
     - 输出：人物跟随参考视频动作的新视频
   - 工具二：Stable Video Diffusion + ControlNet
   - 工具三：即梦"动作模仿"功能

4. 换装（如果需要）
   - 工具：IDM-VTON / OOTDiffusion
   - 换不同的衣服

5. 后期加 BGM
```

**优点**：
- 动作参考视频，AI 人物能做出"网红舞"
- 换装快，可批量

**缺点**：
- 动作与人物细节可能不匹配
- 长视频容易崩

## 五、**关键的"虚假信号"和"真实信号"**

### 5.1 为什么视频看起来像真人？
- **动作自然**：基础视频来自真实拍摄或高质量参考
- **表情连贯**：AI 训练时已经学会了眨眼、微笑
- **头发飘逸**：发丝动力学是 AI 强项

### 5.2 为什么本质是 AI？
- **静音轨道**：100% 概率是 AI 数字人特征（无现场录音）
- **皮肤完美度**：超出现实磨皮极限
- **身材比例**：A4 腰 + 筷子腿 = AI 训练数据偏好
- **品牌一致性**：跨视频完全相同的"完美形象"是数字人最大优势

### 5.3 用户观察的"同脸同动作"如何解释？
- **同脸**：LoRA 训练锁定面部特征
- **同动作**：可能用了**同一段参考舞蹈视频**驱动
- **同身材**：固定 prompt 模板生成
