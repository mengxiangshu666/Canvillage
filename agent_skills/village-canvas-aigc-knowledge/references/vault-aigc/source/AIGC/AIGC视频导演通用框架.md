# 1. 铁律清单

> 以下铁律适用于**任何**AIGC视频项目，不依赖具体剧本。

## 1.1 提示词铁律

### 铁律 A：物理行为描述（因果链升级版）
**适用场景**：任何涉及角色动作的提示词
**原则**：AI不会推断动作。不写"他出去了"——写他**用哪只手、身体怎么转、脚怎么迈、重心怎么移**。

**格式**：
```
主体 + 身体部位 + 物理动作 + 方向 + 做完后的位置
```

**三层对比**：

| 层级 | 写法 | AI理解 |
|------|------|--------|
| ❌ 事件级 | "他出门了" | 人凭空消失 |
| ⚠️ 动作级 | "他跨出门槛，转身关门" | 动作模糊，方向不明 |
| ✅ 物理级 | "他抬起右脚跨出门槛，身体重心前移，上半身探出门外，左脚跟上——现在整个身体在门外。他转身面向门，身体转了180度。他伸出右手，抓住门把手，手臂向后拉，门向自己靠近，直到门框完全贴合。门关上了。" | 可逐帧生成 |

**自查**：每句动作描述问——"用哪只手？身体怎么转？重心在哪只脚？做完之后这个人在什么位置？"

### 铁律 B：禁止概括词
**适用场景**：任何有具体角色名的项目
**原则**：用资产表中的具体角色名，不用"孩子/父亲/警察/男人/女人"。
**自查**：搜索「孩子」「父亲」「警察」「男人」「女人」→出现即错误。

### 铁律 C：中文写中文场景
**适用场景**：中文内容
**原则**：AI吃中文比英文翻译更准。

### 铁律 D：@主体标注
**适用场景**：多角色画面
**原则**：画面描述中标注 `@角色名`，不是只在台词里标。

### 铁律 E：负面约束
**原则**：每镜末尾加 `不要生成台词字幕 不要BGM 生成环境音和台词配音 同期声`
**额外**：按项目风格加专属禁止项（如暗调项目禁止阳光/暖色/鲜艳色彩）

### 铁律 F：15s硬上限 + 不切碎
**原则**：每个大段 ≤ 15s，一个完整连续镜头。不切成碎片。
**时长**：按内容密度定——动作密=短，情感深=长。

### 铁律 G：提示词一体
**原则**：摄影系统+灯光+胶片+动作+台词+负面约束→全塞一个prompt字段，不分节点。

---

## 1.2 流程铁律

### 铁律 H：先看资产再写剧本
**流程**：逐张看人物→逐张看场景→写剧本→资产映射表
**原则**：剧本贴着图的特征写，不先想故事再找图。

### 铁律 I：先跑一镜再全量
**原则**：选一镜代表性镜头先跑→看效果→通过后再全量跑。不要全跑全翻。

### 铁律 J：先480p后高清
**原则**：所有镜头480p最低画质生成→验证通过→拼合→一键高清。

---

## 1.3 内容铁律

### 铁律 K：台词要有潜台词
**原则**：每句"表面说A，实际说B"。
**自查**：问"这句话表面在说什么？实际在说什么？"无第二层=重写。

### 铁律 L：短视频必须有开头背景
**规则**：30s→5-10s铺垫 / 60s→10-15s / 90s→20-30s
**方式**：旁白（第三人称/纪录片风）

### 铁律 M：旁白讲故事不是念档案
**原则**：有具体细节（时间/地点/事件/场景），让观众听一遍就记住。

### 铁律 N：台词信息密度
**规则**：每句3-5秒/每段7-10句/紧张时刻0句/情感时刻5+句

# 2. 剧本写作通用流程

> 不管拍什么，按这个流程走。

## 2.1 第一步：资产盘点

```
1. 逐个看人物资产 → 记录：外貌/衣着/年龄/气质
2. 逐个看场景资产 → 记录：灯光/色调/构图/道具
3. 逐个看道具资产 → 记录：用途/象征意义
4. 输出：资产清单表
```

## 2.2 第二步：故事大纲

```
1. 用一句话说清楚：谁 + 要什么 + 障碍是什么
2. 拆成 N 个大段：每段一个核心情绪/事件
3. 定每段时长：按内容密度，不按模板
4. 输出：段落概要表
```

## 2.3 第三步：写剧本

```
1. 开头介绍段（旁白+空镜，铺垫背景）
2. 主体段落（每段贴着资产图写）
3. 每段标注：用哪个场景、哪个人物
4. 结尾段（余味，不总结）
```

## 2.4 第四步：资产映射

```
1. 人物 → 段号（哪些段出现）
2. 场景 → 段号（哪个段用哪个场景）
3. 道具 → 段号
4. 备用资产 → 标注（给不同时长版本留空间）
```

## 2.5 第五步：台词审查

```
1. 每句有潜台词吗？（表面A，实际B）
2. 每段台词够7-10句吗？
3. 角色说话符合身份/地域/时代吗？
4. 声线库配好了吗？（年龄+性别+质感+口音+状态）
```

# 4. AI音画同步台词系统

> Seedance 2.0 VIP 自带音画同步。无需TTS。换剧本只换声线库。

## 4.1 黄金格式

```
【台词/旁白（@角色名，声线描述，语气描述，情绪描述）："具体台词内容"】
```

## 4.2 声线描述公式

```
年龄 + 性别 + 质感 + 口音 + 状态
```

**质感库**：沙哑 / 粗粝 / 虚弱 / 浑浊 / 浑厚 / 清澈 / 低沉 / 尖锐

## 4.3 语气/情绪描述方法

**错误**：用概括词（悲伤、紧张、愤怒）
**正确**：写"像在____"的具体状态

| 概括词 | → | 状态描述 |
|--------|---|---------|
| 悲伤 | → | 像在说一件他也说不清楚的事 |
| 紧张 | → | 压得很稳但追得很快 |
| 绝望 | → | 不是求饶，是在求一个机会 |
| 试探 | → | 语气像在闲聊，但其实是试探 |
| 克制 | → | 声音很轻，不想让对方听出他的难受 |

## 4.4 声线库模板（每个项目新建一张）

| @角色 | 声线 | 用在哪 |
|--------|------|--------|
| @角色1 | [年龄] [性别] [质感]声线，[口音]口音，[状态] | 段X |
| @角色2 | ... | 段Y |

## 4.5 全局指令

```
不要生成台词字幕 不要BGM 生成环境音和台词配音 同期声
```

# 5. 摄影系统选型

> 不依赖剧本。按整体风格选一套，全片统一。

## 5.1 按风格选摄影机

| 风格 | 机身 | 镜头 | 胶片 | 滤镜 |
|------|------|------|------|------|
| **现实主义/纪录片** | ARRI Alexa Mini | Zeiss Super Speed定焦 | Kodak 500T | BPM 1/8 |
| **文艺/清新** | Sony Venice | Cooke S4 | Kodak 250D | BPM 1/4 |
| **赛博朋克/科幻** | RED Komodo | Angénieux变焦 | — | 无 |
| **复古/年代** | ARRI Alexa | Zeiss Standard Speed | Kodak 200T | BPM 1/2 |

> 238项目数据："ARRI+Alexa"出现7250次，"Kodak Vision"同量级。现实主义=ARRI+Kodak是铁律。

## 5.2 按风格选画幅比

| 画幅 | 效果 | 适用 |
|------|------|------|
| 2.39:1 | 宽银幕/电影感/孤立感 | 剧情片/TVC |
| 1.85:1 | 标准电影/平衡 | 一般短片 |
| 16:9 | 电视/网络 | 短视频 |
| 1.66:1 | 欧洲文艺片/亲密 | 文艺片 |
| 4:3 | 复古/压抑/老照片 | 年代/悬疑 |

## 5.3 按风格选影调

| 参数 | 现实主义暗调 | 文艺清新 | 商业暖调 | 科幻冷峻 |
|------|------------|---------|---------|---------|
| 饱和度 | -30% | -10% | +10% | -20% |
| 暗部 | 5% | 15% | 10% | 3% |
| 高光 | 85% | 95% | 90% | 80% |
| 色温偏移 | 冷蓝 | 微暖 | 暖 | 蓝绿 |

# 6. 灯光设计决策树

> 不依赖剧本。按场景类型和情绪选灯光。

## 6.1 核心原则

- **有源光**：每一束光都有看得见的来源
- **现实主义不补光**：暗的地方就是暗的
- **AI提示词写光源**，不写形容词（"冷蓝夜光从窗缝漏入" ≠ "dark room"）

## 6.2 按场景类型选光源

| 场景类型 | 可用光源 | 光质 | 色温 |
|---------|---------|------|------|
| 室内夜间 | 窗缝光/台灯/屏幕光 | 硬 | 2800-3200K |
| 室内白天 | 窗户光/天光 | 柔 | 5600K |
| 室外夜间 | 路灯/月光/手电/警灯 | 视光源而定 | 4000-6000K |
| 室外雾天 | 环境光/远处灯光 | 极软 | 5600K |
| 工业/仓库 | 荧光管/工矿灯/手电 | 硬 | 4300K |
| 舞台/礼堂 | 聚光灯/面光 | 柔 | 3200K |

## 6.3 按情绪选光比

| 情绪 | 光比 | 补光 |
|------|------|------|
| 平静/温暖/安全 | 1:1-2:1 | 有 |
| 日常/对话/中性 | 3:1-4:1 | 弱 |
| 紧张/压抑/不安 | 6:1-8:1 | 无 |
| 恐惧/追捕/极端 | 10:1-12:1 | 无 |

## 6.4 灯光提示词模板

```
[光源]从[方向]照入，[光质]，[光比]，不补光/弱补光，色温[值]K
```

# 7. 镜头语言选型

> 不依赖剧本。按表达需求选参数。

## 7.1 焦段选择

| 焦段 | 与人物的距离感 | 最佳用途 |
|------|-------------|---------|
| 24mm | 远/冷/客观 | 建立空间/大环境 |
| 35mm | 中/对话距离 | 人物在环境中的关系 |
| 50mm | 近/亲密 | 情感交流/中近景 |
| 85mm | 极近/审视 | 特写/手/道具/眼神 |

## 7.2 景别选择

| 景别 | 焦段 | 画面中人的占比 | 传达什么 |
|------|------|-------------|---------|
| 大远景 | 24mm | 人很小 | 孤独/渺小/环境 |
| 全景 | 35mm | 全身 | 人物与环境关系 |
| 中景 | 35-50mm | 膝盖以上 | 动作/互动 |
| 中近景 | 50mm | 胸部以上 | 对话/情感 |
| 近景 | 50mm | 肩膀以上 | 反应/内心 |
| 特写 | 85mm | 局部 | 关键物件/情绪高点 |

## 7.3 运镜选择

| 运镜 | 效果 | 用在哪 |
|------|------|--------|
| 固定 | 客观/冷静/纪实 | 对话/静默/观察 |
| 横摇 | 空间展开/连接 | 空镜介绍 |
| 手持 | 紧张/真实/主观 | 追逐/冲突/慌乱 |
| 推近 | 情感深入/发现 | 关键表情/揭示 |
| 下摇 | 跟随动作/落下 | 物件掉落/低头 |

> **现实主义铁律**：不用Steadicam/Ronin。轻微呼吸晃动=真实。

## 7.4 光圈与景深

| 光圈 | 景深 | 用在哪 |
|------|------|--------|
| f/8-f/11 | 深 | 大远景 |
| f/2.8-f/4 | 中 | 中景/全景 |
| f/2 | 浅 | 中近景/近景 |
| f/1.4-f/1.8 | 极浅 | 特写 |

# 8. 转场选择矩阵

> 不依赖剧本。按两段之间的关系选。

## 8.1 四种转场

| 转场 | 何时用 | 效果 |
|------|--------|------|
| **硬切** | 连续动作/同一时间线/同一空间 | 不可见/自然 |
| **J-Cut** | 下一段的声音需要先行铺垫情绪 | 观众不知已进下一场 |
| **叠化** | 时间跳跃/空间跳跃/抒情过渡 | 柔和过渡 |
| **黑屏** | 情感重击/章节分隔/留呼吸口 | 让观众消化 |

## 8.2 决策矩阵

```
同一空间 + 连续时间 → 硬切
声音需要先入 → J-Cut
跳时间/跳空间 → 叠化
情感需要重击 → 黑屏
```

## 8.3 做法（AI生成时不需要，剪映后期处理）

AI生成的视频片段之间，转场由兄弟在剪映里加。提示词里不需要写转场——但**我需要知道每段之间用什么**，因为影响前一段结尾和后一段开头的画面设计。

# 9. 音效设计节奏模板

> 不依赖剧本。按节奏类型套用。

## 9.1 三层音效结构

| 层 | 内容 | 密度 |
|----|------|------|
| 环境音 | 空间基础声（2-3层叠加） | 贯穿全片 |
| 拟音 | 画面内物件声音 | 关键节点 |
| 静默 | 完全无声 | 转折点 |

## 9.2 标准节奏曲线

```
开头（中密度）：环境音2-3层+旁白
发展（高密度）：环境音+拟音+对白
高潮前（极低/零）：静默+心跳
高潮（极高）：全层叠加
结尾（递减→零）：单一声音→静默
```

## 9.3 环境音类型库

| 空间 | 环境音 |
|------|--------|
| 室内夜间 | 风扇/钟表/夜虫/远处电视 |
| 室外货场 | 风声/货船汽笛/远处狗叫 |
| 楼道 | 回声/脚步/远处说话 |
| 礼堂 | 空调/座椅响声/布幕摩擦 |

# 10. LibTV CLI 通用工作流

> 换项目只换参数和资产。

## 10.1 标准流程

```bash
# 1. 创建
libtv project create "项目名"
libtv project use <uuid>

# 2. 上传资产
libtv upload "角色名" --resource "本地路径"
libtv upload "场景名" --resource "本地路径"

# 3. 创建节点
libtv node create "镜名" -t video \
  -s model="Seedance 2.0 VIP" \
  -s modeType="image2video" \
  -s resolution="480p" \
  -s duration=<秒> \
  --prompt "[见第3章模板填]" \
  --left-add <角色ID> --left-add <场景ID>

# 4. 运行（先跑一镜验证）
libtv node <id> --run

# 5. 批量运行
# 逐个或分批跑，每次跑完检查
```

## 10.2 关键参数速查

| 参数 | 可选值 | 默认 |
|------|--------|------|
| model | "Seedance 2.0 VIP" / "Kling O3" | — |
| modeType | "text2video" / "image2video" | 连了图=自动 |
| resolution | "480p" / "720p" / "1080p" / "4k" | "720p" |
| duration | 4-15 | 5 |
| ratio | "16:9" / "9:16" / "1:1" / "4:3" | "16:9" |
| enableSound | "on" / "off" | "on" |

## 10.3 踩过的坑

| 坑 | 表现 | 解法 |
|----|------|------|
| model key≠name | `star-video2` 报错 | 用 `"Seedance 2.0 VIP"` |
| 中文台词引号 | PowerShell解析乱码 | Python `subprocess` 传参 |
| 连了图切模式 | text2video报错 | 先 `--left-rm` 断开 |
| 超时 | `--run` 卡住 | 加 `timeout=300` |

## 10.4 CLI不支持的功能

- TTS → Seedance自带音画同步替代
- 图片精修 → Web UI手动
- AI音乐 → Web UI或剪映后期
- 视频超分 → Web UI一键高清

# 15. 角色一致性保障机制

> 跨镜头同角色 = AIGC短剧最大痛点。17镜翻车中阿强多次变色变衣。

## 15.1 双输入图法（238项目验证的标准方案）

```
第1张图 → 锁人脸/妆容/衣着（角色资产图）
第2张图 → 锁场景/光线/气氛（场景资产图）
显式禁止 → AI继承第1张的动作和构图到第2张
```

**LibTV CLI 实现**：
```bash
libtv node create "镜名" -t video \
  -s model="Seedance 2.0 VIP" \
  -s modeType="image2video" \
  --left-add <角色资产ID> --left-add <场景资产ID>
```

**提示词中额外锁定**：在prompt中重复角色的具体外貌——"@阿强，灰绿色旧夹克，灰色T恤，胡茬黑眼圈"

## 15.2 跨镜头一致性清单

- [ ] 同一角色在所有镜头的提示词中，外貌描述一致（衣着/发型/体型）
- [ ] 使用同一张角色资产图作为所有该角色镜头的第一输入
- [ ] 双输入时显式禁止AI继承参考图的动作
- [ ] 跑完所有该角色镜头后，逐镜对比角色外貌

## 15.3 常见翻车与修复

| 翻车 | 原因 | 修复 |
|------|------|------|
| 衣服颜色变了 | 提示词中没写明衣着 | 每镜提示词加衣着描述 |
| 脸型变了 | 角色资产图权重不够 | 双输入把角色图放第一 |
| 同一场景两个角色变成同龄人 | 没写年龄和外貌差异 | 每镜明确写年龄+外貌特征 |

# 16. 负面提示词通用体系

> 不同风格/题材需要不同的负面词库。不是一套通用负面打天下。

## 16.1 按题材选负面词库

### 现实主义暗调（如《<PROJECT_CASE>》）

```
禁止：sunlight, daylight, bright, warm colors, vibrant, saturated,
      clean, polished, smooth, perfect skin, plastic, CGI, 3D render,
      cartoon, anime, illustration, smiling, cheerful,
      eye contact, looking at camera, sharp focus on eyes
```

### 古风/国风

```
禁止：modern clothing, modern architecture, cars, smartphones,
      neon lights, western buildings, English text, plastic,
      CGI smoothness, overly saturated, cartoon
```

### 赛博朋克/科幻

```
禁止：natural sunlight, warm colors, rustic, vintage, medieval,
      daytime countryside, organic materials, handmade, cartoon
```

### 文艺清新

```
禁止：dark shadows, gritty, dirty, grunge, horror, gore,
      high contrast, harsh light, industrial, urban decay
```

## 16.2 全风格通用负面（每镜都加）

```
blur, blurry, motion blur, out of focus, distorted face,
deformed hands, extra fingers, fused fingers, missing fingers,
bad anatomy, bad proportions, ugly, disfigured,
watermark, text, signature, logo, low quality, jpeg artifacts
```

## 16.3 使用方式

在每镜提示词末尾追加：
```
不要生成台词字幕 不要BGM 生成环境音和台词配音 同期声
[通用负面] [题材专属负面]
```
