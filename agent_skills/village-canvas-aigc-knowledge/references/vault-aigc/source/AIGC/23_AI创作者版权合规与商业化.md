## 三、10 条变现铁律

1. **前三秒就是一切** — TikTok 3秒判生死，YouTube 看点击率
2. **必须披露** — 2026年不披露 AI → 惩罚，主动披露不影响推荐
3. **一条视频喂三个平台** — 20分钟长视频 → 5条 TikTok + 4条 Reel + 1条 Short
4. **选对赛道** — 金融/科技/健康 RPM 是娱乐的 5-10 倍
5. **声音质量第一** — 平板机器人旁白 = 低质量信号
6. **有故事，不只靠画面** — 三幕结构：钩子3秒 → 发展中段 → 收尾
7. **做本地化** — 多语言字幕是低竞争但高回报的蓝海
8. **稳定 > 爆发** — 每周 3 条 > 爆发 20 条然后沉默
9. **从第一天就多条腿走路** — AdSense + 联盟 + 品牌合作 + 会员
10. **绝对不要 AI 垃圾** — 2026年的 YPP 严查"原创性"

## 四、版权核心原则

### EU AI Act 2026 状态

- 欧盟27国直接适用，无需各国转立法
- AI 生成物不含人类创作 → 不应享有版权
- 训练数据使用是否需要授权仍在讨论中

### 实际创作建议

| 维度 | 建议 |
|------|------|
| 用真实演员长相 | 不可以用，这是肖像权问题 |
| 用有版权的角色 | 不可以用，迪士尼会告到你破产 |
| 用自己的提示词 | ✅ 完全属实，提示词是你自己的创作 |
| 用自己的参考图 | ✅ 更稳固，有人的参与度 |
| 用真人导演笔记 | ✅ 最稳，版权归属靠"人的创作性投入" |
| 后期剪辑调整 | ✅ 每步增加版权确定性 |

### 核心判定标准

AI 生成内容的版权保护依赖于**人类创作贡献的程度**：
- 纯提示词生成 → 版权不确定
- 自写剧本 + 自己定妆照 + 自己选帧 + 自己剪辑调色 + 自己配音 → 版权稳固
- 原创故事 + 90% 以上画面经过人工选择/修改 → 版权明确
