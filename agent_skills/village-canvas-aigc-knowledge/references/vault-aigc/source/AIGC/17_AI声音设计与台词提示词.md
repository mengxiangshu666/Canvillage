# 17_AI声音设计与台词提示词体系 v1.0

> 来源交叉验证：Cutout.pro Seedance Audio Guide (2026-04) + Kling 3.0 Prompt Guide (2026-03) + Community testing
> 浏览器的声音与画面是统一生成的，不是后期贴上去的。
> 台词提示词写对了，声音才能清晰、完整、有情感。

---

## 核心概念

AI 视频模型（Seedance 2.0、Kling 3.0、Wan 2.6/2.7）的声音不是后期合成的——它们是 **统一多模态音视频联合生成架构**。声音和画面在同一推理过程中生成，意味着：

- 你说什么 = 画面 + 声音一起决定
- 你不说声音 = 模型自己猜
- 你说错了 = 音画不一致

---

## 一、Seedance 2.0 声音系统（三层架构）

ByteDance 的 Seedance 2.0 采用三层音频结构，每层可以独立控制。

### 1.1 三层总览

| 层 | 功能 | 怎么写提示词 |
|----|------|-------------|
| **Dialogue** | 对白 + 自动口型同步 | `Character speaks in Mandarin: "今天天气真好。"` |
| **SFX** | 事件音效 | `SFX: thunder crack at 3s` |
| **BGM** | 背景音乐 | `BGM: lo-fi ambient piano, slow around 70 BPM` |

### 1.2 Dialogue（对白）铁律

**1. 语言标签语法**
```
Character speaks in Japanese: "今日は天気がいいですね。"
Character says in English: "I can't believe this is happening."
人物用中文说："你走吧，别回头。"
```

模型根据语言标签 + 文本内容自动映射音素到嘴型。

**2. 短句原则——5-10 词/句**
- 长句子 → 口型糊（8 秒后尤其明显）
- 复杂绕口令 → 口型崩
- 长对白 → 拆成多段拼接

**3. 节奏控制**
```
"Brief pause at 2s, then continues with urgency."
"Silence for 1 second, then whispering."
```

说话速度写 80% 自然语速最好。留空让口型引擎有空间。

**4. 不要写头部动作**
- ❌ "Nodding while saying 'yes'"
- ❌ "Turning head to look"
- ✅ 锁住镜头，让角色说话时头部微动即可
- 头部动作会和口型引擎争夺注意力，产生半吊子的不自然动作

**5. 景别要求**
- 最佳：中近景 + 锁住镜头
- 可用：正面 / 微侧（three-quarter）
- 不可用：远景（人脸分辨率不够）、侧脸（口型不准）

### 1.3 SFX（音效）

**描述音源 + 材质**
```
"Boots on wet cobblestone"        → 沉重、潮湿的脚步声
"Sneakers on hardwood"              → 轻快、空旷的脚步声
"Paper crumpling slowly"            → 纸张揉皱
"Sword being drawn from scabbard"   → 金属摩擦
```

**时间锚定**
```
"SFX: thunder crack at 3s. Lightning illuminates the scene at the thunder crack."
"Sound: rain bed + distant train hum. SFX: chess piece click at 2s."
```

- 2-3 层音效混合最多
- 超过 3 层会浑浊，建议在后期加

### 1.4 BGM（背景音乐）

**风格 + 情绪 + 速度**
```
"lo-fi ambient piano"
"tense orchestral build"
"upbeat indie folk"
"melancholic and sparse"
"slow, around 70 BPM"          (BPM 是参考值，不是精确锁定)
```

**淡入淡出**
```
"Music: low piano note enters at 3s, resolves on last frame."
"Silence holds final 0.5s."     ← 防止音频突兀截断
```

**混音优先级（重要！）**
```
"Dialogue clean and prominent, music low, ambient subtle."
"Music leads, ambient secondary, no dialogue."    ← 无对白场景
```

不写优先级 → 三层以相似音量对抗 → 对白模糊。

### 1.5 口型同步优化

| 因素 | 最佳 | 注意 |
|------|------|------|
| 镜头距离 | 中近景 | 远景/特写都不行 |
| 面部角度 | 正面/微侧 | 侧脸不稳定 |
| 句子长度 | 5-10 词 | 太长 → 口型糊 |
| 参考人像 | 高清、正面、无遮挡 | 模糊或遮挡 → 口型不准 |
| 背景 | 去背景（透明 PNG 最好） | 杂乱背景干扰人脸建模 |
| 语言 | 中文 > 英文 > 日韩 | 中文最准（训练数据偏重） |

**定妆照链接口型质量**：这是很多人不知道的。Seedance 2.0 用参考人像建模嘴型。一张模糊的、部分遮挡的人脸 → 口型近似。一张高清、正面、去背景的人像 → 口型精确。07 号定妆法的"纯白试探→浅灰#E8E8E8设定表"流程，不仅影响画面一致性，也影响声音。

## 二、Kling 3.0 声音系统

Kling 3.0 的音频系统与 Seedance 类似，但有不同侧重点。

### 2.1 对话和音频元素

```
"Female voice, mid-range pitch, speaking with warm enthusiasm,
with subtle urban ambient sound in background."
```

写法要点：
- 先描述声音特质（性别、音高、情感）
- 再描述环境音
- 示例中包含了"mid-range pitch"（中音区）这种精确控制

### 2.2 教育/教程场景的台词示例

```
"Female voice narration: 'Fold the corner diagonally to create a triangle,'
warm instructional tone, clear articulation."
```

- 明确标注 "narration"（旁白）
- 台词本身用引号括起来
- 加上语气提示（warm instructional tone, clear articulation）

### 2.3 Kling 3.0 Omni 模式

Kling 3.0 的 Omni 模式统一了：
- 角色一致性
- 元素参考
- 语音到角色绑定
- 自动口型同步

这意味着你可以创建可复用的**角色语音库**，跨镜头保持音色一致。

### 2.4 Kling 3.0 多机位示例中的音频

```
"Shot 1 (5s): Wide shot, woman in red coat walking through misty forest...
Shot 2 (5s): Medium shot tracking alongside subject...
Shot 3 (5s): Close-up of subject's face as she stops and looks up..."
```

多机位场景下，音频信息可以在多个镜头间延续。如果有对白，建议只在近景镜头加台词（更准确），中远景加环境音。

## 三、Suno AI 配乐提示词体系

Suno 是独立的声音/歌曲生成工具，不是视频内生的音频。用于后期配乐。

### 3.1 有效提示词的 4 要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **Mood & Emotion** | 情绪状态 | `"nostalgic" "energizing" "melancholic"` |
| **Instrumentation** | 乐器 | `"acoustic guitars" "orchestral strings" "analog synths"` |
| **Tempo & Groove** | 速度和律动 | `"slow ambient" "fast techno" "90 BPM"` |
| **Environment/Purpose** | 使用场景 | `"podcast intro" "game soundtrack" "cinematic"` |

### 3.2 常用提示词模板

**电影级配乐**
```
Cinematic orchestral, hopeful, 90 BPM, strings and piano, no vocals
Tense orchestral build, dark, suspenseful, brass and percussion
Melancholic piano solo, slow, minimal, ethereal
```

**背景音乐**
```
Lo-fi chillhop, soft drums, vinyl crackle, warm Rhodes chords
Ambient electronic, evolving textures, minimal percussion, meditative
Upbeat indie folk, acoustic guitar, light percussion, warm
```

**音效**
```
"Music that feels like drifting over city lights"    ← 通过意象表达
"Vintage synth like early 80s pop"                   ← 通过类比表达
```

## 四、AI 视频全链路声音控制总结

### 4.1 三层音轨混合策略

```
Video 画面层 (AI生成)
  ├── Dialogue 对白层 —— 台词提示词控制，含口型同步
  ├── SFX 音效层 ———— 事件音效，时间锚定
  └── BGM 背景层 ———— 可 AI 生成（Suno/Udio）后后期合成
```

### 4.2 推荐工作流

1. **视频生成时**：让 AI（Seedance/Kling）自带原生对白 + SFX
2. **后期处理**：
   - 保留 Seedance 的 SFX 和 BGM（时间锚准）
   - 替换 AI 对白为录制配音（如果需要更高精度）
   - 用 Suno/Udio 生成 BGM 添加
3. **混音控制**：
   - 如果一层不够清晰 → 加 `"Dialogue clean and prominent"` 优先级提示
   - 如果混音太满 → 减到 2 层，在后期加第三层

### 4.3 铁律

1. **台词提示词 > 画面提示词** —— 声音是理解叙事的第一通道，糊了对白整个短片就完了
2. **短句 > 长句** —— 5-10 词每句，做不到就拆多段
3. **近景锁定 > 远景对白** —— 远景不配说台词
4. **先写优先级 > 不写** —— 不然三层打架，对白被淹没
5. **定妆照质量 = 口型质量** —— 07 号5步法不仅管画面，也管声音
6. **文字永远后期合成** —— 任何 AI 视频都不生成字幕/文字，必加 `--no subtitle text`
