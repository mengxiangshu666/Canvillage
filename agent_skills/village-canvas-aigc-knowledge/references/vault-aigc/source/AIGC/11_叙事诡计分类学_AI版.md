## 第 1 章：叙事诡计总纲

### 1.1 什么是叙事诡计

**定义**：通过操控信息呈现的方式，让观众产生特定的认知偏差，最终在揭示时刻获得"原来如此"的震撼。

**核心公式（来自 04 号文件）**：
```
90% 铺垫：让观众以为这是 A
10% 揭示：原来是 B（颠覆观众认知）
```

### 1.2 诡计的 4 层深度

| 层次 | 诡计深度 | 观众反应 | 代表 |
|------|---------|---------|------|
| **L1 信息隐瞒** | 导演瞒着观众 | "哇，原来是这样" | 《第六感》 |
| **L2 视角欺骗** | 通过角色视角骗观众 | "这个叙述者在骗我" | 《搏击俱乐部》 |
| **L3 结构颠覆** | 打乱时间/因果本身 | "我连时间线都搞错了" | 《记忆碎片》 |
| **L4 元叙事** | 让观众意识到自己在被操控 | "这个故事在玩弄我" | 《趣味游戏》 |

## 第 2 章：9 大类叙事诡计

### 类型 1：不可靠叙述者（Unreliable Narrator）

**定义**：叙述者提供的信息不完全可信。观众必须在观看过程中自行判断真相。

**5 种亚型**：

| 亚型 | 机制 | 经典案例 | AIGC 适用 |
|------|------|---------|----------|
| **天真型**（Naive）| 叙述者不理解自己看到的事 | 《房间》（5岁男孩视角）| ✅ 短片佳 |
| **疯狂型**（Madman）| 叙述者精神异常，分不清现实 | 《搏击俱乐部》《黑天鹅》| ⚠️ 需视觉区分 |
| **说谎型**（Liar）| 叙述者故意撒谎 | 《非常嫌疑犯》《消失的爱人》| ✅ |
| **失忆型**（Amnesiac）| 叙述者记忆受损 | 《记忆碎片》| ✅ 非线性必须 |
| **傲慢型**（Pompous）| 叙述者自以为是，扭曲事实 | 《美国精神病人》| ✅ |

**AIGC 执行方案**：
- 用视觉对比（暖/冷色调）区分"叙述者说的"和"真实发生的"
- 用画幅比切换（如 2.35:1 → 1.33:1）标记视角切换
- 关键揭示：最后 10% 时长给出"真相版"画面

### 类型 2：非线性叙事（Non-Linear Narrative）

**定义**：不按时间顺序讲述事件。

**6 种亚型**：

| 亚型 | 机制 | 经典案例 |
|------|------|---------|
| **倒叙框架** | 结局→回溯→回到结局 | 《公民凯恩》《日落大道》 |
| **双线交织** | 两条时间线交替推进 | 《教父 2》《敦刻尔克》 |
| **反向叙事** | 从结局往前推 | 《记忆碎片》（全反）|
| **环形叙事** | 结尾回到开头 | 《低俗小说》《暴雨将至》 |
| **碎片/拼图** | 多个碎片事件非时序排列 | 《21 克》《巴别塔》 |
| **分叉叙事** | 同一事件的不同可能性 | 《罗拉快跑》《滑动门》 |

**AIGC 执行方案**：
- 用颜色/滤镜区分时间线（暖=过去，冷=现在，或反之）
- 用画面边缘效果（暗角=过去，全亮=现在）
- 每个时间线只用 1-2 个场景，降低制作复杂度

### 类型 3：视角反转（Perspective Reversal）

**定义**：观众以为自己理解的故事，在揭示后发现完全是另一回事。

**4 种亚型**：

| 亚型 | 机制 | 经典案例 |
|------|------|---------|
| **好人=坏人** | 主角/盟友实为反派 | 《非常嫌疑犯》《禁闭岛》 |
| **坏人=好人** | 反派实为保护者 | 《终结者 2》T-800 |
| **现实=幻觉** | 全部或部分为幻觉/模拟 | 《黑客帝国》《异次元骇客》 |
| **受害者=施害者** | 受害者其实是加害者 | 《囚徒》《老男孩》 |

**AIGC 执行方案**：
- 在前 90% 不给任何视觉暗示（这是关键——不能"剧透"）
- 在最后 10% 用 1-2 个闪回画面揭示真相
- 用镜面/反射作为视觉母题（暗示"看到的不是真实的"）

### 类型 4：信息差（Dramatic Irony / Information Asymmetry）

**定义**：观众知道但角色不知道（或反之）。

**3 种亚型**：

| 亚型 | 机制 | 经典案例 |
|------|------|---------|
| **观众知道** | 观众比角色多知道 | 希区柯克的"桌子下的炸弹" |
| **角色知道** | 某个角色知道但其他人不知 | 《无间道》卧底 |
| **无人全知** | 所有人都是盲人摸象 | 《罗生门》 |

### 类型 5：红鲱鱼（Red Herring）

**定义**：故意设置的误导线索，将观众注意力引向错误方向。

**AIGC 执行方案**：
- 用构图权重（大特写）放大误导物件
- 用慢镜头/音乐重音强调误导线索
- 真正的线索藏在画面边缘或焦点外

**经典案例**：《灵异第六感》（红=Trouble），《精神病患者》（Marion 的钱）

### 类型 6：麦高芬（MacGuffin）

**定义**：推动情节但本身不重要的物件/目标。

**经典案例**：《低俗小说》的手提箱、《公民凯恩》的"玫瑰花蕾"

**AIGC 应用**：短片非常适合——用一个具体物件串联 5 段结构。

### 类型 7：元叙事（Meta-Narrative）

**定义**：故事意识到自己是故事。打破第四面墙。

**3 种亚型**：

| 亚型 | 机制 | 经典案例 |
|------|------|---------|
| **直接对话** | 角色对观众说话 | 《纸牌屋》《死侍》 |
| **嵌套结构** | 故事中的故事 | 《盗梦空间》《改编剧本》 |
| **形式自反** | 通过形式本身揭示"这是虚构" | 《趣味游戏》（倒带杀人） |

### 类型 8：时间诡计（Temporal Trick）

**定义**：操控时间流速或方向。

| 亚型 | 机制 | 经典案例 |
|------|------|---------|
| **慢镜头揭示** | 关键时刻放慢 | 《黑客帝国》子弹时间 |
| **快镜头压缩** | 加速表现过程 | 《梦之安魂曲》嗑药蒙太奇 |
| **时间循环** | 同一天不断重复 | 《土拨鼠之日》《明日边缘》 |
| **冻结时间** | 时间停止 | 《X 战警》快银场景 |

### 类型 9：沉默揭示（Silent Revelation）

**定义**：不用台词，纯画面揭示真相。**AIGC 短片的最优选择**。

**核心技巧**：
- 一个物件 = 揭示一切（照片、纸条、伤疤）
- 一个表情变化 = 角色领悟
- 一个镜头运动 = 观众的认知升级（如推镜头揭示细节）

**经典案例**：《老无所依》硬币、《肖申克》海报后的洞

## 第 3 章：诡计组合矩阵

**高级叙事 = 2-3 种诡计叠加**。

| 组合 | 经典案例 | 效果 |
|------|---------|------|
| 非线性 + 不可靠叙述者 | 《记忆碎片》 | 观众连时间线都拼不出真相 |
| 视角反转 + 信息差 | 《禁闭岛》 | 知道主角有问题，但不知道问题多大 |
| 红鲱鱼 + 沉默揭示 | 《灵异第六感》 | 红色误导 90 分钟，5 秒揭示 |
| 元叙事 + 时间诡计 | 《趣味游戏》 | 用倒带告诉你"你的期待是虚构的" |
| 非线性 + 视角反转 | 《低俗小说》 | 死了的角色又活了（因为时间线不同） |

## 第 4 章：AIGC 短片诡计速查

**按短片时长（6-12 分钟）推荐诡计**：

| 时长 | 推荐诡计 | 为什么不推荐 |
|------|---------|------------|
| **1-3 分钟** | 沉默揭示 > 视角反转 | 非线性太复杂，来不及建立 |
| **4-6 分钟** | 视角反转 > 沉默揭示 > 红鲱鱼 | 不可靠叙述者需要更多铺垫 |
| **7-12 分钟** | 所有诡计可用 | 足够时间建立 + 揭示 |

**按视觉风格推荐**：

| 视觉风格 | 最配诡计 | 原因 |
|---------|---------|------|
| 极简主义 | 沉默揭示 | 用少量元素揭示 = 极简的终极形态 |
| 电影感纪实 | 不可靠叙述者 | 真实感增强欺骗性 |
| 赛博朋克 | 视角反转 + 现实=幻觉 | 科技模糊真实 |
| 表现主义 | 疯狂型不可靠叙述者 | 扭曲视觉 = 扭曲心智 |
| 动画/实验 | 元叙事 | 动画可以打破任何规则 |

## 第 5 章：5 段结构 × 诡计植入

**把诡计嵌入 04 号文件的 5 段结构**：

| 段 | 诡计植入点 |
|----|-----------|
| **段 1 建立**（15%）| 铺设假前提。给观众一个"看起来很合理"的世界 |
| **段 2 升级**（20%）| 埋第一道裂痕。1 个细节让细心的观众开始怀疑 |
| **段 3 觉醒**（20%）| 埋第二道裂痕。不可忽视的矛盾出现 |
| **段 4 抉择**（25%）| 揭示前夜的紧张。观众在"旧理解"和"新怀疑"间摇摆 |
| **段 5 回归**（20%）| **10% 揭示**。真相砸下来。用最少的话（或无话）收束 |

## 第 6 章：叙事诡计 AIGC 提示词速查

```yaml
narrative_tricks_aigc:

  unreliable_narrator:
    visual_markers: "dual color palette, warm=memory cold=reality"
    reveal_shot: "single flash frame of true events, jarring contrast"
    prompt_keywords: "unreliable POV, subjective camera, fragmented memory"

  nonlinear:
    visual_markers: "color grade shift per timeline, aspect ratio switch"
    prompt_keywords: "non-linear timeline, events out of sequence"

  perspective_reversal:
    setup: "establish comfortable understanding"
    reveal: "single image/detail that inverts everything"
    prompt_keywords: "hidden truth revealed, perception shattered"

  dramatic_irony:
    prompt_keywords: "audience knows what character doesn't"
    visual: "split screen or foreground/background information gap"

  red_herring:
    prompt_keywords: "deliberately misleading visual emphasis"
    visual: "extreme close-up on irrelevant object, true clue at frame edge"

  silent_revelation:
    prompt_keywords: "wordless revelation, visual epiphany"
    visual: "slow push-in on key object, character's micro-expression shift"
```

## 第 7 章：诡计失败检查清单

```
□ 揭示是否太早了？（观众在段 3 就猜到了 = 失败）
□ 揭示是否太晚了？（最后一秒才给，观众来不及消化 = 失败）
□ 揭示后回看，前 90% 是否每帧都合理？（不合理 = 欺骗感）
□ 诡计是否服务主题？（纯粹炫技 = 空洞）
□ 不用台词能否完成揭示？（不能 = 叙事薄弱）
□ 2-3 种诡计叠加后，是否过于复杂？（6-12 分钟短片最多 2 种）
□ AIGC 执行上，不同时间线/视角的视觉标记是否明显？
```

## 第 8 章：经典诡计案例拆解（AIGC 版）

### 案例 1：《记忆碎片》—— 反向叙事 + 失忆型不可靠叙述者

**诡计**：彩色线倒着走（结局→开头），黑白线正着走。交替推进。

**AIGC 可学**：
- 彩色/黑白区分双线
- 每段结尾 = 上段的开头（反向因果链）

### 案例 2：《灵异第六感》—— 信息差 + 沉默揭示

**诡计**：观众和主角都不知道主角已死。

**AIGC 可学**：
- 90% 时间不给任何"另一个世界"暗示
- 揭示靠 1 个物件（婚戒从妻子手指滑落）+ 闪回

### 案例 3：《搏击俱乐部》—— 疯狂型不可靠叙述者

**诡计**：Tyler Durden 是叙述者的另一个人格。

**AIGC 可学**：
- 在揭示前插入几帧 Tyler 的闪影（阈下信息）
- 揭示后回放几个关键场景的"真相版"
