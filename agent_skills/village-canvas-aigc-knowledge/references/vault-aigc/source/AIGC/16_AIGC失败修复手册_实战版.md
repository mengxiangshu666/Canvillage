## 第 1 章：6 大类失败模式速查

### 1.1 生图失败

| 失败类型 | 现象 | 原因 | 修复方法 | 优先级 |
|---------|------|------|---------|--------|
| **脸崩** | 面部不对称/五官错位/多只眼 | 模型对多人脸分布不敏感 | 1) Adetailer插件修复 2) 减小人物数量 3) 加"detailed beautiful face, symmetrical" | 🔴 最高 |
| **手崩** | 6指/手指数不对/手部模糊 | 手部训练数据不足 | 1) 手部重绘 2) 加"perfect hands, detailed fingers" 3) 降低denoising strength | 🔴 最高 |
| **文字崩** | 文字乱码/拼写错误 | 扩散模型文字生成弱 | 1) 换Lib Navo 2 2) 去掉文字需求(后期PS加) 3) 加"clear legible text" | 🟡 中 |
| **姿势崩** | 人物扭曲/不自然 | 构图/姿势描述不精确 | 1) 明确pose描述 2) 用ControlNet骨骼 3) 降低cfg scale | 🟡 中 |
| **场景飘** | 背景不符/物体错位 | 多元素注意力稀释 | 1) 减少场景元素 2) 用权重语法 (element:1.3) 3) 拆成多图合成 | 🟢 低 |
| **风格错** | 风格不匹配 | 风格词权重不够 | 1) 重复风格词 2) 加--no排斥错误风格 3) 换模型 | 🟢 低 |

### 1.2 生视频失败

| 失败类型 | 现象 | 原因 | 修复方法 | 优先级 |
|---------|------|------|---------|--------|
| **身份丢失** | 角色脸变/脸崩/换人了 | 跨帧注意力不一致 | 1) 用强身份保持模型(可灵O3) 2) 降低动态程度 3) MagicID双路径技术 | 🔴 最高 |
| **运动崩** | 人物抖动/变形/闪烁 | 时间一致性不足 | 1) 减慢运动 2) 固定摄像机 3) 降低resolution | 🔴 最高 |
| **手崩** | 视频手部变形 | 视频模型手部训练更少 | 1) 藏手(写"hands in pockets/natural") 2) 使用Seedance静态手 | 🔴 最高 |
| **环境漂移** | 背景变形/闪烁 | 长视频时间一致性难 | 1) 缩短视频时长 2) 使用reference image锁定 3) 加cameraFixed | 🟡 中 |
| **文字错** | 视频中文字乱码 | 视频扩散模型无文字能力 | 1) --no subtitle text 2) 绝不靠AI生成文字 3) 后期合成 | 🟡 中 |
| **角色僵硬** | 人物不动/木偶感 | 运动参数过弱 | 1) 增强运动描述 2) 换可灵O3真人感 3) 加"natural body language, subtle micro-movements" | 🟢 低 |
| **面部表情死** | 表情单一/不自然 | 微表情生成困难 | 1) 加表情描述"subtle smile/anxious/fatigue" 2) 换可灵O3 3) 缩短镜头重新拍 | 🟢 低 |
| **多角色混淆** | 多人物融合/交换 | 身份区分度低 | 1) 限制人数 2) 加区分描述(different clothing/height/age) 3) 分镜分开拍 | 🟢 低 |

## 第 2 章：失败修复流程（3步法）

### 流程 1：1次微调（调1-2个词）

**什么时候用**：失败程度轻微（30%以下的异常）

```
步骤：
1. 不改提示词主体
2. 只调最相关的1-2个词
3. 重新生成

示例：
原prompt: "a man sitting at desk, modern office, 50mm, medium shot"
脸崩→ 加 "detailed symmetrical face, natural expression"
手崩→ 改 "hands resting on desk naturally" → "hands in pockets"
```

**关键**：不重写整个提示词。只精准改最可能失败的词。

### 流程 2：换参考图（换视觉输入）

**什么时候用**：微调后仍然失败

```
步骤：
1. 换一张更清晰/更准确的参考图
2. 保持提示词不变
3. 重新生成

如果是image2image: 换输入图
如果是text2video: 添加参考图驱动
如果是Seedance: 换@Image引用的资产图
```

**关键**：参考图是"锚点"。好的参考图=好的结果。

### 流程 3：换模型（换底层能力）

**什么时候用**：换参考图后仍然失败

```
步骤：
1. 分析失败类型对应哪个模型的弱点
2. 选一个在这个弱点上更强的模型
3. 换模型重新生成

示例：
- 脸崩 → 可灵O3（真人感+多机位） > Seedance Mini
- 文字 → Lib Navo 2（文字准确之王） > 其他模型
- 电影感 → 悠船 V8.1（电影感场景） > Lib Image
- 多机位 → Wan 2.6（多机位15s） > 其他模型
```

**关键**：不重写提示词。只换模型。如果3步都不行，才考虑重写。

## 第 3 章：8个最常见的AI视频广告错误及修复

> 来源：ShortGenius 2025 + 兄弟实操

| 错误 | 现象 | 修复 |
|------|------|------|
| **1. 过度依赖AI生成面部** | 脸崩/不真实/Deepfake感 | 1) 多用远景/背影 2) 加面部细节描述 3) 用真人感模型 |
| **2. 忽略品牌一致性** | 风格跳跃/不统一 | 1) 锁定一个风格 2) 使用STYLE LOCK 3) 统一色调和字体 |
| **3. 节奏不当** | 太慢/太快/注意力丢失 | 1) 前3秒必须抓眼球 2) 每4秒换一个视觉元素 3) 控制视频时长≤15s |
| **4. 忽略声音设计** | 无声/配音尴尬/声音与画面不匹配 | 1) 原生音效优先 2) 音效与画面同步 3) 启用enableSound |
| **5. 文字合成缺陷** | 文字乱码/位置错 | 1) NO AI文字 2) 后期PS/Premiere合成 3) --no subtitle text |
| **6. 运动过度** | 人物抖动/变形 | 1) 减慢运动速度 2) 固定摄像机 3) 减少运动描述词 |
| **7. 背景失真** | 环境变形/闪烁 | 1) 减少场景复杂度 2) 锁定参考背景 3) 缩短视频 |
| **8. 后期过度处理** | 生硬/丢失AI原生感 | 1) 保留AI的"不完美"纹理 2) 不过度锐化 3) 保留画面的有机感 |

## 第 4 章：Adetailer 脸部修复方法

> 来源：知乎/YouTube Stable Diffusion教程 + 浙大MagicID论文2025

### Adetailer（最强脸部修复插件）

```
用途：自动检测人脸 → 放大 → 重新inpaint → 降噪 → 融合
步骤：
1. 安装Adetailer插件（https://github.com/Bing-su/adetailer）
2. 勾选"Enable Face Restoration"
3. 选择模型：face_yolov8n.pt（检测）/ bd_face_model（修复）
4. 调整参数：
   - Denoising strength: 0.3-0.5（太高变形，太低没效果）
   - Inpaint area: "Only masked"（只修复脸部区域）
   - Mask blur: 4（边缘过渡）
5. 生成 → Adetailer自动修复 → 输出
```

### MagicID（浙大最新技术）

```
来源：浙江大学 & Hedra AI, 2025年12月
方法：双路径身份保持机制
特点：
- 语义解耦：身份特征与运动特征分离
- 身份保持：跨帧面部一致性95%+
- 运动自然：消除角色僵硬
应用场景：需要同一角色出现在多个镜头
```

### 手动修复方案（不用插件）

```
1. 生成多张 → 选一张脸最好的
2. Photoshop：把好脸贴到其他图
3. img2img + 低denoising（0.2-0.3）→ 融合
4. 多次迭代
```

## 第 5 章：手部修复方法

### 方案A：躲手法（最快）

```
- 加 "hands behind back"
- 加 "hands in pockets"
- 加 "hands resting on desk, palms down, fingers hidden"
- 换远景/中景（不要特写手）
```

### 方案B：强化提示词法

```
- 加 "perfect hands, anatomically correct fingers, 5 fingers"
- 加 "detailed knuckles, natural hand gesture"
- 用负向提示：--no deformed hands, extra fingers, fused fingers, missing fingers
```

### 方案C：Inpaint修复法

```
1. Adetailer可以同时修脸和手
2. 单独mask手部 → inpaint → 低denoising
3. 多张生成 → 选一张手最好的 → Photoshop合成
```

### 方案D：ControlNet法

```
1. 准备一张手部骨架图
2. ControlNet + depth/canny/pose
3. 引导模型按骨架生成手部
4. 成功率提升50%+
```

## 第 6 章：跨帧一致性问题（视频专用）

> 这是AIGC视频最大的痛点——模型没有"角色记忆"

### 问题类型

| 问题 | 表现 | 影响 |
|------|------|------|
| **身份漂移** | 同一个人物在不同帧变成不同的人 | 角色无法建立共情 |
| **服装变化** | 衣服颜色/款式在帧间改变 | 观众出戏 |
| **发型变化** | 头发长短/颜色变化 | 角色不一致 |
| **环境漂移** | 背景物体移动/消失/变形 | 空间感崩溃 |
| **光照跳变** | 画面闪烁/亮暗跳变 | 观影体验差 |

### 解决方案

```
优先级1：换模型
- 可灵O3：真人感最强，身份保持较好
- Seedance 2.0 Mini：[STYLE LOCK]可锁定视觉风格
- Wan 2.6：时间一致性较好

优先级2：提示词技巧
- 加 "consistent character appearance throughout"
- 加 "maintaining identical face, clothing, hairstyle"
- 用reference image锁定角色

优先级3：技术方案
- MagicID（浙大+ Hedra AI）：双路径身份保持
- DynamicFace（小红书AIGC团队）：换脸算法
- ControlNet + IP-Adapter：条件引导

优先级4：后期修复
- 逐帧检查 + Photoshop修关键帧
- Topaz Video AI去闪烁
- Runway ML逐帧修复
```

## 第 7 章：修复决策树（速查版）

```
START: 生成失败了
│
├─ 脸崩了？
│   ├─ 轻微(30%以下) → 加面部描述词 → 重生成
│   ├─ 中度(30-60%) → 换参考图 → 重生成
│   └─ 严重(60%+) → 换可灵O3 → 重生成
│
├─ 手崩了？
│   ├─ 可接受 → 用前景遮挡法重写提示词
│   ├─ 必须出场 → 加手部强化词 → 重生成
│   └─ 特写 → Inpaint修复 → 再生成
│
├─ 文字错了？
│   ├─ 需要文字 → 换Lib Navo 2 → 重生成
│   └─ 不需要 → 去掉文字描述 → 后期PS加
│
├─ 环境漂移了？
│   ├─ 视频 → 缩短时长/加cameraFixed/换Wan 2.6
│   └─ 图片 → 减少场景元素 → 重生成
│
├─ 风格不对？
│   ├─ 30%偏差 → 加强风格词权重 → 重生成
│   └─ 80%偏差 → 换模型 → 重生成
│
└─ 角色不一致？
    ├─ 多人 → 限制人数/分开拍
    └─ 单人 → 换可灵O3/加IP-Adapter → 重生成
```

## 第 8 章：预防失败的最佳实践

### 生图前检查清单

```
□ 1. 模型选择正确？（真人→可灵O3, 电影感→悠船V8.1, 文字→Lib Navo 2）
□ 2. 提示词有--no排除？（--no deformed hands, extra fingers, text, watermark）
□ 3. 场景元素不超过5个？（太多会稀释注意力）
□ 4. 人物数量不超过2个？（多人脸崩率×3）
□ 5. 手部有特殊处理？（躲手/强化描述/后期修复）
□ 6. 参考图清晰/准确？
□ 7. 分辨率匹配？（高分辨率→高细节可能带来更多崩坏）
```

### 生视频前检查清单

```
□ 1. 视频时长合理？（短线≤10s崩坏率低）
□ 2. 运动强度适中？（高速运动＞低速运动的崩坏率）
□ 3. 使用了reference image？（无参考图的identity难保持一致）
□ 4. 提示词≤40词？（超过40词注意力稀释严重）
□ 5. --no包含文字/水印？
□ 6. 模型支持当前的分辨率/比例？
□ 7. 声音设计合理？（需要声音→enableSound on）
```
