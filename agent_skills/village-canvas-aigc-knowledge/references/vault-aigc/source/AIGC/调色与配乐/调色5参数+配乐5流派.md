# #9 调色

## 一、调色 3 大体系

### 体系 1：LUT (Look Up Table)
- **核心**：预设色彩转换
- **实战**：电影 LUT (Kodak / Fuji)
- **占比**：40%

### 体系 2：节点调色 (Node-based)
- **核心**：DaVinci Resolve 节点调色
- **实战**：每个镜头单独调色
- **占比**：50%

### 体系 3：AI 自动调色
- **核心**：ML 算法自动调色
- **实战**：自动 LUT 应用
- **占比**：10%

**实战：节点调色 = 50% = 主流**

## 五、调色 5 大流程

### 流程 1：基础校色 (Primary)
1. 曝光 (Exposure)
2. 白平衡 (White Balance)
3. 对比度 (Contrast)
4. 饱和度 (Saturation)
5. 色调 (Tint)

### 流程 2：二级校色 (Secondary)
1. 选区 (Qualifier)
2. 隔离肤色 (Skin Tone)
3. 隔离天空 (Sky)
4. 隔离主体 (Subject)

### 流程 3：LUT 应用
1. 选择 LUT
2. 强度调整 (Intensity)
3. 节点叠加

### 流程 4：风格化
1. 色彩分级 (Color Grade)
2. 调性统一 (Look)
3. 情感调整

### 流程 5：一致性
1. 多镜头统一
2. 多场景统一
3. 全片一致

# #10 配乐

## 一、配乐 3 大体系

### 体系 1：原创音乐 (Original Score)
- **核心**：作曲家原创
- **实战**：电影配乐
- **占比**：70%

### 体系 2：现有音乐 (Existing Music)
- **核心**：使用版权音乐
- **实战**：商业广告
- **占比**：20%

### 体系 3：AI 生成音乐 (AI Music)
- **核心**：AI 生成音乐
- **实战**：短剧 / 短视频
- **占比**：10%

**实战：禁毒微短剧 = AI 生成音乐 / 禁用 BGM**

---

## 二、配乐 4 大类型

### 类型 1：主题音乐 (Theme Music)
- **特征**：电影主题
- **实战**：每个电影有 1 个主题
- **药神实战**：《只要平凡》

### 类型 2：场景音乐 (Scene Music)
- **特征**：特定场景
- **实战**：每个场景单独
- **药神实战**：法庭戏音乐

### 类型 3：情绪音乐 (Mood Music)
- **特征**：特定情绪
- **实战**：紧张 / 抒情 / 悬疑
- **药神实战**：追逐戏紧张音乐

### 类型 4：背景音乐 (Background Music / BGM)
- **特征**：贯穿全场
- **实战**：纪录片
- **占比**：60% 短剧

**实战：我们的禁毒微短剧 = 禁用 BGM = 用环境音代替**

---

## 三、配乐 4 大参数

### 参数 1：BPM (Beats Per Minute)
| 类型 | BPM | 实战 |
|------|-----|------|
| 极慢 | <60 | 抒情 |
| 慢 | 60-90 | 沉思 |
| 中 | 90-120 | 日常 |
| 快 | 120-150 | 紧张 |
| 极快 | >150 | 追逐 |

**实战：禁毒微短剧 = 60-90 BPM = 抒情**

### 参数 2：调式 (Key)
| 调式 | 情绪 | 实战 |
|------|------|------|
| C 大调 | 明亮 | 喜剧 |
| A 小调 | 忧郁 | 悲剧 |
| E 大调 | 雄伟 | 史诗 |
| D 小调 | 紧张 | 悬疑 |

**实战：禁毒微短剧 = A 小调 = 忧郁**

### 参数 3：乐器 (Instrument)
| 乐器 | 实战 |
|------|------|
| 钢琴 | 抒情 |
| 弦乐 | 史诗 |
| 吉他 | 日常 |
| 电子 | 紧张 |
| 大提琴 | 沉重 |

**实战：禁毒微短剧 = 钢琴 + 大提琴 = 沉重抒情**

### 参数 4：音量 (Volume)
| 类型 | dB | 实战 |
|------|-----|------|
| 主导 | -3 | 主题 |
| 中等 | -6 | 场景 |
| 背景 | -12 | BGM |
| 极弱 | -20 | 环境 |

**实战：禁毒微短剧 = -20 dB = 极弱 = 环境音代替**
