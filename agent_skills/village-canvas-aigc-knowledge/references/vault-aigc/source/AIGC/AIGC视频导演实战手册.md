# 1. 核心铁律（17条）

## 1.1 剧本写作铁律

### 铁律 1.9：分镜脚本禁止概括词
**触发**：写脚本时
**内容**：禁止使用"孩子/父亲/警察/男人/女人"等概括词。必须使用资产总表中的具体角色名。
**自查**：搜索「孩子」「父亲」「警察」「男人」「女人」→出现且无资产名=错误。

### 铁律 1.10：提示词必须写因果链
**触发**：写任何动作描述时
**内容**：AI不推断因果。写"效果/结果"前必须先写"谁做了什么导致了这个效果"。
**格式**：`谁 → 做了什么 → 导致什么`

| ❌ | ✅ |
|----|-----|
| 门关上 | 阿强跨出门槛，转过身，伸手抓住门把手，把门拉向自己，门完全关闭 |
| 钢管滑落 | 阿强拉动操纵杆→叉车液压启动→车身震动→震动传导到钢管架→钢管架晃动→钢管脱出→下滑 |
| 镜头下移 | 门关上后，镜头跟随关门的方向自然下移到地面 |

### 铁律 1.11：剧本先看资产再写
**触发**：写剧本前
**流程**：逐张看人物资产→逐张看场景资产→写剧本→做资产映射表
**原则**：剧本贴着图的特征写，不先想故事再找图。

### 铁律 1.12：台词要有潜台词
**触发**：写每句台词后
**内容**：每句台词必须"双层"——表面说A，实际说B。
**自查**：问"这句话表面在说什么？实际在说什么？"无第二层=重写。

| ❌ 只有功能性 | ✅ 有潜台词 |
|-------------|-----------|
| 爸，你干啥去 | 你上回也是这么说的。上上回也是。我怕你不回来了 |
| 挣钱 | 挣钱。给你买药（实际他去的不是挣钱） |

### 铁律 1.13：短视频必须有开头背景介绍
**触发**：所有短视频
**规则**：30s→5-10s铺垫 / 60s→10-15s铺垫 / 90s→20-30s介绍
**方式**：旁白（纪录片风/第三人称）> 字幕 > 画面

### 铁律 1.14：台词信息密度
**触发**：写剧本台词
**规则**：每句3-5秒 / 每段7-10句 / 紧张时刻0句 / 情感时刻5+句
**音速**：250-300字/分钟 = 4-5秒/句（含停顿）

### 铁律 1.15：旁白要有细节和画面感
**触发**：写旁白时
**原则**：旁白讲故事，不是念档案。要有具体细节（厂名/事件/场景）。

| ❌ | ✅ |
|----|-----|
| 阿强，35岁。失业一年。 | 阿强，三十五岁。原来在机械厂，去年关了门。从那以后就没再找着正经活儿。 |

## 1.2 视频生成铁律

### 铁律 1.16：15s大段硬上限 + 不切碎
**触发**：设计镜头结构时
**内容**：每大段≤15s（Seedance上限）。每个大段一个完整连续镜头，不切成碎片。
**为什么**：15s够让动作展开、空间建立、情绪沉淀。5s一镜=PPT翻页。
**时长**：按内容定，不按模板定。动作密=短，情感深=长。

### 铁律 1.17：提示词 = 因果动作链，不是画面描述
**触发**：写提示词时（17镜全军覆没教训）
**内容**：提示词写的是"谁做了什么导致什么"，不是"画面长什么样"。
**三要素**：谁（具体角色名）→ 做了什么（因果动作）→ 导致什么（物理结果）

**常见翻车**：

| 错误写法 | AI的理解 | 正确写法 |
|---------|---------|---------|
| "Small rental room night" | 白天阳光进来 | "冷蓝夜光从窗缝漏入" |
| "Both in partial silhouette" | 正脸清晰可见 | "两人脸部都在阴影中，只露侧脸" |
| "Son hand enters from right" | 一只手，没动作 | "小宇从画面右侧靠近阿强，把手伸到阿强面前" |
| "Old neighbor appears" | 两个同龄男人 | "老周，五十多岁，胡子花白" |

## 1.3 提示词写法铁律

### 中文场景必须用中文写
Seedance吃中文比英文更准确。"阿强走进雾中货场" > "A man walks into foggy cargo dock"

### @主体标注必须在画面描述里
不是只标在台词里。画面描述中也要写 `@阿强` `@陈警官` 标记角色。

### 负面约束要明确
`不要生成台词字幕 不要BGM 生成环境音和台词配音 同期声`

### 禁止项
- 禁止五官特写
- 禁止可读文字
- 禁止动作迟钝僵硬
- 禁止无反作用力动作
- 禁止阳光/暖色/鲜艳色彩（现实主义暗调项目）

# 2. 剧本写作方法论

## 2.1 五版迭代路线（《<PROJECT_CASE>》实战）

| 版本 | 被否原因 | 学到的 |
|------|---------|--------|
| v1（60s/13句） | 台词太少/没深意 | 剧本不是"提示词"——是"写人" |
| v2（90s/26句+旁白） | 旁白像报告 | 旁白要讲故事，不是念档案 |
| v3（90s/35句+280字旁白） | 台词仍"功能性" | 每句台词要有潜台词 |
| v4（90s/30句+因果重构） | 过了 ✅ | 阿强松手→钢管自己滑→来不及了 |
| v5→v6（6段长镜头，因果链重写） | 17镜全翻 | 中文因果链+@主体标注+一段一镜头 |

## 2.2 剧本结构模板

```
片头介绍（20-30s）：旁白+空镜，交代人物/冲突/动机
主体段落（N段 × 变长）：每个大段一个连续镜头
  ├── 段内动作链：因果完整
  ├── 段内对白：潜台词
  └── 段尾留钩子→下一段自然衔接
```

## 2.3 资产映射方法论

**写前**：逐张看人物外貌+场景灯光色调+道具
**写中**：每个段落标注使用哪个场景、哪个人物
**写后**：资产映射表——用了哪些、哪些备用、哪些可扩展

**《<PROJECT_CASE>》资产映射示例**：

# 3. 专业分镜提示词框架（9维）

> 每个镜头必须包含以下9个维度。238项目验证：顶级项目摄影机参数>50条。

## 维度总览

| # | 维度 | 内容 | 238项目数据 |
|---|------|------|------------|
| 1 | 摄像系统 | 机身+传感器+镜头+胶片+画幅比 | ARRI+Alexa 7250次 |
| 2 | 灯光设计 | 主光/光质/方向/光比/色温 | 有源光=真实 |
| 3 | 景别 | 大远景→特写 | 特写 6678次（最高频） |
| 4 | 摄影参数 | 焦段+光圈+影调 | 定焦组优于变焦 |
| 5 | 运镜 | 固定/横摇/手持/推近 | 推拉跟移 14960次 |
| 6 | 站位 | 角色画面位置（画左/画右/画中） | — |
| 7 | 情绪 | 角色状态（不是概括词） | — |
| 8 | 台词 | 对白+旁白（音画同步格式） | — |
| 9 | 负面约束 | 每镜专属禁止项 | 模糊1688/变形1523 |

## 3.1 景别选择指南

| 景别 | 焦段 | 用途 | 使用频率 |
|------|------|------|---------|
| 大远景 | 24mm | 建立空间/世界观/孤独感 | 开头+转折 |
| 全景 | 35mm | 人物在环境中的关系 | 动作高潮 |
| 中景 | 35-50mm | 人物互动/对话 | 最高频 |
| 中近景 | 50mm | 情感交流/关键台词 | 次高频 |
| 近景 | 50mm | 反应/情绪爆发 | 关键时刻 |
| 特写 | 85mm | 关键道具/手部/眼神 | 关键节点 |

## 3.2 运镜选择指南

| 运镜 | 效果 | 用时 |
|------|------|------|
| 固定 | 客观/冷静/纪实 | 10镜/18镜 |
| 横摇（缓慢） | 空间展开/审视 | 场景空镜 |
| 手持跟拍 | 紧张/真实/主观 | 追逐/冲突 |
| 推近 | 情感深入/发现 | 关键表情 |
| 下摇 | 跟随动作/物件落地 | 打火机落地 |

> **现实主义铁律**：不要Steadicam/不要Ronin/不要稳定器。轻微呼吸晃动=真实。

# 4. AI音画同步台词体系

> Seedance 2.0 VIP 自带音画同步。无需TTS工具。

## 4.1 黄金格式（238项目验证）

```
【台词/旁白（@角色名，声线描述，语气描述，情绪描述）："具体台词内容"】
```

**来源验证**：
- 《唐僧不听劝》：`【台词（中年男性音色，语气慌乱）：那岸边的香料又是何物？】`
- 《邪修学英语》：`女主（亲切自然）："这个是核桃，Walnut。"`
- 《寻找中国队》：`用极其认真语气说："I've done my research."`

## 4.2 声线描述公式

```
年龄 + 性别 + 质感 + 口音 + 状态
```

**示例**：
- `@阿强 — 中年男性沙哑疲劳声线，川渝口音，声音很轻`
- `@小宇 — 七岁男孩虚弱声线，气喘，说话断断续续`
- `@陈警官 — 中年男性低沉稳重声线，克制有距离感`
- `@老周 — 五十多岁老码头粗粝沧桑声线，川渝口音`

## 4.3 语气/情绪描述方法

**不是概括词**，是"像在____"的具体状态：

| ❌ 概括词 | ✅ 状态描述 |
|----------|-----------|
| 悲伤 | 像在说一件他也说不清楚的事 |
| 紧张 | 压得很稳但追得很快 |
| 绝望 | 不是求饶，是在求一个机会 |
| 试探 | 语气像在闲聊，但其实是试探 |
| 愤怒 | 不是吼，是压了一辈子的东西终于漏出来 |

## 4.4 全局指令

```
不要生成台词字幕 不要BGM 生成环境音和台词配音 同期声
```

每镜末尾必加。

## 4.5 台词在提示词中的位置

```
[摄影系统] [灯光] [@角色 画面动作描述] [【台词（@角色，声线，语气）："内容"】] [全局指令]
```

**关键**：@角色要在画面描述中出现，不只在【台词】块里。

# 5. 摄影系统参数参考

## 5.1 现实主义暗调项目模板

```
2.39:1宽银幕
机身：ARRI Alexa Mini
传感器：Super 35
镜头：Zeiss Super Speed Mk III 定焦组（24/35/50/85mm）
滤镜：Tiffen Black Pro-Mist 1/8
胶片：Kodak Vision 3 500T（5219）
色温基准：3200K钨丝灯 → 夜间外景4300-5600K
调色方向：冷灰蓝主调/暗部5%/饱和度-30%/高光≤85%
运动：无稳定器/三脚架+手持/轻微呼吸晃动
```

## 5.2 影调分区

| 场景 | 色温 | 对比度 | 光比 |
|------|------|--------|------|
| 货场大远景（雾） | 5600K | 低（雾压低反差） | 1:1 |
| 出租屋内 | 3200K冷蓝 | 中高 | 6:1-8:1 |
| 老楼道 | 2800K暖黄 | 中 | 3:1 |
| 集装箱夹缝 | 4300K | 极高（刀切光） | 10:1 |
| 事故现场 | 红蓝警灯+冷蓝雾 | 高 | 5:1 |
| 礼堂闪回 | 5600K+暖黄聚光 | 中低 | 2:1 |

## 5.3 为什么用这些参数

AI不是真的换了摄影机——这些参数是**美学锚点**。你写"ARRI Alexa Mini + Kodak 500T"，AI就知道：
- 暗部冷蓝偏移
- 颗粒细腻
- 低反差
- 纪录片质感

**238项目数据**："ARRI"+"Alexa"出现7250次，"Kodak Vision"同量级——是AIGC摄影机参数铁律。

# 6. 灯光设计体系

## 6.1 核心原则

**有源光（Motivated Lighting）**——每一束光都有看得见的来源。
**现实主义不补光**——暗的地方就是暗的。

| 参数 | 现实主义暗调项目 |
|------|----------------|
| 主光策略 | 单光源主导 |
| 辅光 | 无（或1-2档欠曝） |
| 轮廓光 | 仅在有逆光光源时使用 |
| 眼神光 | 无（AI打太亮→虚假） |
| 灯型 | 实景光源优先（窗、灯管、手电、警灯） |

## 6.2 光源类型

| 光源 | 效果 | 光比 | 色温 |
|------|------|------|------|
| 窗缝光 | 硬/窄/戏剧化 | 8:1 | 3200K冷蓝 |
| 壁灯 | 柔/扩散/温暖 | 3:1 | 2800K暖黄 |
| 手电光 | 极硬/束光/紧张 | 12:1 | 6000K冷白 |
| 警灯 | 闪烁/紧急/红蓝 | 5:1 | 红蓝交替 |
| 聚光灯 | 柔/舞台/温暖 | 2:1 | 3200K暖黄 |
| 雾+环境光 | 极软/低反差 | 1:1 | 5600K冷蓝 |

## 6.3 光比与情绪

| 光比 | 情绪 | 用在哪 |
|------|------|--------|
| 1:1-2:1（低反差） | 平静/温柔/闪回 | 礼堂 |
| 3:1-4:1（中反差） | 日常/对话 | 楼道 |
| 6:1-8:1（高反差） | 紧张/压抑 | 出租屋 |
| 10:1-12:1（极高反差） | 恐惧/追捕 | 夹缝/手电 |

# 7. 镜头语言体系

## 7.1 焦段与距离感

| 焦段 | 与人物的距离感 | 最佳用途 |
|------|-------------|---------|
| 24mm | 远/冷/客观 | 大远景/建立空间 |
| 35mm | 中/对话距离 | 中景/全景 |
| 50mm | 近/亲密 | 中近景/近景/情感 |
| 85mm | 极近/审视 | 特写/手/道具 |

## 7.2 光圈与景深

| 光圈 | 景深 | 用在哪 |
|------|------|--------|
| f/8 | 深景深 | 大远景，全部清晰 |
| f/2.8 | 中景深 | 中景，环境可辨 |
| f/2 | 浅景深 | 中近景，焦点在人物 |
| f/1.8 | 极浅 | 特写，只对焦关键物件 |

## 7.3 定焦 vs 变焦

**238项目结论**：定焦组的"呼吸感"是现实主义的命。
- 定焦：轻微畸变+边缘暗角="人眼在看"
- 变焦：太干净="摄影机在拍"

# 8. 转场设计方法论

## 8.1 4种核心转场

| 转场 | 用在哪 | 效果 |
|------|--------|------|
| **硬切** | 连续动作/同一时间线 | 自然/不可见 |
| **J-Cut** | 下一段声音先进来 | 观众不知不觉已在下一场 |
| **叠化** | 时间跳跃/空间转移 | 抒情/过渡 |
| **黑屏** | 情感重击/留呼吸口 | 让观众消化 |

## 8.2 转场选择决策树

```
同一空间连续时间 → 硬切
声音需要先铺垫情绪 → J-Cut
时间跳跃/空间跳跃 → 叠化
情绪需要重击/观众需要喘气 → 黑屏
```

## 8.3 238项目最佳实践

- 《最后的舞者》：全片硬切，只在结尾用黑屏——现实主义不玩花活
- 《天骸》：动作匹配切——剑挥出去，下一个镜头砍在盾上
- 《此间风息》：J-Cut贯穿全片——声音永远比画面先到0.5秒
- 《镇关》：色彩匹配——红灯笼到红纸伞，颜色做桥

# 9. 音效设计体系

## 9.1 音效三层结构

| 层 | 内容 | 示例 |
|----|------|------|
| 环境音 | 空间基础声音，2-3层叠加 | 风扇+夜虫+远处咳嗽 |
| 拟音 | 画面内物体的声音 | 门锁咔哒/打火机落地/钢管摩擦 |
| 静默 | 完全无声 | 全段静默=最大声音 |

## 9.2 音效节奏曲线

**现实主义短片标准节奏**：
```
开头（中密度）：环境音2-3层+旁白
发展（高密度）：环境音+拟音+对白
高潮前（极低）：静默+心跳
高潮（极高）：环境音+对白+拟音+金属
结尾（低→零）：单人声→静默
```

# 10. LibTV画布实操指南

## 10.1 完整工作流

```bash
# 1. 创建项目
libtv project create "<PROJECT_CASE>"

# 2. 绑定目录
libtv project use <uuid>

# 3. 上传资产
libtv upload "阿强" --resource "<LOCAL_PATH>"
libtv upload "场景-出租屋" --resource "<LOCAL_PATH>"

# 4. 创建组
libtv group create "段一-开场" -p <uuid>

# 5. 创建视频节点（image2video + 双输入）
libtv node create "段一-开场" -t video \
  -s model="Seedance 2.0 VIP" \
  -s modeType="image2video" \
  -s resolution="480p" \
  -s duration=15 \
  --prompt "[提示词全文]" \
  --left-add <角色资产ID> --left-add <场景资产ID>

# 6. 运行生成
libtv node <id> --run

# 7. 查看状态
libtv node list -p <uuid>
```

## 10.2 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| model | "Seedance 2.0 VIP" | 必须用名字，不是key |
| modeType | "image2video" | 连了图片资产=自动 |
| resolution | "480p" | 先低画质验证 |
| duration | 4-15 | Seedance 2.0范围 |
| ratio | "16:9" | 标准宽屏 |
| enableSound | "on" | 音画同步 |

## 10.3 CLI坑点

| 坑 | 表现 | 解法 |
|----|------|------|
| model key vs name | `-s model=star-video2` 报错 | 必须用 `-s model="Seedance 2.0 VIP"` |
| PowerShell引号 | 中文台词引号被解析 | 用Python subprocess传参 |
| 媒体输入连了就切模式 | text2video连了资产图就报错 | 先 `--left-rm` 断开再跑text2video |
| 生成超时 | `--run` 卡住 | Seedance约2分钟，加 `--timeout 300` |

## 10.4 CLI不可用的功能（需Web UI）

- TTS模型（narakeet-ai-tts）— 用Seedance自带音画同步替代
- 图片精修（nebula-ultra）— Web UI手动精修
- AI音乐（mureka-8）— Web UI或后期
- 视频超分（volcano-video-upscaler）— Web UI一键高清

# 13. 翻车修复手册

## 13.1 17镜翻车全量分析

### 翻车类型1：影调/灯光不匹配（最频繁）

| 镜 | 想要 | AI生成 | 原因 |
|----|------|--------|------|
| 1.2 | 冷蓝夜光出租屋 | 白天阳光照进来 | "night"只是形容词，AI没当指令 |
| 1.3 | 剪影效果 | 父亲正脸清晰 | "silhouette"被AI忽略 |

**修复**：不用形容词，用**光源描述**。"冷蓝夜光从窗缝漏入" ≠ "room at night"

### 翻车类型2：动作/因果缺失

| 镜 | 想要 | AI生成 | 原因 |
|----|------|--------|------|
| 2.1 | 双手传递药盒 | 一只手，无传递 | AI不知道这是"传递"动作 |
| 2.2 | 门正在关上+打火机掉落 | 门开着，人站着 | AI不理解"关门"的因果 |

**修复**：写完整因果链。"他推开门→跨出门槛→转身抓住把手→拉向自己→门完全关闭→打火机从身上滑落→掉在地上"

### 翻车类型3：角色识别失败

| 镜 | 想要 | AI生成 | 原因 |
|----|------|--------|------|
| 2.3 | 老周（50+邻居） | 两个同龄男人 | AI没识别"old neighbor" |

**修复**：@角色标注 + 具体外貌描述。"@老周，五十多岁，黑色旧夹克，灰色内搭，胡子花白"

### 翻车类型4：@主体格式错误
**错误**：只在台词里写@角色
**修复**：画面描述和台词都要标注

## 13.2 翻车修复SOP

```
1. 下载视频 → 看中间帧
2. 识别翻车类型（灯光/动作/角色/格式）
3. 对照提示词找缺失的因果链
4. 补充因果链重写提示词
5. 单镜重跑验证
6. 通过后再跑下一镜
```

> **关键教训**：先跑一镜看效果，通过后再全量跑。不要像第一次那样17镜全跑全翻。
