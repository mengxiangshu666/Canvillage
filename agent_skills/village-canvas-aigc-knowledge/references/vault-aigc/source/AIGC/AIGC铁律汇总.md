

## ⚠️ 铁律 1.20：物理常识三校验（2026-06-28 13:10 兄弟立规矩）

**用户原话**：「你要从物理世界观念上来推断。看看他这个东西到底合不合理。具体情况具体分析。」

**核心原则**：从物理世界常识推断。**不要走极端——太多台词或太少台词都不行。具体情况具体分析。**

### 三校验（写任何含台词的剧本前必走）

**维度一：字/秒校验**
- 普通人说话：3-4字/秒
- 虚弱/害怕/压抑状态：1.5-2.5字/秒
- 旁白：2.5-3字/秒
- 每段时长 ÷ 角色状态字速 = 该角色最大台词量

**维度二：呼吸/沉默校验**
- 每两句台词之间至少0.5秒沉默让演员呼吸
- 重场戏（悲伤/真相/承诺）台词之间1-2秒沉默让观众消化
- 台词时间 + 沉默时间 + 环境音时间 ≤ 段时长

**维度三：环境音最低占比校验**
- 电影对话场景 ≥40% 非台词时间（环境音/沉默/动作音）
- 紧张追逐场景 ≥60%（呼吸/脚步/物品碰撞为主）
- 抒情独白场景 ≥30%（背景音乐/空镜/呼吸）
- 段时长 × (1-环境音占比) = 台词最大时长

### 校验工具代码

```python
def check_segment(seg_name, duration, lines):
    speed_map = {
        '小宇虚弱': 1.5, '阿强压抑': 2.0, '老周沧桑': 2.2,
        '陈警官沉稳': 2.5, '旁白克制': 2.5,
    }
    total_speech = 0
    for role, state, words in lines:
        speed = speed_map.get(state, 2.0)
        total_speech += words / speed
    env_pct = (duration - total_speech) / duration * 100
    if total_speech > duration * 0.85:
        return 'SUPERLOAD ' + str(round(total_speech - duration*0.85, 1)) + 's'
    elif env_pct < 30:
        return 'ENV_LOW (<30%)'
    else:
        return 'PHYSICS_OK'
```

## ⚠️ 铁律 1.21：物理常识是辅助，不是判决（2026-06-28 13:13 兄弟立规矩）

**用户原话**：「你要从物理世界观念上来推断。看看他这个东西到底合不合理。具体情况具体分析。这个你应该明白吧？」

**核心原则**：物理常识计算器是**辅助工具**不是**判决器**。三校验结果是**告警**不是**禁用**。

### 平衡的两个极端

| 极端 | 表现 | 后果 |
|------|------|------|
| ❌ 不算 → 凭感觉塞 | 段二14s塞79字 → 物理超载38s | 嘴形乱+环境音没+观众听不清 |
| ❌ 算死 → 必须严格30%环境音 | 重场戏情感台词被砍光 | 信息丢失+情绪断裂 |

**正确**：算 → 看见告警 → 重新思考**这段到底要讲什么** → 调整结构或信息密度

### v8段二A的临界判断

物理校验器跑出 v8段二A = 24% 环境音 < 30% 阈值 = OVERLOAD
- 严格派：必须砍2字台词
- 实际判断：阿强这句"听见没。下回咳得凶了喊我"是**核心情感重场戏**
  - 砍掉"咳得凶" = 丢失关键医学信息（小宇哮喘发作的信号）
  - 砍掉"喊我" = 丢失核心动作指令
- 决策：**保留24%环境音**（低于阈值但**重场戏可放宽到25%**）

### 阈值浮动表（具体情况具体分析）

| 场景类型 | 严格阈值 | 浮动范围 | 理由 |
|---------|---------|---------|------|
| 日常对话 | 40% | 35-45% | 节奏可以快 |
| 重场戏（悲伤/真相/承诺）| 30% | **20-30%** | 情感浓度高 |
| 激情对峙 | 45% | 40-50% | 双方语速都快 |
| 内心独白 | 35% | 25-40% | 旁白密度高 |
| 紧张追逐 | 60% | 50-70% | 呼吸+脚步为主 |

### 从单事件抽规律的方法论

1. **观察具体事件**（v7段二超载38秒）
2. **抽象出通用规律**（混合角色段不能简单平均字速）
3. **做成计算器/校验器**（physics_calculator.py）
4. **用计算器跑全剧本**（v7段二段三段五全部OVERLOAD）
5. **看见告警不是立刻执行，是要思考意图**（v8段二A重场戏保留24%）
6. **保留灵活性**（铁律1.20+1.21双校验）

### 跨剧本适用

- 短剧对白：阈值 40%±5
- TVC广告：阈值 25%±10（旁白为主）
- 抒情空镜：阈值 50%±20（多空镜少台词）
- 数字人口播：阈值 20%±5（密集信息）
