# AIGC 提示词翻译引擎规则库

> 版本：2026-06-21 · 基于兄弟提供的 10 个专业培训材料融合提炼
> 目标：将用户"人话"请求 → 翻译为可直送 AI 模型生产的专业 prompt

## 一、翻译引擎核心原则

### 1.1 兄弟说一句话，我吐出完整 prompt

用户输入："帮我做个修仙短剧的女主角"
我输出：角色设计 prompt + 三视图 prompt + 场景 prompt + 剧本 prompt

### 1.2 七个翻译铁律（跨所有场景）

| # | 铁律 | 说明 |
|---|------|------|
| 1 | **框架先行** | 没有"帮我写个剧本"——必须框死类型/时长/风格/平台/受众 |
| 2 | **开头定生死** | 最重要的信息放第一句（类型锁定："这是一张真实真人图片"/"3DCG风格"）|
| 3 | **结尾强强调** | 次重要放最后（"请严格保持所有视图头部和脚底在同一水平线"）|
| 4 | **结构段落化** | 用标题/编号/冒号分段，不写流水账 |
| 5 | **负面先排除** | "不要"写在正面需求之后，作为边界约束 |
| 6 | **一次一个需求** | 不要在一轮对话里塞太多，分轮递进 |
| 7 | **AI 是助理** | 我吐出的是草稿，用户是导演，用户决定用不用 |

### 1.3 提示词权重定律（从课程提炼）

```
第一句权重★★★★★ → 锁定画风/类型/身份
最后一句权重★★★★ → 重点强调/关键约束
中间权重★★★ → 具体描述（可能被随机省略）
```

### 1.4 平台适配指南（2026-06-21 实战验证）

| 平台 | 语法偏好 | 负面词 | 特殊规则 |
|------|---------|--------|---------|
| **即梦AI**（字节） | 中文物理描述+摄影术语+自然段落 | 无独立负面词机制 | hex色值可能不如中文描述稳定；结构化标题弱化为自然段落；推荐2700K/6500K式量化 |
| **Midjourney** | 英文逗号分隔短语，逗号=权重 | `--no` 替代负面词 | 结构化标签无效；需转英文；艺术家名权重高 |
| **Stable Diffusion** | 英文结构化标签，括号+数字调权 | 正面负面都支持 | hex码需配合ControlNet；LoRA用`<lora:name:weight>` |
| **DALL-E 3** | 自然语言一段话 | 不支持负面词 | 完全不需要结构化，越自然越好 |

### 1.5 主观词 → 物理参数翻译铁律

**绝对禁止**的模糊词：逼仄、潮湿、破败、神秘、温馨、高级、有氛围感

**强制翻译对照**：

| 主观词 | 物理参数翻译 |
|--------|-------------|
| "逼仄" | 房间纵深4米，宽3米，层高2.6米，两侧墙面间距≤2米 |
| "潮湿" | 墙角黑绿色霉斑直径约15cm，墙面漆起皮卷曲，空气湿度~85% |
| "破败" | 木窗框漆面脱落露出灰色木纹，玻璃有裂痕，门槛石缺角 |
| "暖黄/暖色调" | 光源色温2700K-3500K |
| "冷蓝/冷色调" | 光源色温6000K-7000K |
| "高级感" | 三层景深（前景中景后景）+ 光影引导线 + 胶片质感 + 非居中构图 |
| "塑料感" | 减少镜面反射值（specular≤0.3）+ 增加材质凹凸纹理 + 降饱和 |
| "有氛围感" | 光影设计（主光源方向+补光位置+轮廓光）→ 引导视线 + 建立情绪 |

### 1.6 自检清单机制（强制）

每个提示词末尾必须追加以下4项自检：

```
□ 自检1：所有主观词是否已翻译为物理参数？（无"美丽""神秘"等）
□ 自检2：光源是否精确到位置和色温？（不是"灯光"而是"天花正中2700K白炽灯"）
□ 自检3：材质是否精确到颜色和状态？（不是"老式木桌"而是"深褐色#5A3A25清漆磨损泛白"）
□ 自检4：负面提示词是否对应正面约束的镜像？（正面说"对齐"，负面说"不要歪"）
```

### 1.7 三条铁律（绝对不可违反）

**铁律1：hex色值禁区**
- ✅ hex色值和材质描述只用在**环境/场景物体**上（墙面、地面、道具）
- ❌ 人物身上**零hex色值、零色块标注**（面部、皮肤、服装等）
- 人物外观由参考图锁定，提示词只写动作、位置、气色
- 例：✅"墙面水泥灰#7A7A72" | ❌"皮肤肉色#F5DEB3"（用参考图，不用hex）

**铁律2：交叉注意力 = 精准锚点 > 越详细越好**
- 关键词少但精准 → 每个词高注意力 → 画面质量高
- 关键词多但互相竞争 → 每个词低注意力 → 画面融化变形
- 关键不是字数，是**精准的注意力分配锚点**
- 去掉所有"不锚定任何东西"的废话词（好看的、精美的、震撼的）
- **不要让两个关键词竞争同一个注意力区域**

**铁律3：实战验证 > 理论**
- 精简理论在复杂多物体场景下失效
- 详细描述控制力远强于精简描述（实战2已验证）
- 理论必须服从实际出片效果——出片有问题就改提示词，不要找理论借口

### 1.9 影调叙事决策矩阵（何止维战略层）

| 影调 | 暗部占比 | 叙事功能 | 典型场景 |
|------|---------|---------|---------|
| **低长调** | 70-85% | 悬疑/危险/戏剧性 | 犯罪片/惊悚片/毒贩家 |
| **低中调** | 60-75% | 压抑/忧郁/内敛 | 文艺片/家庭剧 |
| **低短调** | 70-85% | 极简/神秘/抽象 | 实验片 |
| **中长调** | 35-55% | 自然/真实/生活化 | 纪录片/日常剧 |
| **中中调** | 35-50% | 平和/舒适/日常 | 生活片/喜剧 |
| **高长调** | 10-25% | 明亮/开阔/希望 | 结尾段落/公路片 |
| **高中调** | 10-30% | 温馨/浪漫/甜蜜 | 爱情片/家庭片 |
| **高短调** | 5-15% | 纯净/空灵/天堂 | 天堂场景/童话 |

**影调三铁律**：
1. **必须量化** — 不说"比较暗"，说"暗部占70%以上"
2. **高光必须指定位置** — 暗部基底中高光是稀缺资源
3. **影调与胶片质感联动** — 低长调+柯达Vision3 500T=真实电影感

### 1.10 布光叙事决策矩阵（何止维战术层）

| 想表达的情绪 | 光源选择 | 色温倾向 | 构图配合 |
|-------------|---------|---------|---------|
| 疏离/孤独 | Rimlight为主 | 偏冷（5000K+） | 偏侧/留白 |
| 坦然/真诚 | Key Light正面 | 中性偏暖（3500-4500K） | 正面/对称 |
| 荒诞/自嘲 | 强明暗对比+冷暖对比 | 冷暖双色温 | 中心对称 |
| 暧昧/不安 | 分割光/半张脸明暗 | 暖色低光 | 偏侧/紧凑 |
| 压迫/威胁 | 顶光/底光/逆光剪影 | 冷色硬光 | 低角度仰拍 |

**光影设计三定律**：
- ✅ 光在两人之间=关系正在发生
- ✅ 光只照一个人=注意力在那里
- ✅ 暖光=安全/亲密，冷光=危险/疏离

### 1.11 景别黄金律 3:5:2（大黑耗子）

| 景别 | 占比 | 叙事功能 |
|------|------|---------|
| 全景（含远景） | 30% | 空间坐标、世界观 |
| 中景 | 50% | 日常叙事、对话 |
| 特写（含近景） | 20% | 关键信息、情绪冲击 |

**交替=呼吸感**：
- 连续3-4个中景→观众开始疲劳
- 在中景之间穿插全景和特写→保持注意力
- 故意"不连贯"的景别切换比规规矩矩的排列更有张力

### 1.12 运镜万能公式（大黑耗子）

```
运镜类型 + 运动方向 + 运行速度 + 具体时长 + 主体位置 + 稳定性要求
```

**运镜稳定性优先级**：
```
定机位 > 缓慢推镜 > 轻微拉远 > 平移跟拍 > 环绕
```

**两条铁律**：
1. 优先单一运镜，不要把推/拉/环绕/跟拍强行叠加
2. 运镜服务叙事，不是炫技

### 1.13 运镜情绪功能对照（大黑耗子）

| 运镜 | 情绪功能 | 提示词要点 |
|------|---------|-----------|
| 推镜 | 聚焦/压迫/进入内心 | 标明速度+时长+起止景别 |
| 拉镜 | 释放/揭示/孤独感 | 标明主体停留方位 |
| 跟拍 | 沉浸/连贯/追逐 | 单一水平移动，不叠加复杂 |
| 环绕 | 仪式感/史诗/高光 | 从180°练手，不直接上360° |
| 横移 | 平行/并置/对峙 | 配合前景遮挡做空间揭示 |
| 升降 | 升华/史诗/揭示 | 上升=视野打开，下降=压迫收紧 |
| 手持 | 纪实/紧张/临场 | 轻微摇晃，不是剧烈抖动 |
| 希区柯克变焦 | 扭曲/心理异常/爆发 | 难控制，需多次抽卡 |
| 定格 | 永恒/关键瞬间 | 配合时间膨胀效果 |

### 1.14 声音分层公式（Seedance 2.0）

```
声音效果 = 对白层(0dB) + 动作音层(-10到-25dB) + 环境音层(-25到-35dB) + BGM层(-15到-25dB)
```

**应用到提示词**（图生视频专用）：
```
[对白层]: 台词内容+语气+情绪+音量参考
[动作音层]: 脚步声/衣物摩擦/物件碰撞+音量参考
[环境音层]: 雨声/风声/远处车声+音量参考
[BGM层]: 风格+情绪+音量参考（最低，不抢戏）
```

### 1.15 越轴检查（180度规则）

**铁律**：当两个角色面对面时，摄影机必须始终在两人连线的一侧拍摄。

**越轴表现**：
- 左边的角色跑到了右边
- 右边的角色跑到了左边
- 观众完全搞不清谁在打谁、谁在看谁

**解决方案**：
- 在提示词中**明确写死角色空间位置**："角色A在画面左侧面向右，角色B在画面右侧面向左"
- 每次切镜后检查：上一镜A在左B在右，这一镜A还在左B还在右吗？
- 如果需要越轴，中间必须插入一个**中性镜头**（正面或全景）做过渡

### 1.16 仙剑4 七段/五段结构（最佳写作范式）

**文生图七段**：
```
[画面构图：景别，视角]
+ [角色完整描述+空间位置]   ← 每次完整重复
+ [人物空间与互动关系]
+ [微表情与面部特写]
+ [场景环境元素与前景/背景道具]
+ [光影几何与大气效果]
+ [视觉风格/胶片质感：镜头，光圈]
```

**图生视频五段**：
```
[运镜轨迹与速度]  ← 放最前面
+ [主体物理动作细节]
+ [环境物理动态]
+ [音效与音乐氛围]
+ [时长：X.Xs]
```

**关键铁律**：
- **角色描述每次完整重复**（仙剑4的云天河在9分镜中完整出现7次）
- 运镜放最前面（信息权重高）
- 微表情独立成段（具体到肌肉级）
- 末尾标注时长
- 音效写在提示词里


## 二.5 维摩诘三层协议框架（战略级）

> 来源于"提示词集"（Prompt Sets）概念——不是单条prompt，是一套约600字的"一致性逻辑协议"。
> 每次创作开始前定调，全片所有镜头共享此协议。

### 空间协议（Space Protocol）
```
环境深度：________（室内纵深/室外远景/无限空间）
广角↔微距切换逻辑：________（何时推何时拉）
空间层次：________（前景/中景/后景各有什么）
机位距离：________（主观视角/客观观察/特写冲击）
```

### 氛围协议（Atmosphere Protocol）
```
颜色分级：________（主色调+补色+强调色）
颗粒感：________（胶片颗粒强度/无颗粒）
烟雾与光的物理交互：________（有/无/强度）
色温基调：________（暖/冷/混合）
```

### 连续性协议（Continuity Protocol）
```
角色特征锚定：________（核心外观关键词，所有镜头共享）
环境元素延伸：________（同一物件在不同镜头的合理延续）
跨帧一致性声明：________（显式写明"100% Consistent"）
```

**使用方式**：开始创作前，先填完三层协议→粘贴给Agent→Agent在后续创作中自动遵循。相当于给Agent一本"创作宪法"。



## 三、场景一：角色设计翻译

### 3.1 用户说 → 我翻译

| 用户说 | 我翻译成 |
|--------|----------|
| "帮我做一个女侠角色" | 完整角色参考表 prompt（含三视图+特写） |
| "我要一个赛博朋克的杀手" | 角色设计 + 义体细节 + 氛围颜色锁定 |
| "做一套古风家族人物" | 提取公共关键词（新中式+立体剪裁+叠穿）→ 逐个生成 |

### 6.4 音效与BGM设计

**完整音频处理流程**：

| 阶段 | 工具 | 免费/付费 | 说明 |
|------|------|-----------|------|
| 配音 | 剪映AI配音 / 逗哥配音 / ElevenLabs | 免费～$5/月 | 按角色选音色，语速1.1-1.2倍更紧凑 |
| 音效 | 剪映素材库 | 免费 | 脚步声/风声/门声/剑鸣——加起来观感提升一档 |
| BGM | Suno / 天工音乐 | 免费50积分/天 | 别一首歌从头铺到尾，跟情绪切换 |
| 原生音画同步 | Seedance 2.0 | 免费额度内 | 视频生成时自动输出双声道立体声 |

**音效设计三原则**：
1. 千万别省音效——脚步声、风声、门开声、剑鸣……加上去观感直接提升一个档次
2. 别一首歌从头铺到尾，跟着情绪切换才有层次感
3. 纸影/幻境等特殊角色的声音要加"隔纸"效果（低通滤波+混响）

**情绪→BGM对照**：
| 情绪 | BGM风格 | 推荐乐器 |
|------|---------|---------|
| 孤独/闷热 | 极简钢琴单音，像钟摆 | 钢琴独奏 |
| 紧张/悬疑 | 低频弦乐Drone，不和谐音程 | 弦乐+电子Drone |
| 温暖/感动 | 钢琴温暖小调旋律 | 钢琴+大提琴 |
| 紧迫/追逐 | 急促鼓点+节奏弦乐 | 打击乐+弦乐 |
| 震撼/反转 | 弦乐骤停+留白 | 全部停-再起 |
| 释然/温暖结尾 | 旋律回归，温暖解决 | 钢琴结尾和弦 |

### 11.17 导演思维 7 条通用规律（v2新增）

| 规律 | 核心应用 |
|------|---------|
| 景别是情绪的标尺 | 小=压迫，大=自由，中=关系。交替=呼吸感 |
| 运镜是叙事的语法 | 推=靠近/亲密，拉=远离/释放，环绕=审视，上升=升华 |
| 光影是叙事的第二语言 | 暖=安全，冷=危险，逆光=剪影，光在两人之间=关系 |
| 声音是类型的开关 | 同一画面+不同音乐=不同类型 |
| 视点转移是叙事的推进 | A视角→B视角→交汇=叙事推进一步 |
| 环境不是背景，是角色 | 仙剑4的红叶=韩菱纱的"和世界不同" |
| 微表情是人物的真相 | 表情弧线=人物揭示 |

## 十三、角色资产卡模板

> 用于"锁定角色一致性"——每个角色一张卡，中英文标准prompt各一套，所有镜头共享。

```
【角色资产卡】
姓名/代号：________
人设关键词：________（3-5个性格词）

== 核心外观描述 ==
- 面部：________（脸型/眼型/鼻/嘴/特殊标记）
- 发型/头饰：________
- 服装（上半身）：________（颜色/材质/状态）
- 服装（下半身）：________
- 配饰/武器：________
- 特征标记：________（伤疤/纹身/痣）
- 声音特征：________

== 标准提示词 ==
标准提示词（中文）：
{景别}，{年龄}岁{性别}，{完整面部描述}，{发型}，{服装上半身}，{服装下半身}，{配饰}，{特征标记}，{环境场景}，{情绪氛围}，{视觉风格}，{光影效果}

标准提示词（英文）：
{Shot type}, {age}-year-old {gender}, {full face desc}, {hairstyle}, {top wear}, {bottom wear}, {accessories}, {features}, {scene}, {mood}, {style}, {lighting}

**使用规则**：

4. 中英文各备一套：即梦用中文，MJ/SD用英文

## 十四、分镜双提示词结构

> 每镜包含文生图+图生视频双prompt，这是《纸人巷》38镜验证的最佳实践。

### 标准分镜模板

| 项目 | 内容 |
|------|------|
| **镜号** | SXX |
| **时间** | XX:XX-XX:XX |
| **景别** | 远景/全景/中景/近景/特写 |
| **角度** | 平视/仰拍/俯拍/侧面/正面 |
| **构图** | 三分法/居中/对角线/满幅 |
| **每秒动作** | 0-2s： ｜ 3-5s： ｜ 6-8s： |
| **音效** | |
| **BGM** | |
| **文生图prompt** | `{景别}，{完整角色描述}，{动作}，{环境}，{情绪}，{风格}，{光影}` |
| **图生视频prompt** | `{动作链用"然后…立刻…紧接着"连接} + {运镜描述}` |
| **备注** | 角色参考图编号/注意事项 |

### 双prompt写作规则

**文生图prompt**（每次必须包含）：
```
景别 + 角色完整外观（逐项引用角色资产卡） + 动作/表情 + 环境 + 情绪基调 + 视觉风格 + 光影 + 画质词
```
**图生视频prompt**（聚焦动态）：
```
0-Xs: {具体动作}，然后 X-Ys: {下一个动作}，紧接着 Y-Zs: {收尾动作}，{运镜方式}
```
**统一参数**：8秒/镜 · 9:16竖屏 · 运动幅度0.5-0.6 · 首帧用文生图静态画面

### 动作链连接词（降低抽卡率的关键）

```
"然后" = 连续发生（动作A完成后B开始）
"立刻" = 快速切换（<0.5秒）
"紧接着" = 因果连接（A导致B）
```

使用"然后…立刻…紧接着"连接的动作链，比自由描述抽卡率降低约50%。

## 67. 跨平台编码策略

> 来源：AIGC三平台模板包 | 案例：地铁站告别电话

**核心发现**：同一个导演母版 → 三种完全不同的 prompt 写法

```
统一原则（三平台通用）:
1. 先锁定主体→动作→镜头→风格（不要 "电影感" 开头）
2. 一镜头 = 一动作 + 一运镜 + 一情绪转折
3. 心理→可见行为: 沉默/呼吸/眼神/嘴角/手部/低头/放下
4. 负面约束必写: 防变脸/换衣/多人/夸张/危险
5. 失败先删冲突，再增强锚点
```

### 即梦编码: 全中文自然
- 连续段落，台词可内嵌
- 策略: 中文自然语言 + 图生视频 + 首尾帧
- 优势: 快速出片

### 可灵编码: 结构化中英混合
- Subject → Movement → Scene → Camera → Lighting → Dialogue → Negative
- 摄影术语用英文，叙事意图用中文
- 优势: 可控性强

### LibLib编码: 资产化三步
- Step1 角色定妆图 → Step2 场景参考图 → Step3 图生视频
- 每步独立 prompt + 独立负面，资产先行
- 优势: 跨镜头一致性最强

## 70. 拆镜法

> 复杂场景不要一个镜头扛全部

```
镜1 空间建立 → 全身远景，孤独空间
镜2 情绪推进 → 中景慢推，说不出
