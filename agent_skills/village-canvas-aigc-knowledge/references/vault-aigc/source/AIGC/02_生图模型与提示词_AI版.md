# 文件 2：生图模型与提示词深度手册（**AI 看的**）

> 受众：AI 助手
> 深度：⭐⭐⭐⭐⭐（含 AI 注意力机制底层原理）
> 关键：**不能傻瓜式套模板，要具体情况具体分析**

## 第 1 章：AI 生图的底层机制（**为什么要"具体情况具体分析"**）

### 1.1 AI 怎么"看"提示词

**AI 生图不是"读字"——是"匹配"**：
- AI 把提示词拆成 **token**（词元）
- 每个 token 在训练数据中找到最相关的视觉概念
- 把这些视觉概念"混合"生成图

**关键洞察**（来自 Atlas Cloud 2026）：
> "**The model weights tags based on their order. If the subject is your priority, place @Image1 at the very beginning of your prompt.**"

**翻译**：模型按**位置**分配权重。**第一个词权重最高**。

### 1.2 AI 注意力机制（**核心**）

**AI 视觉注意力公式（简化版）**：
```
注意力 = f(位置权重, 词频权重, 上下文权重, 多模态权重)
```

**4 大权重**：

| 权重 | 影响 | 例子 |
|------|------|------|
| **位置权重** | 越靠前越高 | "瘦削黑眼圈男性" 在前 → 强 |
| **词频权重** | 高频词强 | "电影感"、"4K" 高频 |
| **上下文权重** | 关联词强 | "cinematic" 强化电影感 |
| **多模态权重** | 参考图 30-70% | @Image1 (70% weight) |

### 1.3 AI 注意力预算

**AI 视觉模型有"注意力预算"**（来自 DALL-E 研究）：
- 总预算 = 100%（固定）
- 主体占用 50-60%
- 风格/光线占用 20-30%
- 细节/环境占用 10-20%
- **超出会被"稀释"**

**实战意义**：
- ❌ 不要写超长描述（> 50 词）—— 注意力稀释
- ✅ 关键信息要靠前
- ✅ 风格/光线简短（1-2 个词组）
- ❌ 避免堆叠（"red, blue, green, yellow"）

### 1.4 "具体情况具体分析"的根本原因

**AI 视觉模型不是"理解"——是"模式匹配"**：
- 同样关键词在不同模型下权重不同
- 同样关键词在不同上下文中权重不同
- 同样关键词在不同模态下权重不同

**结论**：**没有"通用完美提示词"**——只有**适配特定模型的提示词**。

## 第 2 章：4 大模型深度剖析

### 2.1 Lib Navo Pro（nebula-ultra）—— **一致性之王**

**模型特性**：
- "**最强图片编辑模型、一致性好**"
- 50s 出图
- **强项**：跨图一致（4 视图、3 状态、多次迭代）

**AI 注意力特征**：
- 参考图占注意力 **60-70%**（极高）
- 提示词占 **20-30%**（被参考图压制）
- 风格锚点占 **10%**

**实战意义**：
- **必须用参考图**（不传 = 浪费一致性能力）
- 提示词**简短**（参考图承担主要工作）
- **不要过度描述**（会让 AI 偏离参考图）

**提示词模板（4 视图）**：
```
(参考图: <主体描述>)

(正面/左/右/背:1.3), (环境:0.6), 光线, 镜头, 风格
--no 卡通, 动漫, 模糊
```

**权重语法**：
- `(元素:1.3)` = 该元素占 130% 注意力
- `(元素:0.6)` = 该元素占 60% 注意力
- 默认 1.0 = 100%

**实战例子（人物 4 视图）**：
```
(参考图: 26 岁中国男性极客，175cm/65kg 瘦削,
黑眼圈明显, 黑色微卷头发抓乱,
宽松黑色纯棉 T 恤, 深灰色休闲裤, 赤脚,
肩膀微微内扣, 微前倾, 目光锁定屏幕姿态)

(正面站立:1.3)
(工作室极简:0.6)
屏幕冷白光 6500K (主光源)
35mm 中景固定
cinematic, 电影感纪实
照片写实风格, 4K, ultra-detailed, sharp focus

--no 卡通, 动漫, 模糊, 错字
```

**注意**：
- 主体描述**靠前**（占 50% 注意力）
- 参考图描述**第一行**（占 70% 视觉注意力）
- 风格锚点**靠后**（占 10%）

### 2.2 Lib Navo 2（nebula-2-flash）—— **文字准确之王**

**模型特性**：
- "**支持联网搜索、文字准确**"
- 25s 出图
- **强项**：UI 文字渲染、海报、字幕

**AI 注意力特征**：
- 文字内容占注意力 **40-50%**（极高）
- 字体描述占 **20-30%**
- 环境/位置占 **20-30%**

**实战意义**：
- **必须明确文字**（"屏幕上写'[X]'"）
- **指定字体**（"等宽字体"、"无衬线"）
- **指定位置**（"屏幕中央"、"右上角"）
- 必加 `--no 错字, 拼写错误, 模糊文字`

**提示词模板（UI 资产）**：
```
[主体]，[显示文字: "[具体文字]"]，[字体]，[位置]，[环境]
--no 错字, 模糊文字, 拼写错误, 卡通
```

**实战例子（UI 资产——有文字）**：
```
极简 AI 助手对话框，
浅灰色（#E0E0E0）半透明背景（透明度 70%），
无边框，圆角 8px，
显示文字 "P，你之前 3 年写过 47 次这句注释。'// 先这样吧，明天再看。'"，
Roboto Mono 等宽字体，左对齐，14px，深灰文字。
深色屏幕背景，UI 写实风格。

--no 错字, 模糊文字, 拼写错误, 卡通
```

**注意**：
- 文字内容**必须用引号**（AI 知道这是要渲染的文字）
- 字体指定要**专业**（"Roboto Mono" 不是"等宽字体"）
- 位置要**明确**（"左对齐" 不是"在中间"）

### 2.3 悠船 V8.1（mj-v8.1）—— **电影感之王**

**模型特性**：
- "**美学水准大幅提升**"
- 50s 出图
- **强项**：电影感场景、纪实风格、美学

**AI 注意力特征**：
- 风格锚点占注意力 **30-40%**（极高）
- 光线描述占 **20-30%**
- 主体占 **20-30%**
- 焦段/构图占 **10-20%**

**实战意义**：
- **必须用风格锚点**（"cinematic, Roger Deakins"）
- **必须详细光线**（"cold blue 6500K, 8:1 ratio"）
- **必须焦段**（"35mm" 或 "85mm"）
- 必加 `--no anime, cartoon, illustration, painting, drawing, sketch, CGI, 3D render`
- 用 `--s 250-500` 平衡美学

**提示词模板（电影感场景）**：
```
[主体]，[环境]
[光线]（必须详细），[焦段]，[构图]
[风格锚点: 导演/摄影师]
--ar 16:9
--no anime, cartoon, illustration, painting, drawing, sketch, CGI, 3D render
--s [250-500]
```

**实战例子（工作室主场景）**：
```
极简极客工作室，凌晨3点
- 3 台显示器弧形摆开
- 中间屏显示代码（模糊化处理）
- 右侧屏角落有 A 助手对话框
- 深色木质桌面，咖啡杯、外卖盒凌乱
- 右侧大窗，凌晨3点城市天际线虚化
- 室内无主灯

冷蓝屏幕光 6500K 作为主光源
窗外城市暖黄 2800K 作为背景层次
35mm 中景固定
cinematic, Roger Deakins style, 电影感纪实
--ar 16:9
--no anime, cartoon, illustration, painting, drawing, sketch, CGI, 3D render
--s 400
```

**注意**：
- **光线要 3 个要素**（色温 + 强度 + 方向）
- **风格锚点要具体**（"Roger Deakins" 不是"专业人士"）
- **--s 400 是中位美学值**（太低没风格，太高失真）

### 2.4 Lib Image（lib-image-2）—— **长文本之王**

**模型特性**：
- "**最新图片模型、长文本能力突出**"
- 60s 出图
- **强项**：极简概念、抽象想法、长描述

**AI 注意力特征**：
- 长描述占 **40-50%**
- 概念关键词占 **20-30%**
- 主体占 **20-30%**

**实战意义**：
- **可以长**（3-5 句）
- 概念要**抽象**（"AI 觉醒"、"哲学"）
- 符号要**明确**（"纯白光标"、"极简元素"）
- **不要复杂环境**

**提示词模板（极简概念）**：
```
[极简主体]，[动作/状态]，[极简环境]，[单一光源]，[极简风格]
[概念关键词]，[哲学关键词]
8K, ultra-detailed, sharp focus
```

**实战例子（纯白重启）**：
```
极简极客工作室，纯白底色屏幕
- 仅有一个光标缓慢闪烁
- 旁边贴着一张边缘卷曲的纸片
- 纸片上手写 "够用就好——爸"
- 26 岁中国男性极客的手按在电源键上
- 桌面上咖啡杯、外卖盒都被推到一边（清理过）

极简主义，电影感，安静深远
8K, ultra-detailed, sharp focus
```

## 第 3 章：3 大资产类型深度剖析

### 3.1 人物资产（Character Reference）

**核心目的**：跨镜头保持角色一致性。

**5 大要素**（**缺一不可**）：

1. **年龄 + 性别** （"26 岁中国男性"）
2. **身材**（"175cm/65kg 瘦削"）
3. **肤色**（"偏黄暗沉（缺睡）"）
4. **服装**（"宽松黑色纯棉 T 恤"）
5. **姿态/表情**（"肩膀内扣，前倾"）

**4 视图策略**：
- 正面（1.3 权重）—— 主参考图
- 左/右（1.0 权重）—— 用 nebula-ultra 编辑
- 背面（1.0 权重）—— 验证 3D 立体结构

**实战模板**：
```
(参考图: 26岁中国男性极客，175cm/65kg 瘦削身材,
黑眼圈明显，黑色微卷头发抓乱,
宽松黑色纯棉T恤，深灰色休闲裤，赤脚,
无首饰无眼镜，肩膀微微内扣，微前倾,
目光锁定屏幕姿态)

(正面站立:1.3)
(工作室极简:0.6)
屏幕冷白光 6500K (主光源)
35mm 中景固定
cinematic, 电影感纪实
照片写实风格, 4K, ultra-detailed, sharp focus

--no 卡通, 动漫, 模糊, 错字
```

**注意（**避免失败**）**：
- 不要 5 视图（5 个会分散注意力）
- 不要混年龄性别（"25-30 岁女性"）
- 不要"年轻化"（"看起来 20 岁"——模糊）

### 3.2 场景资产（Environment Reference）

**核心目的**：跨镜头保持环境一致。

**5 大要素**：

1. **空间**（"极简极客工作室"）
2. **物件**（"3 台显示器、咖啡杯、外卖盒"）
3. **光线**（"屏幕冷白 6500K + 窗外暖黄 2800K"）
4. **构图**（"中景 50mm 固定"）
5. **氛围**（"凌晨 3 点、电影感纪实"）

**多视角策略**：
- 视角 1（中景 50mm）—— 主场景
- 视角 2（特写）—— 道具/对话
- 视角 3（俯视）—— 桌面布置
- 视角 4（窗边）—— 冷暖对峙

**实战模板**：
```
极简极客工作室，凌晨3点
- 3 台显示器弧形摆开（中间 27 寸大屏，两侧 24 寸）
- 中间屏显示代码（模糊化处理）
- 右侧屏角落有 A 助手对话框
- 左侧屏显示邮件
- 深色木质桌面，咖啡杯、外卖盒凌乱
- 椅子：人体工学黑色
- 窗户：右侧大窗，凌晨3点城市天际线虚化
- 室内无主灯

冷蓝屏幕光 6500K 作为主光源
窗外城市暖黄 2800K 作为背景层次
35mm 中景固定
cinematic, Roger Deakins style, 电影感纪实
--ar 16:9
--no anime, cartoon, illustration, painting, drawing, sketch, CGI, 3D render
--s 400
```

**注意（**避免失败**）**：
- 不要混多场景（"工作室+街道"）
- 不要 6 视角（视角过多会跑偏）
- **必须模糊处理敏感内容**（代码/文件/邮件）

### 3.3 物品资产（Object Reference）

**核心目的**：跨镜头保持物品一致（如手机、武器、文件）。

**5 大要素**：

1. **物品类型**（"极简 AI 助手对话框"）
2. **形状**（"圆角 8px"）
3. **颜色**（"浅灰 #E0E0E0"）
4. **材质**（"半透明，透明度 70%"）

- 状态 3（变化中）—— 状态切换瞬间
- 状态 4（最终）—— 收束状态

## 第 5 章：3 大坑（**必避免**）

### 坑 1：超长描述（> 50 词）

**症状**：生成的图"模糊"、"概念不清"、"细节错位"。

**根因**：AI 注意力被稀释。

**修复**：
- 关键信息靠前（占 50% 注意力）
- 风格/光线简短（1-2 个词组）
- 砍掉所有"冗余"描述

### 坑 2：风格矛盾

**症状**：生成的图"风格混乱"、"光影错位"。

**根因**：多个风格锚点打架（"cinematic + animation + 3D render"）。

**修复**：
- 选**单一**风格锚点
- 跨模态一致（"cinematic" 配 "ARRI Alexa"，不配 "cartoon"）

### 坑 3：参考图模糊

**症状**：4 视图脸变了。

**根因**：参考图不清晰（< 1K 分辨率）。

**修复**：
- **2K/4K 高清参考图**（必备）
- 单主体参考（不要多人）
- 干净背景（避免 AI 跑偏）

## 第 6 章：失败模式与修复

### 失败 1：手部畸形

**症状**：6 根手指、手臂弯折。
**预防**：`--no deformed hands, extra fingers, bad anatomy`
**修复**：局部重绘或换用 nebula-ultra 编辑。

### 失败 2：脸崩（中景脸）

**症状**：中景脸"诡异谷"（眼睛错位、皮肤塑料感）。
**预防**：避免 50mm 中景脸，用 35mm 或 85mm。
**修复**：用 85mm 特写替代。

### 失败 3：文字错字

**症状**：UI 文字乱码。
**预防**：`--no 错字, 拼写错误, 模糊文字`
**修复**：换用 nebula-2-flash 重生成。

### 失败 4：跨镜头角色不一致

**症状**：4 视图脸变了。
**预防**：用 Lib Navo Pro 编辑（不是重写）。
**修复**：固定种子 + 同一参考图。

### 失败 5：环境漂移

**症状**：同一工作室，前后镜头风格不同。
**预防**：用 Lib Navo Pro 锁定主场景，再用悠船 V8.1 生成其他视角。

- 电影感 → **不**用 Lib Image（美学不如 V8.1）
- 极简概念 → **不**用 Navo Pro（长文本不如 Image）

### 铁律 3：失败用微调，不用重写

- 失败 1 次：微调 1-2 个关键词
- 失败 2 次：换参考图
- 失败 3 次：换模型

## 第 8 章：AI 看的元规则

### 元规则 1：注意力优先
- 关键信息靠前（占 50% 注意力）
- 风格锚点靠后（占 10%）
- 描述不超过 50 词

### 元规则 2：模型特性匹配
- 一致性需求 → nebula-ultra
- 文字需求 → nebula-2-flash
- 美学需求 → mj-v8.1
- 概念需求 → lib-image-2

### 元规则 3：负面约束必备
- 任何图：`--no deformed hands, extra fingers, bad anatomy, watermark`
- UI：`--no 错字, 模糊文字, 拼写错误`
- 电影感：`--no anime, cartoon, illustration, painting, drawing, sketch, CGI, 3D render`
- 速度优先：`--no 复杂, 装饰`

### 元规则 4：参考图是 70% 视觉决定
- nebula-ultra：参考图占 70% 注意力
- 提示词只补 30%
- **不要用提示词"对抗"参考图**

### 元规则 5：失败检查清单（5 步）

```
1. 提示词是不是太长了？（> 50 词）
2. 风格锚点是不是矛盾？（多个）
3. 参考图是不是高清？（< 1K）
4. 负面约束是不是够？（基础黑名单）
5. 模型选对了吗？（场景匹配）
```
