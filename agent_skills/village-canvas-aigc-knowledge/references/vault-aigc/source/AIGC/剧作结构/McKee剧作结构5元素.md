## 一、McKee 剧作核心 3 元素

### 元素 1：欲望 (Desire)
- **定义**：角色想要什么
- **实战**：每个场景的主角色必须有明确欲望
- **药神实战**：
  - 程勇欲望 1：赚钱（场景 1-9）
  - 程勇欲望 2：自保（场景 19-21）
  - 程勇欲望 3：救赎（场景 22-27）

### 元素 2：困难 (Obstacle)
- **定义**：阻止角色实现欲望的障碍
- **实战**：每个欲望必须有对应困难
- **药神实战**：
  - 困难 1：法律（场景 19-21）
  - 困难 2：良心（场景 22-23）
  - 困难 3：身体（场景 27）

### 元素 3：行动 (Action)
- **定义**：角色为克服困难采取的行动
- **实战**：行动 = 角色弧的推进器
- **药神实战**：
  - 行动 1：卖药（场景 6-9）
  - 行动 2：退出（场景 19-21）
  - 行动 3：重新卖药（场景 23-25）

## 二、McKee 5 大结构原理

### 原理 1：单一主角
- 一个故事 = 一个主角
- **实战**：程勇是药神唯一主角
- **例外**：群像戏 = 多个主角但有一个主线

### 原理 2：主角欲望必须是具体的
- 抽象欲望（"想幸福"）= 失败
- 具体欲望（"想卖药赚钱"）= 成功
- **药神实战**：程勇的"想卖药赚钱"非常具体

### 原理 3：困难必须是不可能克服的
- 容易克服的困难 = 平淡
- 不可能克服的困难 = 戏剧
- **药神实战**：法律不能违抗 = 不可能克服

### 原理 4：主角必须行动
- 等待 = 失败
- 行动 = 成功
- **药神实战**：程勇从"等待"到"行动"= 角色弧

### 原理 5：结局必须是"二选一"
- 主角成功 OR 失败
- 模糊结局 = 失败
- **药神实战**：程勇坐牢 = 失败，但医保改革 = 道德胜利

## 三、McKee 价值变化 4 阶段

### 阶段 1：初始价值（场景 1）
- **价值**：负（程勇失败）
- **场景**：卖印度神油，欠租三万二
- **实战**：开场建立负价值

### 阶段 2：价值正向变化（场景 5-9）
- **价值**：负 → 正（程勇看到机会）
- **场景**：发现印度药，决定走私
- **实战**：价值开始上升

### 阶段 3：价值负向变化（场景 19-21）
- **价值**：正 → 负（程勇退出）
- **场景**：怕被抓，宣布退出
- **实战**：价值开始下降

### 阶段 4：最终价值（场景 22-27）
- **价值**：负 → 极负 → 极正（程勇坐牢 + 医保改革）
- **场景**：黄毛死 → 程勇重新卖药 → 坐牢 → 医保改革
- **实战**：先极负再极正 = 情感高潮

## 四、McKee 角色弧 5 类型

### 类型 1：正向弧 (Positive Arc)
- 失败 → 成功
- **药神实战**：程勇的"坐牢"不是失败，是道德成功
- **占比**：40%

### 类型 2：负向弧 (Negative Arc)
- 成功 → 失败
- **药神实战**：黄毛的"逃出" = 失败（他死了）
- **占比**：30%

### 类型 3：平坦弧 (Flat Arc)
- 成功 → 成功
- **药神实战**：刘牧师、思慧 = 平坦弧
- **占比**：15%

### 类型 4：堕落弧 (Corruption Arc)
- 好人 → 坏人
- **药神实战**：假药贩子张长林
- **占比**：10%

### 类型 5：觉醒弧 (Awakening Arc)
- 普通人 → 觉醒
- **药神实战**：程勇 = 觉醒弧
- **占比**：5%

## 五、McKee 场景 4 元素

### 元素 1：场景目标 (Goal)
- 角色在场景中要达到的目标
- **药神实战**：
  - 场景 5：吕受益说服程勇卖药
  - 场景 21：吕受益让程勇回来
  - 场景 26：程勇认罪

### 元素 2：场景冲突 (Conflict)
- 角色遇到的对抗
- **药神实战**：
  - 场景 5：程勇的犹豫 vs 吕受益的请求
  - 场景 21：程勇的逃避 vs 吕受益的绝望
  - 场景 26：法律的控诉 vs 程勇的真心

### 元素 3：场景灾难 (Disaster)
- 场景结束时的负面结果
- **药神实战**：
  - 场景 5：程勇没回答 = 不确定性
  - 场景 21：程勇转身走 = 拒绝
  - 场景 26：程勇认罪 = 失败

### 元素 4：场景转折 (Turning Point)
- 从一个场景推到下一个的钩子
- **药神实战**：
  - 场景 5 → 6：程勇拨电话 = 决定
  - 场景 21 → 22：黄毛死 = 转折
  - 场景 26 → 27：法官宣判 = 转折

## 十一、McKee 5 大方法论

### 方法论 1：单一主角 + 单一欲望
- 一个故事 = 一个主角 = 一个欲望
- **实战**：程勇 = 主角 = "救赎"

### 方法论 2：欲望必须具体
- 抽象欲望 = 失败
- 具体欲望 = 成功
- **实战**："想卖药赚钱" 比 "想成功" 强 10 倍

### 方法论 3：困难必须不可能
- 容易克服 = 平淡
- 不可能克服 = 戏剧
- **实战**：法律 = 不可能克服

### 方法论 4：价值必须变化
- 静态价值 = 失败
- 变化价值 = 成功
- **实战**：程勇从"负"到"正"再回"负"再回"极正"

### 方法论 5：高潮必须是主角的最终选择
- 高潮不是事件，是选择
- **实战**：程勇选择重新卖药 = 高潮
