## 是什么

不是提示词模板，是一套完整的 **Seedance 2.0 导演操作系统**。28 个子技能 + 59 篇参考文献 + 126 个评估用例，覆盖从剧本到交付的全流程。

## 核心能力

- **导演引擎**：先读场景，定一个意图，再让摄像机/灯光/表演/声音都服务这个意图
- **序列规划**：长故事自动拆成多个镜头，保持连贯性
- **续写**：基于已生成片段继续，不从头猜
- **版权安全**：自动检测并改写不安全内容
- **故障排查**：坏片根因诊断+修复
- **专业电影人标准**：导演/摄影/制片/剪辑/调色/声音/字幕/交付——每个角色对应工作流
- **多语言**：中英日韩西俄六语种

## 28 个子技能

### 核心管线（16个）
访谈、序列规划、续写、提示词生成、压缩提示词、摄像机、动作、灯光、角色、风格、VFX、音频、管线、食谱、故障排查

### 治理层（3个）
版权安全、反废话、过滤修复

### 多语言（9个）
中英日韩西俄六语种词汇 + 中日韩三语种示例

## 跟我们体系的关系

装在 AIGC 导演子 agent 里，作为导演的"操作系统"。配合我们已有的 9 维分镜模板 + 因果动作链，让子 agent 从"懂提示词"升级到"懂导演"。
