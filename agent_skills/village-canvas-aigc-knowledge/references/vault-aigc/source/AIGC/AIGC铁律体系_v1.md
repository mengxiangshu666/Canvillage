## 核心铁律（23条）

### 1.6 Windows 本机操作只用 Python
PowerShell 有隐性坑：编码/引号转义/heredoc $variable 污染。不允许在 PS 里写复杂 Linux 命令。

### 1.7 整理笔记必须同步 Obsidian
写任何笔记/分析/计划 → 同时写两处：`memory/` + Obsidian vault。禁止只写 memory 不写 Obsidian。

### 1.8 AIGC 工具链 = 即梦AI + 可灵 + LibTV + TapNow
四件套。不用 ComfyUI / WebUI / Stable Diffusion WebUI。不推荐四件套之外的平台。

### 1.9 分镜脚本禁止使用概括词
禁止：孩子/父亲/警察/男人/女人。必须使用该剧本资产总表里的具体人物名。
自查：写完搜"孩子""男孩""父亲""警察"——出现且无资产名 = 错误，立刻改。

### 1.10 提示词必须写因果链，不写孤立结果
错误：「门关上」。正确：「阿强跨出门槛，转身从外面把门拉上。」
AI 不推断因果。写"效果/结果"之前，必须先写"谁做了什么导致了这个效果"。

### 1.17 提示词 = 物理因果动作链，不是画面描述
17镜全军覆没的教训：提示词写"画面长什么样"而不是"谁做了什么导致什么"，AI 就随机编。
核心：主体 + 身体部位 + 物理动作 + 方向 + 做完后的位置。

### 1.18 图片生成占 80-90% 重要性
AI 视频的本质是"把图片动起来"。输入图三要素：灯光方向、色调统一、构图完整，直接决定输出视频质量。
流程：先精修图片（nebula-ultra 统一灯光/色调/构图）→ 再跑视频。

### 1.19 剧本能力是底基
剧本有硬伤，再牛的摄影机参数/灯光/胶片都救不了。
三档：底基合格 → 可以进提示词；底基有洞 → 必须先修剧本；底基是狗屎 → 重写，提示词全部作废。

### 1.20 物理常识三校验
写任何含台词的剧本前必走三维校验：
- 字/秒校验：普通人说话 3-4 字/秒；压抑/虚弱 1.5-2.5 字/秒
- 呼吸校验：每两句台词之间至少 0.5 秒沉默
- 环境音最低占比：对话场景 ≥40%、紧张追逐 ≥60%、重场戏情感 ≥30%

### 1.21 物理常识是辅助，不是判决
三校验结果是告警，不是禁用。看见告警 → 重新思考这段意图 → 调整结构或信息密度。

### 1.22 GitHub 学习内化标准
学到一个思维框架，不是记下来，是直接用。判断标准：能不能改变我的某个判断/行为/标准。
6条已内化：ADR 格式 / Hooks over prompts / Clean Code triggers / HITL checkpoint / 一概念一词 / System Design Checklist。

### 1.23 每个大段时间灵活配置
15s 硬上限是安全阈值不是强制标准。段长 = 信息量 ÷ 节奏。
决策：列→物理校验→加运镜变化→决定最终段长，各段时长之和 ≤ 全片总时长。

### 1.25 autonomous-execution 核心
在明确范围内自主执行，遇到敏感操作（发送消息/购买/删除/凭证/系统配置/提权）→ 停住问用户。
错误处理：语法/拼写 → 自己修重试；缺文件 → 问用户；API 错误(只读) → 重试退避；认证错误 → 停住问用户。

## AIGC 导演 9 维提示词体系

| # | 维度 | 核心 |
|---|------|------|
| 1 | 摄像系统 | 机身+传感器+镜头+胶片+画幅比+运动 |
| 2 | 灯光设计 | 主光/光质/方向/光比/色温——有源光不补光 |
| 3 | 景别 | 大远→全景→中景→中近→近→特写 |
| 4 | 摄影参数 | 焦段（24/35/50/85mm）+ 光圈 |
| 5 | 运镜 | 固定/横摇/下摇/手持/推近/上摇 |
| 6 | 站位 | 每个角色的画面位置（画左/画右/画中/前景/背景） |
| 7 | 情绪 | 角色那一刻的具体状态（不是概括词） |
| 8 | 台词 | 完整对白+旁白（每镜标注） |
| 9 | 负面约束 | 全片通用18条 + 每镜专属2-6条 |

## 画风/风格 prompt 工具箱（140+ 风格锚点）

禁止直接写 "Pixar style" / "Disney style" / "Studio Ghibli style"（版权敏感），用技术描述替代。

| 风格 | 关键词 | 模型推荐 |
|------|---------|---------|
| 皮克斯 3D | `3D animated film look, soft global illumination, rounded shapes` | 悠船 V8.1 |
| 中式国潮 | `ink-and-cinnabar palette, zhongyong symmetry` | Seedream 5.0 Lite |
| 真人写实 | `photorealistic, real human skin, natural lighting, slight grain` | Lib Navo Pro + Kling O3 |
| 电影感 | `anamorphic cinema, Kodak Vision3 5219 500T, 35mm grain` | Kling O3 |

## 俯视调度图 SOP（锁定站位/走位/运镜三要素）

1. 列角色与场景
2. 生 Anchor 设定表
3. **生俯视调度图**（核心！90 度 2D 平面图 + 数字标签）
4. Prompt 引用俯视图坐标
5. 验证（逐帧坐标偏差 < 5%）

## 音画同步台词公式

```
【台词/旁白（@角色名，声线描述，语气描述，情绪描述）："具体台词内容"】
```

声线公式：年龄 + 性别 + 质感（沙哑/粗粝/虚弱/浑厚）+ 口音 + 状态
全局指令：`不要生成台词字幕 不要BGM 生成环境音和台词配音 同期声`
