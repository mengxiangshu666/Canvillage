# AIGC 画布深度学习 — 终极大总结

> 数据：LibTV 238 个项目 · 37,721 节点 · 22,584 条 prompt
> 方法：逐个深读 + 统计分析 + 跨项目模式识别
> 日期：2026-06-26

---

## 一、创作范式：精确型已取代探索型

### 数据
- **精确型（≤150节点）**：约 85% 的项目
- **中型（150-500节点）**：约 12%
- **探索型（>500节点）**：不到 5%（仅天骸、回声、南宋皇帝、电影院、贵司有尾、月老有点忙等）

### 含义
AIGC 创作已经成熟。早期的大规模试错（回声 2,148 节点）在 2026 年不再常见。当下的最佳实践是：
- 教程项目 30-100 节点
- TVC/广告 50-150 节点
- 短片/MV 100-300 节点
- 极少超过 500 节点

**不是"节点越多越好"，是"节点恰到好处"。**

---

## 二、核心工作流：image2image 是氧气

### 数据
- 超过 90% 的项目以 image2image 为主导（i2i > 60% 总操作数）
- **100% image2image（零 text2image）** 的极端案例：10+ 个项目
  - 产品TVC商业级广告、生来齐天MV、衣路随行、甜蜜盛宴、黄白、女装种草、碇真嗣童年、火车驶入山洞、极氪9x、十二生肖
- text2image 主导的项目极少（StarVideo2.0 绝佳体验、飞来一只干饭王等个别动画类）

### 含义
AIGC 的真相不是"写 prompt 生成图"，而是：
```
参考图 → 精修 → 精修 → 精修 → 生视频
```
text2image 是点火开关，用完就丢。95% 的时间花在 image2image 迭代上。

## 三、模型铁三角：2026 年已固化

### 标准三件套（220+/238 项目使用）

| 角色 | 模型 | 用途 |
|------|------|------|
| 视频引擎 | **star-video2** | mixed2video / singleImage2video |
| 精修引擎 | **nebula-ultra** | image2image 精修 |
| 文生图引擎 | **lib-image-2** | text2image 第一版草稿 |

### 新涌现的专用工具

| 工具 | 用途 | 使用项目 |
|------|------|---------|
| **volcano-video-upscaler** | 视频超分（720p→4K） | 冰峰之战、纯黑iPad、服装带货、儿童剧场等 |
| **volcano-subtitle-eraser** | 字幕擦除 | 紫夜、山海拾遗官、EVA漫画等 |
| **kling-v3-motion-control** | 视频运动精确控制 | 侏罗纪开口说话、黄白产品特效 |
| **mureka-8** | AI 音乐/音效生成 | 拳瓦2026、运动相机TVC、时尚服饰TVC |
| **motion-3.1** | 图像运动控制 | 点赞幻影、AI纪录短片、粉色凝视 |
| **seedream-4.5/5** | 新一代图像模型 | 大量项目已迁移 |

## 四、类别工作流模式

### TVC/广告（41 个项目）
**统一公式**：
```
lib-image-2（草稿 2-3 版）
→ nebula-ultra（精修 5-10 轮）
→ star-video2（生视频）
→ volcano-video-upscaler（可选：4K 输出）
```
特征：精确型、image2image 主导、大量负面约束、摄影机参数较少（<10 条）

### 短片/MV（37 个项目）
**变量更大**：节点数 80-2,148（回声极端案例）
特征：摄影机参数使用量远高于 TVC、结构化 prompt 更多、负面约束更多

### 教程（14 个项目）
**极简化**：全部 ≤100 节点
特征：故意减少步骤以清晰教学、模型选择教科书式（lib-image-2 + nebula-ultra + star-video2）、极少使用专用工具

### 国风/非遗（38 个项目）
**摄影机参数重度使用**：
- 楼兰迷冢：127 条
- 天骸：152 条
- 镇关：81 条
特征：追求电影级质感、国风题材天然需要更多细节控制

## 五、摄影机参数：被低估的竞争力

### 顶级使用者（摄影机 prompt >100 条）
1. 弑龙者：224 条
2. 天骸：152 条
3. 楼兰迷冢：127 条
4. 最后舞者：116 条
5. 月老有点忙：99 条
6. 苔（香水TVC）：98 条

### 含义
摄影机参数不是加分项，是**区分普通作品和电影级作品的分水岭**。写了"ARRI ALEXA 65 + Cooke S4 50mm T2.0"不等于就好看，但从来不写的项目一定缺少电影感。

### 顶级使用者（负面约束 >100 条）
1. 回声：310 条
2. 南宋皇帝：293 条
3. 王朝末日：293 条
4. 几楼了：130 条
5. 牙齿广告：133 条

### 含义
顶级项目有大量负面约束。不是偶然——这些项目知道"不要什么"能精确锁定视觉边界。

---

## 七、关键教训

1. **节点不是越多越好** — 238 个项目的共识：40-150 节点是最佳区间
2. **模型不是越多越好** — 铁三角（star-video2 + nebula-ultra + lib-image-2）已覆盖 90% 场景
3. **专用工具要会选** — volcano-video-upscaler 上 4K、mureka-8 配音乐、subtitle-eraser 去字幕
4. **TVC 有公式** — 产品广告已高度标准化，照着铁三角走就能出品质
5. **故事性项目需要更多摄影机参数** — 短片>MV>TVC>产品，叙事越强，镜头语言越重要
6. **image2image 是永远的答案** — "写好第一版 prompt"这个执念该放下了

> 顶级创作者不写更好的 prompt——他们做更多的 image2image。
