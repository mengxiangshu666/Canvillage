## 第 1 章：构图 12 法则（Composition）

### 1.1 三分法（Rule of Thirds）

**定义**：将画面用 2 横 2 竖分为 9 等份，主体放在 4 个交叉点上。

**情绪含义**：
- 主体偏左 + 右侧留空 = 期待、未知、未来方向
- 主体偏右 + 左侧留空 = 回顾、过去、沉思
- 主体居中 = 权力、庄严、对称美（少用，易呆板）

**AIGC 提示词写法**：
```
rule of thirds composition, subject positioned at left-third intersection,
negative space on right side, cinematic framing
```

**经典案例**：
- 《肖申克的救赎》雨中仰天：Andy 在左三分之一，雨水和天空占右三分之二 → 自由
- 任何好莱坞对话场景：说话者 eyes 对齐上三分之一线

### 1.2 引导线（Leading Lines）

**定义**：用画面中的自然线条（道路、栏杆、光束、建筑边缘）引导视线到主体。

**情绪含义**：
- 直线引导 = 目标明确、坚定
- 曲线引导 = 优雅、神秘、旅程感
- 多条线汇聚 = 命运交汇、不可避免
- 断裂/混乱线条 = 迷失、困惑、无序

**AIGC 提示词写法**：
```
leading lines composition, converging lines directing eye toward subject,
natural architectural lines framing the focal point
```

**经典案例**：
- 《2001 太空漫游》走廊透视：单点透视引导线 → 科技的冷酷
- 《公民凯恩》深焦镜头：窗户线条将视线导向少年 Kane

### 1.3 对称构图（Symmetry）

**定义**：画面左右或上下完全对称。

**情绪含义**：
- 完美对称 = 秩序、权力、庄严、压迫感
- 打破对称 = 混乱、转折、意外

**AIGC 提示词写法**：
```
perfectly symmetrical composition, centered framing,
Wes Anderson style symmetry, balanced left and right
```

**经典案例**：
- 韦斯·安德森所有电影：强迫症级对称 → 秩序中的荒诞
- 《闪灵》走廊：对称中的恐怖

### 1.4 框架内框架（Frame Within a Frame）

**定义**：用前景元素（门框、窗户、拱门、树枝）围住主体。

**情绪含义**：
- 框住 = 被限制、被困、窥视感
- 多层框 = 层层嵌套的现实、多重视角

**AIGC 提示词写法**：
```
frame within a frame composition, subject framed by doorway/archway,
foreground elements creating natural frame around subject
```

**经典案例**：
- 《搜索者》结尾门框：John Wayne 被门框框住 → 属于荒野，不属于文明

#### 1.4.1 框中框的三种大师母题 —— 杨德昌 / 侯孝贤 / 王家卫

三位华语作者导演的"框中框"代表三种不同的情绪含义，AIGC 可按情绪需求选择对应母题：

| 导演 | 框中框原型 | 情绪含义 | 代表作品 | 提示词要素 |
|------|-----------|---------|---------|-----------|
| **侯孝贤** | **拱门 / 门洞 / 远景框** | **历史压抑感** —— 被嵌套在更大叙事中，观众无法进入 | 《悲情城市》医院大堂拱门 + 黑暗房间的双重画框 | `arched doorway framing subject, dark room inner frame, distant background, period interior` |
| **王家卫** | **栏杆 / 百叶 / 前景遮挡密集** | **亲密中的隔离感** —— 人物近在咫尺但被层层隔开 | 《花样年华》走廊栏杆、《堕落天使》窗后金城武与杨采妮 | `foreground bars/blinds obstructing view, intimate close-up behind obstruction, voyeuristic composition` |
| **杨德昌** | **窗 / 玻璃 / 百叶窗** | **人际不信任 + 现代官僚倦怠** —— 看得见但穿透不了 | 《恐怖份子》小说家办公室百叶窗、《青梅竹马》玻璃隔断 | `window blinds dividing frame, glass partition, office interior, mutual visibility without connection` |

**AIGC 通用提示词模板**：
```
{arched doorway|bars|blinds|window frame|grate} in foreground,
subject framed within secondary frame,
layered depth between obstruction and subject,
{historical oppression|intimate isolation|modern alienation} mood
--no subtitle text
```

**成本提示**：框中框是**低成本高级感手法**——只需在 prompt 中加一个前景物体即可提升情绪密度，无需复杂建模 / 灯光。

### 1.5 负空间（Negative Space）

**定义**：大面积留白，主体只占画面一小部分。

**情绪含义**：
- 大量负空间 = 孤独、渺小、自由、极简
- 负空间在主体前方 = 期待、未知
- 负空间在主体后方 = 被遗弃、过去

**AIGC 提示词写法**：
```
negative space composition, small isolated subject in vast empty space,
minimalist framing, subject occupying only 10% of frame
```

**经典案例**：
- 《地心引力》太空镜头：宇航员 vs 无尽黑暗 → 绝对孤独

### 1.6 黄金比例（Golden Ratio / 1.618:1）

**定义**：螺旋曲线构图，比三分法更自然。

**情绪含义**：自然美感、和谐、古典美学

**AIGC 提示词写法**：
```
golden ratio composition, Fibonacci spiral guiding eye flow,
naturally balanced and harmonious framing
```

### 1.7 三角构图（Triangular Composition）

**定义**：画面元素形成三角形（正三角/倒三角）。

**情绪含义**：
- 正三角（底宽顶尖）= 稳定、权力、庄严
- 倒三角 = 不稳定、紧张、即将倒塌

**经典案例**：
- 《最后的晚餐》耶稣居中三角 → 神圣稳定

### 1.8 深度构图（Deep Space Composition）

**定义**：前景/中景/远景三层清晰分离，强调空间纵深。

**情绪含义**：世界的复杂性、人物与环境的关系

**AIGC 提示词写法**：
```
deep focus composition, foreground midground background clearly layered,
atmospheric perspective, depth conveyed through scale and overlap
```

**经典案例**：
- 《公民凯恩》：深焦 + 三层空间 → 权力结构可视化

### 1.9 平面构图（Flat Composition）

**定义**：消除纵深，画面如平面画布。

**情绪含义**：抽离、客观、图案化、漫画感

**AIGC 提示词写法**：
```
flat composition, no depth of field, graphic design aesthetic,
2D planar layering, Roy Andersson style tableau
```

### 1.10 荷兰角（Dutch Angle / Canted Frame）

**定义**：相机倾斜，水平线不平行。

**情绪含义**：不安、混乱、心理失衡、世界颠倒

**AIGC 提示词写法**：
```
dutch angle, tilted camera, canted frame, skewed horizon line,
disorienting perspective, psychological unease
```

**经典案例**：
- 《第三人》下水道追逐：持续荷兰角 → 道德颠倒的世界

### 1.11 高低角度（High/Low Angle）

**定义**：
- 高角度（俯拍）：相机从上往下拍
- 低角度（仰拍）：相机从下往上拍

**情绪含义**：
- 俯拍 = 脆弱、渺小、被支配、上帝视角
- 仰拍 = 强大、威严、威胁、英雄感
- 极俯（鸟瞰）= 命运、全景、抽离
- 极仰（虫视）= 压倒性的力量

**AIGC 提示词写法**：
```
low angle hero shot, camera looking up at subject from ground level,
imposing and powerful perspective
```

### 1.12 过肩镜头（Over-the-Shoulder / OTS）

**定义**：从 A 的肩膀后方拍 B，A 的肩/头在画面边缘。

**情绪含义**：
- A 肩虚化 = A 是观察者/倾听者
- B 清晰 = B 是当前焦点
- 两个人都在 = 关系镜头

**AIGC 提示词写法**：
```
over-the-shoulder shot, foreground shoulder slightly out of focus,
subject in midground, intimate conversation framing
```

### 1.13 远观即伦理：反特写构图（Kiarostami 物理距离美学）

**定义**：拒绝把人物作为画面中心或情绪焦点，把人物放进广阔环境或远距离构图中，让观众**物理上**保持距离并自己填充情感。

**情绪含义**：
- 沉思、冥想、生命的脆弱
- 拒绝情感消费（拒绝好莱坞"特写=情感入侵"的语法）
- **伦理距离**（观众无权直接进入人物的私密情感）
- 环境压迫 / 自然崇高

**AIGC 提示词模板**：
```
extreme wide shot, character tiny in vast landscape (15+ meters distant),
small figure against horizon, environment dominates 80%+ of frame,
no facial detail visible, audience must imagine emotional state,
Kiarostami contemplative pacing, post-Bazinian realism,
natural light, no close-up intrusion
```

**反 prompt 模板**（明确禁止特写）：
```
--no close-up, --no facial detail, --no emotional close-mic on subject,
--no tight framing, --audience constructs emotion themselves
```

**经典案例**：
- **Taste of Cherry（Kiarostami, 1997）**：反复出现**俯拍土路上 Badii 缓慢行驶的汽车**——人物只是车内的模糊形状，情感由观众自己投射
- **The Wind Will Carry Us（Kiarostami, 1999）**：主角 Behzad 经常**留在画面外或窗户后**——画面给村庄，不给主角
- **Ten（Kiarostami, 2002）**：整部片只用仪表盘上 2 个固定机位——物理限制即美学限制

**与"特写"的对照表**：

| 维度 | 传统特写（好莱坞）| 远观（Kiarostami 式）|
|------|-------------------|---------------------|
| 人物占比 | 40-70% 画面 | 5-15% 画面 |
| 情绪入口 | 观众直接进入 | 观众必须自己建构 |
| 与环境关系 | 人物主导 | 环境主导 |
| 道德态度 | 共情 / 消费 | 尊重 / 反思 |
| AI 时代适配 | 高（AI 强项）| 低（AI 默认避开）|

**AIGC 创作的反奇观价值**：
- AIGC 视频默认靠特写+面部微表情驱动情绪——这是 AI 的强项，也是 AI 的**陷阱**
- Kiarostami 反其道而行：让 AI 视频**避开自己擅长的路径**
- **核心洞察**：当 AI 让特写无限便宜，**远观反而变成奢侈品**

**配套技法**（针对 Kiarostami 风格短片）：
- 仪表盘 / 窗户 / 门框 / 走廊尽头——四种"远观物理装置"
- 锁死机位 + 角色在画面内缓慢移动（替代特写 = 用运动学代替表情学）
- 声音承担情感（`close-mic ambient soundscape`，距离感的视觉 + 亲密感的听觉 = 张力）

**AIGC 适配矩阵**：

| 模型 | 是否适合 Kiarostami 远观 | 原因 |
|------|--------------------------|------|
| Seedance 2.5 | ✅ 强 | 8 秒物理一致性强，仪表盘机位稳定 |
| Sora 2 | ✅ 强 | 长镜头 + 物理真实感强 |
| Kling 3.0 Omni | ✅ 强 | native audio 让"声音承担情感"成为可能 |
| Wan 2.2 | ✅ 强 | MoE 架构擅长静态长焦场景 |
| Runway Gen-4 | ⚠️ 中 | 多角色稳定性可，但 native audio 弱 |

**反 AIGC 默认逻辑的口诀**：
> "**AI 的强项是特写。Kiarostami 让你用 AI 做 AI 不擅长的事——这就是作者性。**"

## 第 2 章：镜头运动 10 式（Camera Movement）

### 2.1 推（Push-in / Dolly In）

**定义**：相机向前移动，靠近主体。

**情绪含义**：
- 慢推 = 亲密、专注、角色内心觉醒
- 快推 = 威胁、突袭、冲击
- 极慢推（creep）= 不安、悬疑

**经典案例**：
- 《好家伙》餐厅长推：Henry 带 Karen 进 Copacabana → 进入他的世界

**AIGC 提示词写法**（视频）：
```
slow push-in dolly movement, camera gradually moving closer to subject,
increasing intimacy and emotional intensity
```

### 2.2 拉（Pull-back / Dolly Out）

**定义**：相机向后移动，远离主体。

**情绪含义**：
- 慢拉 = 揭示环境、告别、疏离
- 快拉 = 震惊、世界观崩塌

**经典案例**：
- 《毕业生》结尾大巴后拉：Ben 和 Elaine 的笑容逐渐凝固 → 冲动后的空虚

### 2.3 摇（Pan）

**定义**：相机固定在三脚架上，水平旋转。

**情绪含义**：
- 左→右 = 探索、发现、跟随
- 右→左 = 回顾、倒叙
- 快速甩摇（whip pan）= 切换、能量、喜剧节奏

**经典案例**：
- 《拯救大兵瑞恩》诺曼底登陆：手持摇 → 战争混乱

### 2.4 俯仰（Tilt）

**定义**：相机固定，垂直旋转。

**情绪含义**：
- 上摇（tilt up）= 揭示高度、庄严、崇拜
- 下摇（tilt down）= 揭示地面、坠落、揭露

### 2.5 跟（Tracking Shot）

**定义**：相机与主体平行移动。

**情绪含义**：
- 侧面跟 = 同行者视角、伙伴关系
- 正面跟（后退拍）= 面对未知、退守
- 背后跟 = 尾随、未知目的地

**AIGC 提示词写法**：
```
lateral tracking shot, camera moving parallel alongside walking subject,
steady dolly movement matching subject speed
```

### 2.6 升/降（Crane / Jib / Boom）

**定义**：相机在摇臂上升降。

**情绪含义**：
- 升起（crane up）= 超越、升华、告别、上帝视角
- 降下（crane down）= 进入、降临、关注

**经典案例**：
- 《乱世佳人》火车站伤员：升起 → 战争的规模

### 2.7 手持（Handheld）

**定义**：摄影师手持相机，产生自然晃动。

**情绪含义**：
- 轻微晃 = 纪录片感、真实、亲密
- 剧烈晃 = 混乱、恐慌、失控
- 呼吸感晃 = 第一人称主观

**经典案例**：
- 《拯救大兵瑞恩》《鸟人》《谍影重重》系列

**AIGC 提示词写法**：
```
handheld camera movement, slight natural camera shake,
documentary style, immersive first-person perspective
```

### 2.8 斯坦尼康/稳定器（Steadicam / Gimbal）

**定义**：机械稳定系统让相机"漂浮"移动。

**情绪含义**：超现实流畅、幽灵视角、全知旁观

PMC 2025 研究：Steadicam 在正面情绪场景（valence 2.82）中评分最高，手持最低。

**经典案例**：
- 《闪灵》走廊跟拍：Danny 骑三轮车 → 诡异漂浮感
- 《好家伙》Copacabana 长镜头

### 2.9 推拉变焦（Dolly Zoom / Vertigo Effect）

**定义**：相机前移 + 变焦后拉（或反之），背景透视剧变但主体大小不变。

**情绪含义**：眩晕、世界观崩塌、重大领悟、认知失调

**经典案例**：
- 《迷魂记》钟楼：Scottie 的恐高症
- 《大白鲨》海滩：Brody 看到鲨鱼攻击

**AIGC 提示词写法**：
```
dolly zoom effect, vertigo shot, camera moving forward while zooming out,
background perspective dramatically shifting, disorienting visual effect
```

### 2.10 固定（Static / Locked-off）

**定义**：相机完全不动。

**情绪含义**：
- 画框内运动 = 观察者、剧场的第四面墙
- 完全静止 = 死亡、时间的停滞

**经典案例**：
- 小津安二郎榻榻米镜头：固定低机位 → 生活的凝视

**运动速度的情绪映射**：

| 速度 | 情绪 |
|------|------|
| 极慢（creep）| 不安、悬疑、仪式感 |
| 慢 | 沉思、庄严、浪漫 |
| 中速 | 叙事推进、日常 |
| 快 | 能量、紧急、喜剧节奏 |
| 极快（whip）| 混乱、切换、冲击 |

## 第 4 章：灯光体系（Lighting）

### 4.1 三点布光（Three-Point Lighting）

**定义**：电影灯光的基础公式。

```
Key Light（主光） + Fill Light（辅光） + Back Light（背光/轮廓光）
```

| 灯光 | 位置 | 强度 | 功能 |
|------|------|------|------|
| 主光 | 主体侧前方 30-45° | 100% | 塑造主体形态 |
| 辅光 | 主体另一侧 | 30-50% | 填补阴影，控制反差 |
| 背光 | 主体后上方 | 50-80% | 分离主体与背景 |

### 4.2 光比（Lighting Ratio）

**定义**：主光+辅光 : 辅光（Key+Fill : Fill）

| 光比 | 名称 | 情绪 |
|------|------|------|
| 2:1 | 低反差 | 自然、柔和、喜剧、日间 |
| 3:1 | 中反差 | 标准剧情、叙事 |
| 4:1 | 中高反差 | 戏剧性、紧张 |
| 8:1 | 高反差 | 悬疑、黑色电影、恐怖 |
| 16:1+ | 极端反差 | 恐怖、表现主义、噩梦 |

**AIGC 提示词写法**：
```
high contrast lighting, 8:1 lighting ratio, deep shadows,
single key light source, dramatic chiaroscuro
```

### 4.3 6 大灯光风格

| 风格 | 特征 | 情绪 | 经典案例 |
|------|------|------|---------|
| **伦勃朗光**（Rembrandt）| 脸颊三角光斑 | 经典、深度、人物内在 | 所有古典肖像 |
| **蝴蝶光**（Butterfly / Paramount）| 鼻下蝴蝶形阴影 | 魅力、好莱坞明星 | 玛琳·黛德丽 |
| **侧光**（Split Lighting）| 半脸亮半脸暗 | 双重人格、内心冲突 | 《教父》 |
| **低调光**（Low-Key）| 大面积暗 + 局部亮 | 神秘、危险、黑色电影 | 《七宗罪》《银翼杀手》 |
| **高调光**（High-Key）| 画面明亮均匀 | 喜剧、广告、天真 | 《老友记》 |
| **环境光**（Ambient / Natural）| 只用场景现有光源 | 真实、纪录片 | 《荒野猎人》 |

| 底光（underlighting）| 恐怖、非人、怪异 |
| 顶光（top light）| 神圣、审判、压迫 |

## 第 10 章：王家卫视觉签名技法（Step-Printing × 慢快门 × 广角 × 霓虹色）

> 来源：3DAY Studio、Doyle 自述、In Depth Cine、Airiti Library 学术论文、independent-photo
> 价值：**这是 AIGC 视频生成最容易模仿也最容易翻车的"电影感"模板**

### 10.1 抽帧 / 偷格（Step-Printing / Undercranking）

**原理**：
- **Step-printing**（抽帧复制）：24FPS 标准拍摄，每帧复制 2-4 次再以 24FPS 播放 → 产生**卡顿式慢动作**，帧与帧之间不连续。
- **Undercranking**（欠速拍摄）：直接以 6-12FPS 拍摄（而非 24FPS），每帧曝光时间拉长（≈1/12 秒），快门更慢 → 产生**拖影模糊**。
- 王家卫 + Doyle 的组合：先用 undercranking 让快门变慢产生 smear（拖影），再做 step-printing 让画面一格一格卡顿。

**经典案例**：
- 《重庆森林》警察 663 喝咖啡，路人模糊流过 → "世界在动，他静止" → 主观孤独可视化
- 《阿飞正传》《堕落天使》多次出现

**数字时代还原方法**（Austin F. Schmidt 实验）：
- Arri Alexa 拍摄 + 后期 Optical Flow 抽帧 + 调慢快门模拟
- Premiere/DaVinci：调低 playback speed 到 20-40% + 手动复制帧

**AIGC 提示词写法**（视频）：
```
slow motion at 6-12 FPS with stutter effect,
motion smear and blur, step-printing aesthetic,
Wong Kar-wai style slow-mo, ghostly smeared movement,
each frame duplicated for strobing effect
```

⚠️ **AIGC 翻车点**：Sora 2 / Veo / Wan 2.2 等视频模型的帧率一般是 24-30FPS，无法直接生成抽帧效果。需要：
- 用传统慢镜头模型生成（如 Sora 2）→ 后期 DaVinci 抽帧
- 或在提示词中强调"strobing motion, frame-by-frame stutter, choppy slow motion"

### 10.2 慢快门拖影（Slow Shutter / Smear）

**原理**：快门速度 1/30 或更慢，运动主体留下长拖影。

**经典场景**：
- 《重庆森林》王菲在酒吧，背景人头攒动拖成长条光带
- 《花样年华》苏丽珍与周慕云在走廊交错，衣角拖影

**AIGC 提示词写法**（图片/视频）：
```
slow shutter speed 1/30, motion blur trails,
ghosting effect on moving subjects,
long exposure photograph aesthetic,
neon lights smeared into ribbons of color
```

### 10.3 极广角手持（Ultra-Wide Handheld）

**原理**：
- Christopher Doyle 在《堕落天使》使用 **6.8mm 极广角**镜头，逼近演员面部
- 狭窄空间（香港走廊、出租屋）+ 广角 = 人物被空间挤压，边缘畸变
- 加上手持 → 浮动、不安、亲密 + 扭曲共存

**经典案例**：
- 《堕落天使》金城武在窄屋独白：6.8mm + 手持 → 神经质、孤独、压迫
- 《东邪西毒》沙漠广角：极广反而显出荒凉辽阔

**AIGC 提示词写法**：
```
6mm-9mm ultra-wide angle lens, extreme barrel distortion,
close-up to subject face, cramped Hong Kong apartment,
handheld camera, intimate yet distorted perspective
```

### 10.4 霓虹色彩与"绿色 = 背叛"符号系统

**色彩符号学**：
| 色彩 | 符号含义 | 经典案例 |
|------|---------|---------|
| **绿色** | 背叛、嫉妒、被"戴绿帽" | 《花样年华》办公室绿墙、绿电话、绿旗袍 |
| **红色** | 欲望、激情、危险 | 张曼玉去见周慕云时换上的红色旗袍 |
| **黄/金** | 怀旧、年代感、旧上海 | 全片低色温暖色调 |
| **粉红/浅紫** | 暧昧、压抑的浪漫 | 苏丽珍粉 vs 周慕云紫 |
| **霓虹蓝紫** | 香港都市、夜的孤独 | 《重庆森林》《堕落天使》重庆大厦 |

```

### 10.5 不规则构图 + 镜面反射

**核心技法**：
- 反射倒影（玻璃、镜面、水洼）→ 让主体在画面中"被复制/被分裂" → 双生、矛盾、隐藏
- 拒绝"完美对齐" → 人物偏置、画面倾斜、打破三分法
- 透过前景遮挡（如百叶窗、栏杆、肩膀）拍主体 → 窥视感、未完成感

**经典案例**：
- 《花样年华》无数镜面反射：苏丽珍在镜子里看自己 → 自我审视
- 《春光乍泄》何宝荣在布宜诺斯艾利斯旅馆镜中

**AIGC 提示词写法**：
```
subject visible through foreground obstruction,
mirror reflection of character, voyeuristic framing,
off-center composition, blinds/lattice casting shadows,
Wong Kar-wai peek-a-boo framing
```

## 第 11 章：杨德昌 + 侯孝贤视觉签名 —— 亚洲作者电影的静默长镜美学

### 12.1 杨德昌的"几何学城市" —— 编辑型导演的精确构图

**核心原则**：杨德昌原是工程师 + 漫画家，他把工程学的精确感带入电影——靠**剪辑 + 构图**完成观点，不靠单镜头的"魔力"。

- **窗 / 玻璃 / 百叶窗** = 看得见但穿透不了的人际关系

- **陡峭中央透视** = 现代社会的压迫感
- **空镜延绵**（Antonioni 式"场景在人物之前开始，在人物之后结束"）
- **3 个平面几何镜头**替代动作镜头（《恐怖份子》欧亚女孩倒下 sidewalk）

- **焦段**：35-50mm 标准镜头为主，少用长焦
- **景深**：中景到深焦，多层次构图
- **机位**：中远景，慢推 / 慢拉，少有手持
- **剪辑**：4-8 秒"原子镜头"靠 montage 形成观点
- **色温**：偏冷调，5500K-6500K（现代都市感）

```

### 12.2 侯孝贤的"凝视的电影" —— 长焦 + 静态机位的诗意

**核心原则**：Nornes & Yeh 称侯孝贤的视觉风格为"**自我克制的风格学**"——限制即表达。他靠**长焦 + 静态 + 非职业演员**创造"历史在远处发生"的疏离感。

#### 12.2.1 核心技法 —— 长焦长镜头
- **75-150mm 长焦**：压缩空间，背景浮雕化
- **静态三脚架**：几乎完全无相机运动
- **非职业演员**：远距离拍摄不被机器压迫，表演更微妙
- **平均镜头长度 42 秒**（《悲情城市》223 个镜头 / 158 分钟）
- **省略叙事**：关键事件发生在镜头与镜头的接缝之间

#### 12.2.2 视觉母题
- **框中框**：医院大堂拱门 + 黑暗房间 = 双重画框 = 历史压抑
- **门 / 窗 / 廊柱**：日常空间的诗学
- **深焦远景**：人物与历史同时呈现，背景不糊化
- **自然光 + 蜡烛光**：避免人工打光的历史感
- **段间省略**：场景之间的空白由观众补充

#### 12.2.3 镜头参数
- **焦段**：**100mm 长焦（强制）**——侯孝贤美学的核心物理基础
- **景深**：浅景深 + 远距离主体 = 空气感透视
- **机位**：固定三脚架，零移动
- **时长**：10-15 秒以上长镜头（AIGC 必须用 Sora 2 / Wan 2.2）
- **色温**：偏暖自然光 4000-5000K + 烛光暖橙

#### 12.2.4 可复用提示词模板

**A. 侯孝贤式长焦凝视（悲情城市 / 海上花式）**
```
telephoto lens 100mm, static locked-off tripod,
distant non-actor subject, compressed background,
deep focus on background events, period interior (1940s-60s Taiwan),
natural ambient light 4500K, candle warm accents 2800K,
Hou Hsiao-hsien aesthetic, contemplative pacing,
unhurried duration, layered foreground/midground/background
```

**B. 框中框 + 双重画框（悲情城市医院式）**
```
arched doorway framing secondary subject,
darkened inner room reducing visible screen space,
frame within frame within frame composition,
period hospital/household, soft diffused light 5000K,
historical suppression mood, distant observation
```

**C. 省略叙事 + 空气感（最好的时光 / 咖啡时光式）**
```
static wide shot 85mm, characters sitting in cafe interior,
long take with minimal action, off-screen events implied,
window reflections + steam + cigarette smoke haze,
golden hour backlight 3200K, contemplative Tokyo/Taipei setting,
viewer fills narrative gaps, Ozu/Hou minimalism
```

### 12.3 杨德昌 / 侯孝贤 / 王家卫 三人对照提示词决策表

| 情绪需求 | 导演选择 | 关键 prompt 词 | 推荐模型 |
|---------|---------|---------------|----------|
| 冷峻理性 / 现代都市孤独 | **杨德昌** | `35mm medium shot, orthogonal architecture, axial symmetry, glass partitions, muted palette` | Seedance 2.5 + montage |
| 历史沉思 / 时光流逝 | **侯孝贤** | `telephoto 100mm, static tripod, distant non-actor, deep focus, period interior, natural ambient light` | Sora 2 / Wan 2.2（长镜头）|
| 心理孤独 / 都市暧昧 | **王家卫** | `6fps step-printing motion blur, neon Hong Kong night, handheld intimate close-up` | Kling + 后期帧重复 |
| 现代极简 / 家庭切片 | **是枝裕和**（受三人影响）| `static 50mm, household interior, family drama, Ozu-style low angle` | Seedance 2.5 |

### 12.4 关键洞察：长焦 + 静态 = 低成本诗意

侯孝贤的长焦风格可被**低成本 AIGC 工作流平替**：
- **长焦** → Seedance / Kling 写 `telephoto lens 100mm, compressed background, distant framing, shallow depth of field`
- **非职业演员** → 避免用真人 LoRA + 强面部锁定，改用**风格化数字人**（LibTV 数字人模块）
- **静态机位** → prompt 写 `static tripod, locked camera, no camera movement`
- **自然光** → 写 `natural ambient light, no artificial studio lighting, candle/window practical light`

**核心洞察**：长焦之所以美，本质是"压缩空间 + 背景浮雕化 + 观众被动"——AI 用 `focal length` + `depth of field` + `subject distance` 三参数组合即可逼近。

### 12.5 日本三轴范式：Ozu / Mizoguchi / Suzuki Seijun 的"反奇观 + 反心理学"（2026-07-02 学习新增）

> 与 §12.1 杨德昌 / §12.2 侯孝贤 / §12.3 王家卫同一谱系下，进一步深入到日本本土三轴——三人都是"反 Hollywood 主流"的最强坐标，但具体技法与杨德昌 / 侯孝贤 / 王家卫不同。

**A. Ozu（小津安二郎）的"榻榻米 + 50mm + ellipses" 三件套**

| 核心技法 | 实现 | AIGC prompt 锚点 |
|---------|------|----------------|
| **榻榻米机位（tatami shot）** | 摄像机放在榻榻米上的跪坐眼高，实际常常更低——离地 1-2 英尺，需要特制三脚架和抬高布景 | `tatami shot, knee-level camera, 30-50cm above ground, forced low-angle` |
| **50mm 镜头（一辈子）** | 全职业生涯只用 50mm——被认为最接近人眼 | `50mm prime lens, eye-of-human-vision, zero optical distortion` |
| **反 eyeline match（无视轴匹配）** | Roger Ebert 引："Ass't suggested shoot conversations so characters looking at each other. Ozu agreed to test: 'You see? No difference!'" | AIGC 多人对话 prompt 应**主动打破 eyeline match**：`conversational blocking with deliberately mismatched eyelines, characters look away from each other` |
| **ellipses 全部省略** | An Autumn Afternoon 婚礼只在对话里"被提及"，下一段才出现，婚礼本身永远不拍——"eschew melodrama by eliding moments that would often be used in Hollywood" | AIGC 短片应**主动省略 High Concept 戏剧瞬间**：fade-in/fade-out 跳过死亡 / 决裂 / 婚礼，让"未呈现"自己发酵 |
| **Agfacolor 红** | 选 Agfacolor，因为"capture reds much better than any other colour process" | `agfacolor-inspired reds, tomato-red curtain, Japanese-flag-level saturated crimson as accent` |
| **完全停用 tracking shots** | "Ozu moved the camera less and less, ceased using tracking shots altogether in his colour films" | `fixed-camera only, no dolly, no tracking, character movement within frame` |
| **静态物件 + 音乐过渡** | 场景切换不淡入淡出，靠**静态物件**（建筑外景）作过渡；非剧情音乐只用在过渡 | `scene transition via static architectural object shot + music bridging transitions, no fades` |

**Ozu 隐含的 AIGC 命题**：**Ozu 的镜头不动，但观众却在动**——观众从"看机器如何运镜"转入"看人在场景里如何生活"。AIGC 模型的种子（seed）天然适合 Ozu 风格——一镜生成就是一次"过日子"。

**B. Mizoguchi（溝口健二）的"散卷轴 + 70% crane + Southern School 中国画" 三件套**

| 核心技法 | 实现 | AIGC prompt 锚点 |
|---------|------|----------------|
| **"一卷散卷轴"美学（scroll-painting）** | Mizoguchi 给摄影师 Kazuo Miyagawa 指令："unroll seamlessly like a scroll-painting" | `uninterrupted scroll-painting camera, long take as unrolled Chinese landscape, no internal cuts` |
| **70% crane shots** | Miyagawa 1992 披露：Ugetsu 70% 镜头是 crane 拍的 | `crane shot 70%+ of duration, vertical + horizontal freedom` |
| **Southern School 中国画灵感** | 受中国南方画派启发——particularly aspired to | `Southern School Chinese scroll-painting composition, negative space, asymmetric horizontal scroll` |
| **Noh mask + hikimayu 拔眉** | Lady Wakasa 妆容 = Noh 戏面具，用 hikimayu 拔眉法 | `Noh mask inspired face makeup, hikimayu eyebrow, classical Japanese theatre face` |
| **靠近日落 + 低光（near sunset）** | Miyagawa 一直把光压低，赶到日落时段拍 | `low-key ambient light, near-sunset warm fill, kept lighting low throughout` |
| **Noh 配乐 + 竖琴限超自然** | Hayasaka 配乐：geza music（歌舞伎） + Noh chanting + drums + flutes，**竖琴仅限超自然场合** | `Noh chanting + drum + flute + harp restricted to supernatural moments, bells in improbable places` |
| **Miyagawa 是唯一被 Mizoguchi 表扬过的摄影师** | "This was the only occasion in which Mizoguchi complimented him for his camera work" | AIGC 摄影应该作为独立可调维度，不是导演提示词的附属 |

**Mizoguchi 对 AIGC 的核心命题**：**Mizoguchi 把"画"（painting）变成"电影"——AI 模型本质也是从 latent space 渲染画，AIGC 长镜头的"卷轴感"是模型天生优势**。Seedance 2.5 的 30 秒原生 = 直接对应 Mizoguchi 的"散卷轴单段"。

**C. Suzuki Seijun（鈴木清順）的"1 天剪辑 + CinemaScope 黑场 + 波普 + 抽象跳跃" 三件套**

| 核心技法 | 实现 | AIGC prompt 锚点 |
|---------|------|----------------|
| **不用 storyboard** | "Suzuki did not use storyboards and disliked pre-planning. He preferred to come up with ideas either the night before or on the set" | AIGC 短片应**允许 prompt 即兴**——首次生成不一定要完美，可让 prompt 在 test 时即兴迭代 |
| **Hachiro Guryu"八人组"** | 编剧 = Suzuki + Takeo Kimura + Atsushi Yamatoya + 5 个助导 8 人合用笔名"八人组" | AIGC = 同样"多人合用笔名"工具——不要追求单一 LLM 输出，多模型多次采样合并 |
| **1 天剪辑** | "The film was edited in one day, a task made easy by Suzuki's method of shooting only the necessary footage" | AIGC 后期应**短而快**——不要 6 周精修，单 4-8 秒段落可在 1 小时内迭代 50 版 |
| **CinemaScope 黑场 + chiaroscuro** | 2.35:1 CinemaScope 黑白片，因宽画幅人物前移不"动态"，Suzuki 改用 spotlight + chiaroscuro | `2.35:1 anamorphic CinemaScope, high-contrast chiaroscuro, spotlit chiaroscuro expressionism` |
| **moiré 雨景 + 无声场** | David Chute 评 Suzuki 复刻前作的蓝色 moiré 雨景，但这次加无声音效 | `blue moiré rain pattern over windshield, anechoic dialogue, loss-of-sea cinematography` |
| **抽象跳跃剪辑** | "Suzuki frequently abandoned continuity, favouring abstract jumps in time and space as he found it made the film more interesting" | AIGC 短片应**主动打破时序**：从 A 跳到 B，看似无逻辑，但情绪延续 |
| **波普 + 歌舞伎 + 超现实 + 荒诞** | Philip Brophy 评 Suzuki："heightened otherness"——同时代四大标签 | AIGC prompt 应同时叠 3-4 种风格：`pop-art aesthetic + kabuki stylization + surrealism + postmodern absurdism` |

**Suzuki 对 AIGC 的核心命题**：**Suzuki 把"垃圾"变"圣物"——Nikkatsu 的 B 级制作 + 黑帮俗套 + 25 天拍摄周期，最终成为反文化经典**。AIGC 的"低精度 / 短时长 / 模型限制"恰恰是 Suzuki 风格的最佳土壤——AIGC 不能拍 Spielberg，但 AIGC 能拍 Suzuki。

**D. 三轴决策表**

| 维度 | **Ozu（小津）** | **Mizoguchi（溝口）** | **Suzuki Seijun（鈴木）** |
|------|--------------|-------------------|----------------------|
| **机位学** | tatami 30-50cm + 50mm prime | 70% crane + scroll-painting 移动 | CinemaScope 固定 + spotlight 戏剧 |
| **戏剧性策略** | **全部省略**（婚礼不出场）| **缓慢浮出**（反战主题自己浮现） | **主动制造混乱**（波普 + 抽象跳跃）|
| **音乐** | 过渡音乐 only | Noh + geza + 竖琴限超自然 | atonal + bells + anechoic 对话 |
| **色彩** | Agfacolor 暖红（极少鲜艳）| 黑白 + 烟 + 日落低光 | 黑白 + 蓝 moiré 雨 + 红蕾丝 |
| **AIGC 适配度** | ★★★★★（固定机位 + 50mm + 模型最低材耗费）| ★★★★（30 秒原生 + 卷轴可 prompt 化）| ★★★★（混乱 + 波普 + 跳跃 = 模型出错反而效果好）|
| **Seedance 2.5 对接** | `tatami shot + fixed 50mm + 15-30s scene-level duration` | `scroll-painting + crane ascending/descending + 15-30s continuous take` | `2.35:1 + chiaroscuro + 3-8s abstract jump cuts` |

**E. "反 Hollywood" 三大承诺（Ozu + Mizoguchi + Suzuki 公约数）**

```
[反 Hollywood AIGC 配方]
- 机位：永远不 eye-level
- 对话：少于 10% 时长
- 省略：所有"重要戏剧瞬间"不直接拍
- 戏剧性：让观众自己脑补
```

——这是 Ozu + Mizoguchi + 伊朗极简 + Ceylan 的公约数——**AIGC 应该学这个公约数，反抗 Hollywood 三件套（eye-level + 对话反打 + 高潮叠满）**。

**F. Ozu 启发 AIGC "音色不靠声卡靠剪辑"**

```
[Ozu 音频配方]
- diegetic sound: 100% ambient（环境声）
- non-diegetic music: 0%
- transition music: 100%（连接镜头之间的唯一音乐）
- 音效本身: 不放任何 diegetic 音效（不强调动作 / 脚步 / 关门）
```

——AIGC 视频模型的音频生成常"铺满"，Ozu 教 AIGC：要么纯背景，要么纯过渡，中间不留音乐。

**G. Suzuki Seijun 的"反常 sensory anchor"作为 AIGC 角色记忆锚点**

Suzuki 给 3 号杀手加"嗅沸腾米性唤起"——AIGC 角色定妆应用同类机制：

```
[AIGC 角色反常 sensory anchor]
- 不靠"创伤背景"取情感
- 而靠"反常感官偏好"建立记忆点
- 例：嗅米、摸织物、敲木头、空杯吃汤……
- 模型生成时加 sensory anchor: 角色每次出现时主动重复一种反常感官动作
```

——能避免"千篇一律的 AIGC 角色"。

## §声音家族相似性原则（Dune FDR 哲学 · 2026-07 学习新增）

### 核心概念

Villeneuve 在 Dune 声音设计简报中的原话：

> "I wanted it to feel like real it will sound close to the spirit of the helicopter it must not sound like a helicopter but in the same family."

**声家族原则**：同一个虚构生物 / 阵营的每一种声音必须**共享同一组基频与谐波结构**，让观众潜意识识别为"同一物种 / 同一阵营"。这是反"千篇一律科幻奇观"的根本策略。

### 声家族四要素

1. **基频统一**：同物种的飞行 / 攻击 / 鸣叫共享 50-200Hz 基础频段
2. **谐波结构**：相同音色指纹（如金属摩擦 / 生物膜振动）
3. **节奏基因**：同阵营的 diegetic 背景层共享节拍
4. **空间定位**：同物种发声的空间来源高度一致（屏幕上方 vs 下方）

### Dune 三阵营声家族对照表

| 阵营 | 基频 | 谐波 | 节奏 | 典型场景 |
|------|------|------|------|---------|
| **Harkonnen 工业化恐怖** | 45-80 Hz | 金属摩擦 + 齿轮咬合 + 钢铁弯曲 | 4/4 工业节拍 + 远方哀号 | Giedi Prime 工业星球 / 室内压迫戏 |
| **Atreides 古典英雄** | 120-200 Hz | 古乐器 + 人声低语 + 弦乐齐奏 | 6/8 史诗节奏 | Caladan 海滨 / 家族议会 |
| **Fremen 沙漠生存** | 80-150 Hz | 风沙摩擦 + 织物拍打 + 部落吟唱 | 不规则沙漠节奏 | Arrakis 沙海 / 部落仪式 |

### AIGC 应用

```yaml
faction_sound_dna:
  harkonnen:
    base_freq: "45-80 Hz low-frequency oppression"
    harmonic: "metal friction, gear meshing, steel bending"
    rhythm: "4/4 industrial beat + distant wailing"
    ambience: "steam leak + heavy machinery + whisper"
    forbidden: "bright high freq / birdsong / warm wood"
```

### FDR（Fake Documentary Realism）哲学

**来源**：Variety 2022 Dune 声音专家专访（Mark Mangini + Theo Green 完整披露）

> "Denis's mandate was to ground it in an organic reality. He didn't want it to feel science-fiction-y. He wanted you to watch the film and feel those sounds existed in acoustic reality. Theo and I had a philosophy: **FDR, or Fake Documentary Realism**."

**3,200 个独立录音 + 750 个音频通道** —— 全部从真实物理声源出发。具体案例：
- Mark Mangini **在死亡谷沙漠埋接触式麦克风**，用锤子砸沙子作为沙虫 thumper 基础声
- 录制**沙丘在风中"唱歌"**（sand dunes singing）的自然现象
- Ornithopter（直升机蜻蜓）用真实甲虫振翅录音为基底

### AIGC 提示词强制规范

```
[Audio Style - FDR]
所有 diegetic 声音必须可溯源到真实物理声源
禁止：abstract synth whoosh, generic sci-fi laser
强制：bio-acoustic, mechanical, environmental 三类之一
跨剧集一致性：同阵营同生物的声谱 DNA 必须保持统一
```
