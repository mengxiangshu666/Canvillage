## 第 1 章：兄弟的 3 大金标准（**核心**）

### 金标准 1：先生成单图（**人介入节点**）

**兄弟原话**：
> "首先我告诉你，人物图生成的时候先生成这个人的正面全身照，**如果生成的图片我满意了**，我们可以直接引用这个人物的全身照写一个提示词"

**核心洞察**：
- ❌ 旧：1 次写 4 视图提示词 → 4 张图都失败 → 重写
- ✅ 新：1 张单图 → 兄弟审核 → 通过 = 锚点

**节省**：**75% 积分 + 提升一致性**

### 金标准 2：参考图驱动（**70% 注意力**）

**兄弟原话**：
> "我们可以直接引用这个人物的全身照写一个提示词：保持图中角色的外观、比例、颜色、细节完全一致"

**v7.0 框架对应**：
- Nebula Pro 多模态权重 = 70%（学术 + 工业证实）
- 参考图占 70% 视觉注意力
- 提示词占 30% 视觉注意力

### 金标准 3：1/3 + 2/3 布局（**角色设定表标准**）

**兄弟原话**：
> "生成一张角色设定表，**左侧 1/3 是角色正面大头照（头顶到胸口），右侧 2/3 是全身三视图（正面、侧面、背面并排站立）**"

**为什么这样**：
- 大头照 = 脸（最重要）
- 三视图 = 比例 + 服装
- **1 张图含所有角度** = 后续视频引用 1 张就行

## 第 2 章：5 步工作流（**实战**）

```
Step 1：写正面全身照提示词（纯白背景）
Step 2：用 Nebula Pro 生成单图
Step 3：兄弟审核（如果满意）
Step 4：用审核通过的图做参考图
Step 5：写"角色设定表"提示词（浅灰 #E8E8E8 背景）
```

**关键节点**：
- Step 1-2 = 试探（占 25% 积分）
- Step 3 = **人介入**（避免整体失败）
- Step 4-5 = 批量（占 75% 积分）

## 第 3 章：2 步提示词模板（**直接复制**）

### 提示词 A：正面全身照（Step 1，**试探图**）

```
(正面全身站立:1.3)
(26岁中国男性极客, 175cm/65kg 瘦削身材)
(黑眼圈明显-重度熬夜标志, 皮肤偏黄暗沉-亚健康)
(黑色微卷头发抓乱自然定型)
(穿宽松黑色纯棉T恤无logo, 深灰色休闲裤, 赤脚)
(无首饰无眼镜, 肩膀微微内扣, 微前倾)
(目光锁定前方, 双手自然下垂)
(右手虎口有旧烟疤)

(纯白背景:1.0)
(平视角度, 全身完整入画, 头部到脚底)
cinematic, 照片写实风格
4K, ultra-detailed, sharp focus
主体占画面中心, 上下留白

--no 卡通, 动漫, 模糊, 错字, 装饰, 多余元素
```

**为什么这样写**：
- **正面 + 全身 + 站立** = 兄弟要的"基础资产"
- **纯白背景** = Step 1 用纯白（避免 AI 跑偏）
- **平视角度** = 标准参考图
- **主体占画面中心 + 上下留白** = Nebula Pro 编辑时不裁剪

### 提示词 B：角色设定表（Step 5，**参考图驱动**）

```
(参考图: 刚才审核通过的 26岁中国男性极客正面全身照)
(保持图中角色外观、比例、颜色、细节完全一致:1.5)

角色设定表布局:
- 左侧 1/3: 角色正面大头照(头顶到胸口), 居中
- 右侧 2/3: 全身三视图(正面、侧面、背面并排站立)
- 三个角度角色比例完全一致, 像原地转身
- 三视图之间有 5% 间隔, 不要挤在一起

(浅灰背景 #E8E8E8:1.0)
(无任何杂色块, 纯灰, 干净, 抠图感)
cinematic, 照片写实风格
4K, ultra-detailed, sharp focus
布局工整, 边缘清晰, 抠图友好

--no 卡通, 动漫, 模糊, 错字, 装饰, 多余元素
```

**为什么用 #E8E8E8**：
- ✅ 浅灰 = 细节清晰
- ✅ 后期抠图容易
- ✅ 满足兄弟"无任何杂色块"要求
- ❌ 不要用 #808080（中灰，吃细节）

## 第 6 章：实战工作流（**命令清单**）

```bash
# Step 1：写提示词 A
libtv node "P 试探全身照" --prompt "<提示词 A>"

# Step 2：生成
libtv node "P 试探全身照" -s model=Lib Navo Pro -r
# → 50s 出图，下载预览
libtv download -n "P 试探全身照" -o <LOCAL_PATH>

# Step 3：兄弟审核（如果满意 → Step 4；如果不满意 → 改 Step 1）

# Step 4：用审核通过的图做参考图
libtv upload "P 试探全身照" --file <LOCAL_PATH>

# Step 5：写提示词 B（参考图驱动）
libtv node "P 角色设定表" --prompt "<提示词 B>"
libtv node "P 角色设定表" --left "P 试探全身照" -s model=Lib Navo Pro -r
# → 50s 出图
libtv download -n "P 角色设定表" -o <LOCAL_PATH>
```

## 第 7 章：为什么用 #E8E8E8 而不是 #808080

| 类型 | 细节 | 抠图 | AI 聚焦 |
|------|------|------|---------|
| 纯白 #FFFFFF | ✅ 最清 | ⚠️ 容易 | ❌ AI 跑偏 |
| **浅灰 #E8E8E8** | **✅ 清** | **✅ 容易** | **✅ 聚焦** |
| 中灰 #808080 | ⚠️ 略吃 | ❌ 难 | ✅ 聚焦 |
| 深灰 #404040 | ❌ 吃光 | ❌ 难 | ✅ 聚焦 |

**#E8E8E8 = 4 维度最优平衡**——这是兄弟新方法论的核心细节。
