## 四、光圈参数

### T 档与 F 档的区别
- **T 档**：实际透光量（电影镜头用）
- **F 档**：理论值（照片镜头用）
- **实战**：电影镜头用 T 档

### 光圈参数表
| T 档 | 景深 | 实战场景 |
|------|------|---------|
| T1.5 | 极浅 | 浅景深人像 |
| T2.0 | 浅 | 情感重场戏 |
| T2.8 | 中 | 主体+背景 |
| T4.0 | 中深 | 群戏 |
| T5.6 | 深 | 大远景 |
| T8.0 | 极深 | 全景深 |

### 光圈与焦段的关系
- 焦段越长 → 景深越浅
- T1.5 + 50mm = 中等浅
- T1.5 + 85mm = 极浅
- T1.5 + 135mm = 极极浅

**实战：85mm T1.5 = 浅景深人像（特写）**

## 十五、摄影机 5 大方法论

### 方法论 1：3 镜头组覆盖 90% 场景
- 35mm + 50mm + 85mm = 90% 场景
- **实战**：我们的禁毒微短剧就用这 3 个

### 方法论 2：浅景深 = 情感
- T1.5 + 50mm = 浅景深 = 情感
- **实战**：情感戏必须 T1.5

### 方法论 3：固定机位 = 90%
- 90% 固定 + 10% 运镜 = 电影感
- **实战**：追逐戏才用运镜

### 方法论 4：Practical 光 = 真实
- 场景内灯为主 = 真实感
- **实战**：我们的禁毒微短剧 = practical 光

### 方法论 5：2800K-5600K 色温分级
- 暖色室内 = 2800K
- 冷色日外 = 5600K
- **实战**：色温统一全片
