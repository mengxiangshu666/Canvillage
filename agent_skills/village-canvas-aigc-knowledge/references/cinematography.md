# 摄影与镜头合同

## 镜头字段

- 叙事目的：本镜新增信息或情绪变化。
- 主体关系：角色、场景、道具以及前中后景层级。
- 景别：大全景、全景、中景、近景、特写、插入。
- 机位：高度、水平角度、俯仰、主轴和屏幕方向。
- 焦段感：广角空间张力、中焦自然透视、长焦压缩和浅景深。
- 构图：三分法、对称、框中框、引导线、负空间、深度构图。
- 运镜：推近、后拉、横移、跟随、环绕、摇移；写路径、方向和终点。
- 光线：主光方向、补光、轮廓光、色温、阴影和反射。
- 验收：主体数量、空间关系、轴线、光线、动作终点和画幅。

## 连续性

- 不无理由改变人物左右位置、视线方向和道具手持手。
- 不把场景参考图的原始机位误当成当前镜头机位。
- 段内优先一个主要运镜；段间转场必须有叙事原因。
- 复杂镜头拆成可连续生成的动作链，不写剪辑软件才理解的后期术语。
