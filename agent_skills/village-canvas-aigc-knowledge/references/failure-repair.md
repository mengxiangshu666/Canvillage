# AIGC 失败修复

## 分类

1. 输入缺失：参考图、角色、场景、道具或字段不存在；
2. 引用错误：顺序、职责、URL、素材类型不匹配；
3. 能力不兼容：模型不支持模式、参考数量、时长、分辨率或参数；
4. Prompt 过载：主体被风格、光线或背景细节稀释；
5. 物理错误：动作方向、重心、接触关系或镜头运动不成立；
6. 质量错误：身份漂移、场景重构、文字错误、闪烁或音画不同步；
7. 外部错误：超时、限流、502/503、队列或中转站失败。

## 最小修复顺序

1. 只改最可能出错的 1–2 个字段；
2. 保留已成功的参考资产和任务记录；
3. 输入问题先补事实，引用问题先改职责，能力问题再换模式/模型；
4. 只在任务已经结束且不会重复提交时重试；
5. 每次修复记录“错误 → 改动 → 预期改善 → 验收条件”。

不要一次同时换模型、换参考图、换画风和换动作，否则无法知道哪项改动真正有效。
