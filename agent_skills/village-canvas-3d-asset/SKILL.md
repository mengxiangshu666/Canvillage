## 推荐工具详解

### TRELLIS 2（微软研究院源码开放）— 首选

**核心优势**：
- 高斯泼溅（Gaussian Splatting）→ 照片级真实纹理
- 免费且源码开放 → 无限本地生成
- 提供Web App（trellis2.app），无需安装
- 仅需8GB+ VRAM

**缺点**：
- 只有图生3D（不支持文字）
- 不支持多视角重建
- 高斯泼溅格式需要转换才能用某些工作流

**输出格式**：GLB（游戏引擎友好）、Gaussian Splatting

### Tripo AI — 功能最全

**核心优势**：
- 完整管线：文字→3D、图片→3D、骨骼绑定、动画、编辑
- Smart Mesh P1.0：~2秒生成干净拓扑
- AI骨骼绑定+动画预置（500+）
- PBR材质（albedo/normal/roughness）

**价格**：免费300积分/月 → $19.90/mo Pro → $49.90/mo Advanced

### Meshy AI — 3D打印首选

**核心优势**：
- 原生STL输出，防水网格
- 3D打印实测排名第一
- 支持文字→3D和图片→3D
- 多格式导出：OBJ/FBX/STL/GLB

**价格**：免费100积分/月 → $20/mo Pro → $48/mo Studio

## 在AIGC电影中的应用

### 应用场景

| 场景 | 工具 | 工作流 |
|------|------|--------|
| 创建虚拟场景模型 | TRELLIS 2 | 参考图 → GLB → 导入场景 |
| 角色道具（武器/配饰） | Tripo AI | 文字描述 → 自动贴图+绑定 |
| 角色动画 | Tripo AI | 图片→3D → 自动骨骼 → 动画预设 |
| 实物转到电影中 | Hitem3D | 多角度拍摄 → 3D重建 |
| 电影级3D资产 | Rodin AI | 干净拓扑 → VFX管线 |

### 推荐管线

```
AIGC导演 3D管线：

剧本 → 2D概念图（Seedream/Flux）
   ↓ TRELLIS 2（图生3D）
3D基础资产
   ↓ Tripo AI（贴图+绑定）
可动角色/道具
   ↓ 合成到视频场景中
```

## 关键参数

### TRELLIS 2参数

| 参数 | 推荐值 |
|------|--------|
| 输入 | 单张图片（512x512以上，正面最佳） |
| 输出 | GLB / Gaussian Splatting |
| 生成时间 | ~15-30s |
| VRAM需求 | 8GB+ |
| 形状精度 | 正面80-95% / 背面50-70% |

### Meshy API参数

| 参数 | 值 |
|------|----|
| ai_model | meshy-5 / meshy-6 / latest |
| model_type | standard / lowpoly |
| 生成时间 | ~1分钟（简单物体更快） |
