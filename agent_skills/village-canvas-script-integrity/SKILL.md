# Village Infinite Canvas 剧本一致性

这个 Skill 不替用户重写剧情。它先建立唯一事实账本，再检查每次改动会不会破坏人物、
世界观、时间和已埋伏笔。目标是让第 1 集到最后一集仍然能够对得上。

## 一、何时加载

- 剧本经过多轮改写，人物性格或关系开始漂移；
- 长篇、多集、季度或系列项目需要管理暗线；
- 一个改动会影响多个场次、角色知识或道具状态；
- 伏笔埋下后忘记回收，或回收与设定冲突；
- 分镜阶段发现角色知道不该知道的信息；
- 需要从大纲扩展到完整剧本，但不想边写边改设定。

## 二、事实分级

每条信息只归入一类：

| 级别 | 定义 | 使用规则 |
|---|---|---|
| 剧本事实 | 已在正式文本中明确发生 | 不得被模型静默改写 |
| 作者决定 | 用户或主创明确批准的设定 | 可作为正式事实写入账本 |
| 合理推断 | 从事实能推出，但未明说 | 使用时标注推断 |
| 待确认 | 存在两种以上合理解释 | 不得当作硬事实 |
| 已否决 | 明确删除或不再采用 | 保留变更原因，防止回流 |

不要用“角色大概会这样”替代事实判断。

## 三、事实账本

### 1. 角色

```text
身份 / 年龄 / 外形锚点
目标 / 恐惧 / 缺陷 / 底线
与每个关键角色的关系及当前变化
各集知道什么、不知道什么、误以为什么
身体状态、服装、伤痕、持有物
```

### 2. 世界规则

```text
物理规则 / 技术规则 / 超自然规则
规则的代价、限制与不能被打破的边界
谁知道规则，谁误以为知道
已展示证据与仍属假设的部分
```

### 3. 时间与空间

```text
绝对时间轴 / 相对先后顺序
地点与交通所需时间
昼夜、天气、季节、光线状态
角色在同一时间点可能出现的唯一位置
```

### 4. 物件与证据

```text
关键道具首次出现、持有者、位置、状态
信件、照片、录像、伤口、录音等证据链
谁看过、谁伪造、谁仍不知情
道具在跨镜中的开合、破损、液位和归属
```

### 5. 伏笔与回收

| ID | 伏笔 | 首次出现 | 指向 | 计划回收 | 状态 |
|---|---|---|---|---|---|
| F01 | 旧钥匙 | EP02 场3 | 父亲身份 | EP08 场2 | open |

状态只使用 `open / paid / abandoned / contradicted`。没有回收不是问题，和后续事实冲突
才是问题。

## 四、连续性四件套

每次改场次，同时检查：

1. **时间地点**：这件事能不能在这时、这里发生；
2. **身体与物件**：伤口、服装、手、道具和天气状态是否连续；
3. **知识状态**：角色是否已经知道导致该行动的信息；
4. **目标与关系**：角色此刻的目标和关系变化是否支持这句台词与动作。

四项冲突时，先改最小字段，不重构整部剧。

## 五、变更影响分析

每次提出修改，按以下链检查：

```text
提议改动
  -> 直接事实变化
  -> 受影响角色知识
  -> 受影响时间 / 道具 / 关系
  -> 已埋伏笔
  -> 已拍摄或已生成资产
  -> 最小修复范围
```

输出格式：

| 改动 | 冲突点 | 影响场次/集数 | 最小修复 | 是否需要用户决定 |
|---|---|---|---|---|
| 主角提前知道真相 | 破坏 EP04 调查动机 | EP03-05 | 改成主角只发现线索 | 否 |

## 六、季度弧线

多集项目使用四阶段检查：

| 阶段 | 任务 | 必须回答 |
|---|---|---|
| 建立 | 人物、世界、主冲突 | 观众必须知道什么？ |
| 升级 | 关系变化、代价上升、暗线织入 | 哪些选择变得不可能？ |
| 转折 | 旧信念失效，真相改变目标 | 哪条信息把世界翻转？ |
| 收束 | 选择、代价、回收与余波 | 哪些伏笔必须付账？ |

暗线按“出现次数、信息增量、回收时间”管理，不让每条暗线同时爆发。每集只允许一个
主要叙事峰值；其他线索负责积累或回声。

## 七、诊断输出

发现冲突时给：

```text
冲突 ID
事实 A / 事实 B
出现位置
为什么不能同时成立
三种修复方向及其副作用
推荐的最小修复
需要主创确认的唯一问题
```

不要直接覆盖正文。只有用户明确要求，或当前工作流已有正式改写授权时，才提出替换稿。

## 八、验收清单

- [ ] 每条关键设定已分级为事实、决定、推断、待确认或否决。
- [ ] 角色知识状态按集/场建立，不靠模型记忆。
- [ ] 时间、地点、服装、伤痕、道具和天气可连续追踪。
- [ ] 伏笔都有稳定 ID 和回收状态。
- [ ] 改动已检查对后续集、已生成资产和暗线的影响。
- [ ] 冲突修复是局部、可回退的，没有顺手重写无关内容。
- [ ] 未把推断写成剧本事实。

## 来源与边界

本 Skill 蒸馏自历史技能归档中的 `script-consistency-guardian`、
`multi-episode-series-writer`、`feature-film-script-expert`、
`concept-short-film-script-creator`，只保留事实追踪、弧线和变更分析方法。
