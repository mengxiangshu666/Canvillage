# 实拍级导演实战规则补遗（2026-09-29 实测沉淀）

> **本 skill 的定位**：画布已有 39 个技能覆盖了导演体系的骨架（导演框架/镜头/表演/剪辑/连续性/风格锁/失败救援）。
> **本 skill 只做一件事**：补上画布里查不到的、**由真实付费生成实测出来的**参数与教训。
> **冲突处理**：当前项目事实、用户要求、模型输入合同与付费授权优先。
> 本文是有限历史样本的经验，不是跨模型的定律；不能仅因某配方失败改写剧情、强制重拍或追加付费。

## 一、视觉事件铁律（片子"有看头"的根治方）

### 病根：配音幻灯片
画布的 `cinematography`/`shotcraft` 管的是**怎么拍**，但没人管**这一镜有没有事件**。实测教训：六镜全部技术达标（角色一致/台词正确/音画同步），但用户评价"**没啥看头**"。

### 铁律 1：每镜必须有一个"属于画面、不属于台词"的戏剧事件
六类任选，**一个都没有 → 这镜是废的，回分镜重写，不要进生成**：

| 类别 | 例句 |
|---|---|
| **物理事件** | 灵珠在掌心炸开强光，另一只手去捂，光从指缝漏出 |
| **调度事件** | 角色进/出画、走到某处、转身、坐下起身 |
| **道具事件** | 布袋被塞进手里、门被推开、油灯被吹灭 |
| **光影事件** | 油灯火苗随语气晃动、影子在墙上"吵架"、雷光把提线照得根根分明 |
| **揭示事件** | 镜中倒影露出不该有的表情、背景出现不该在场的人 |
| **质感事件** | 提线突然绷紧、纸脸在光下露出裂纹 |

### 铁律 2：关掉声音测试
> **把音轨关掉，这一镜还能看懂"谁在做什么/出了什么事"吗？** 看不懂 = 配音幻灯片 = 白拍。

### 铁律 3：写作顺序倒过来
**分镜表必须为每镜加两栏**：`【视觉事件】` + `【无声可读性】`，且**先写视觉事件，再写台词**——台词是给视觉事件配的说明，不是主角。

### 铁律 4：开场 3 秒
必须是**视觉奇观 / 生死危机 / 反常识画面**三选一。需要"听完台词才懂"的微妙反差 = 慢热，**不叫钩子**。

## 二、FACS 微表情编码（解决"木偶人念经"）

画布 0 命中这项。**不要写情绪词，要写肌肉动作**——模型不认"他很害怕"，只认具体肌肉。

| 情绪 | FACS AU 组合 | 提示词写法 |
|---|---|---|
| 真笑 | AU6 + AU12 | `cheek raisers contracting, lip corners pulled up diagonally, crow's feet at eye corners` |
| 悲伤 | AU1 + AU4 + AU15 | `inner brows raised and drawn together, lip corners pulled down` |
| 惊讶 | AU1+AU2+AU5+AU26 | `brows raised high, upper eyelids lifted showing white above iris, jaw dropped` |
| **恐惧** | AU1+AU2+AU4+AU5+AU7+AU20+AU26 | `inner and outer brows raised and drawn together, eyes wide with tightened lower lids, lips stretched horizontally, jaw dropped` |
| 愤怒 | AU4+AU5+AU7+AU23 | `brows lowered and drawn in, eyes narrowed and intense, lips pressed thin` |
| 厌恶 | AU9+AU15+AU16 | `nose wrinkle, lip corners depressed, lower lip pushed down` |
| 轻蔑 | AU12 单侧 + AU14 | `one-sided lip corner pull creating a dimple, asymmetric smirk` |

### 三条命门
1. **微表情时长 0.04–0.2 秒**（超过 0.5 秒就变普通表情）；
2. **真假之别在 AU6**：只有嘴角上提（AU12）而无颊肌上提（AU6）的笑，观众潜意识判定"假笑"；
3. **克制 = 先泄漏再压制**：假装镇定的正确写法是「0.15 秒真实情绪微表情闪现 → 强行压回中性脸」，**不是全程面无表情**。

## 三、戏剧五力自检（剧本张力引擎）

每场戏推导时显式自检，**满足不足 3 项则打回重写**：

| 力 | 问什么 |
|---|---|
| **欲望** | 主角这一场拼死想要什么？（必须具体到物品/信息/动作）|
| **阻力** | 什么挡着他？（物理/人际/道德）|
| **信息差** | 观众知道但角色不知道的（悬念核心）；或角色以为胜券在握、观众目睹意外（惊喜）|
| **风险** | 退缩失败的惨烈代价 |
| **时间压力** | 什么时候截止？（倒计时/逼近的脚步/燃烧的引线）|

## 四、锚定链：多镜角色一致性的根方法

### 病根：文字描述锁不住脸
实测：四视图做完后，**后续每一镜首帧都"凭文字重新想象"生成**（写"木雕灰须官帽、深褐道袍"），结果六镜生成了**六具不同的木偶**，场景材质光影每镜漂移。用户评价"**人物场景不一致、很跳脱**"。

### 正确方法（三步）
1. **每角色一张「定妆主图」（Master Shot）**——从四视图挑最佳姿态生成，全片唯一身份锚点；
2. 身份保持镜头按模型支持的模式绑定正式定妆参考，多角色参考分别标明职责。
   不把外部 `-r` 写法当村长工具参数；无参考能力时如实说明不能据此保证锁脸；
3. **帧级拉片**：在可比较的姿态、景别与光线下，核对骨相、五官关系、发型和身份标记。
   记录镜号/时间码、参考资产、具体差异与是否影响识别。未定义测量方法时不报“偏差百分比”；
   透视、表情和光照变化不能单独判作身份漂移，证据不足记待核对。付费重拍另看授权。

### 场景一致性
- 同场戏：首帧再叠加**上一镜尾帧**作第二参考（角色 + 场景**双锚定**）；
- 不同场景：用场景主视角图作参考。

### 跨镜一致性技术栈
`定妆主图` → `正式参考绑定` → `按模型能力继承空间参考` → `具体身份差异核对` → `授权内局部修复与复验`

## 五、H3 台词铁律（实测血泪）

### 铁律 0：台词必须逐字引用
> **不给台词原文 → 生成 gibberish 乱码。**（实测：只写"说出一句话"，输出"世面秀賤的虛諷"式的伪古文）

### 规则 1：以实际对白与表演安排时长
保留用户台词原文；按实际音频或试读语速、停顿、动作和模型能力估计所需时间。
历史短台词样本发生过重复，不能推导出最低字数或50%语音占比。
短句、反应镜和静默是合法创作选择，不为填时长增添或重复台词。
若产物重复，记录时间码，先核对对白是否重复编译，再考虑裁剪、调整时长或授权内局部重生成。

### 铁律 2：不说话的人必须标静默
用 `全程保持静默，不出任何声音`。不标 → 模型把"忍笑/叹气"**发成声**（实测双人镜中父亲忍笑，音频多出"呵呵"）。

### 规则 3：明确静默与环境音意图
无对白段写清无人说话、嘴唇状态与允许的环境声；完全静音也可以是用户要求。
历史样本发生过填充声音，不代表模型永远不能静默，不为避免空窗擅自增加配乐或对白。

### 规则 4：将对白与画面文字职责分开
对白原文只放当前模型支持的专用声音字段或格式；用户要求无字幕时明确无字幕。
散文引号在历史样本中出现过烧字幕，不能据此保证某种句式必然避免文字；结果需实际核对。

### 规则 5：对白容量与说话人
说话人、语言、语气和逐字台词按当前模型合同编译；容量以实测音频时长和表演停顿核对。
不设置跨语言固定字数上限；超出镜头容量时提出延长或合理拆镜方案，不擅自删改对白。

### ⚠️ 验收盲区
ASR转写可能把同音词写错；人工听音可以核对发音，不能从相同发音恢复唯一汉字。
对白语义结合脚本上下文核对，字幕文字另按实际画面与文本资产检查。

## 六、视频生成的结构性约束

### 6.1 时长按内容选，不按模型上限
| 镜头内容 | 时长 | 理由 |
|---|---|---|
| 对白镜 | **4–5 秒** | 台词填得满、无静默填充、漂移少 |
| 连贯动作戏 | **8–15 秒** | 动作不能断，漂移靠帧级修剪兜底 |
| 慢节奏情绪场 | **10 秒** | 长镜呼吸感本身是叙事手段 |

**为什么不能一刀切用最长时长**：① H3 不会静默（短台词塞 15 秒会重复）；② **漂移随帧累积，15 秒镜最后 1/3 最难看**（实测 14 秒处构图明显向尾帧收敛）；③ 长镜失败重跑损失翻倍；④ 快节奏剪辑线里 2/3 用不上。

### 6.2 首尾帧双锚定（唯一可靠的锁构图手段）
- 传 `first_frame` + `last_frame` 成对（尾帧与首帧构图相同）→ **彻底压住推镜**（实测跨对白/水下场景复现成立）；
- **提示词写"锁机位"无效**：正写"摄影机完全静止" + 负面词堆 `zoom/push in/dolly`，模型照推。**必须用结构约束，不能用形容词。**
- **⚠️ 锚定管不了中间帧**：模型在中间帧自主生成的粒子（气泡/烟尘）仍会糊脸 → 对策：**从提示词源头删掉生成动机** / 改构图避开 / 帧级修剪只留干净段。
- **⚠️ 锚定管不了中间帧**：这是"提示词约束有边界"的最强证据。

### 6.3 动态验收三查
静态首帧通过 ≠ 视频可用。抽 `0s/中段/尾段` 三帧，核对：
1. **身份是否漂移**（五官是否稳定）
2. **构图是否位移**（是否自行推近）
3. **画面是否出现文字/纹理伪影**

### 6.4 场景先验无法用提示词消除
实测：水下气泡是**强场景先验**——删净所有气泡词、首尾帧都无气泡，中间帧仍自主生成。
> **判断口径**：删净所有相关描述后缺陷仍出现 → 它是场景先验 → **立刻停止改词**，改走后期/时长路线。

### 6.5 瞬间事件模型抓不住
"提线**突然绷紧**"这种一刹那的变化，在 4 秒动态里会被弱化。
> **重要事件要改成"持续状态"**（提线一直是紧的、绷出弧度），而不是"突然发生"。

## 七、拼接纪律

### 7.1 默认打法：生成边界对齐剪辑点
- 把每段的"秒数上限结尾"**正好设计成一个切镜头的时刻**；下一段换景别/机位开始（剪辑本来就允许跳变）；
- 优势：绕开接力漂移、顺手裁掉尾段漂移帧、符合快切结构、不需为接力额外生成尾帧；
- **例外**：只有"同机位必须连续"的镜才用帧接力。

### 7.2 音画同步校验
- **音轨与视频轨必须用同一套裁剪参数抽取**（曾因"视频掐头去杂音、音频没掐"导致音画错位 1 秒且越往后越偏）；
- 拼接前**逐段校验音画时长差 ≤ 0.06 秒**（PyAV 读容器 `duration` 最可靠）；
- 音轨略长时用**视频尾帧定格（tpad）**补齐，**不要用 `-shortest` 硬切**（会裁掉台词末尾字）。

### 7.3 裁帧禁忌
> **裁尾必须避开台词区**，只裁台词结束后的静默段（实测裁掉 0.4 秒把"中规中矩"切成"中规轴"）。

## 八、付费生成纪律

1. 提交前核对村长真实任务/production run、正式产物、同镜现有任务和本轮 `task_authorization`；
   不依赖外部 `.dream-run.jsonl`，不凭日志为空认定失败。
2. 任务仍在运行或状态未知时先查询/恢复，不能重复收费提交；重生成先核对失败原因、
   已完成产物和授权余量。取回结果不等于新生成，取消是否停止计费以供应商实际回执为准。
3. 不并行重复提交同一镜头；独立镜头是否并行以当前生产合同与授权为准。
4. 核对逐字台词、所需参考、声音/字幕要求和真实工具合同，不统一强制首尾帧、无字幕或无BGM。
