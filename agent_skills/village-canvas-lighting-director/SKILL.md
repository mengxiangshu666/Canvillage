# 光影专项

光不是形容词，是**现场关系**。写「电影感打光」模型无法执行；写「左前方四十五度阴天天光，
冷灰，只照亮左眼与鼻梁一侧，暗区保留发丝结构」才能执行。

> 与相邻技能的分工：`village-canvas-cinematography` 管摄影语法（构图/焦段/景深/机位），
> `village-canvas-visual-style` 管全片风格锁；本技能**只管光**——光源从哪来、
> 照到哪、怎么衰减、跨镜头怎么保持一致。

## 一、何时加载

- 用户说画面太脏、太平、太暗、看不清主体；
- 出现平均发亮（没有重点）、无来源光（不知道光从哪来）、曝光跳变、阴影方向混乱、
  发光物照射范围失真；
- 夜景、室内、烛火、路灯、霓虹等有实景光源的场景；
- 多镜头之间光线不连续（前一镜顺光、后一镜逆光但环境没变）。

## 二、按任务选工作方式

| 用户给的 | 怎么做 |
|---|---|
| 场景想法 | 从零设计光线模块 |
| 完整视频提示词 | **保留**剧情/动作/角色/镜头，只重写光影部分 |
| 已有光影提示词 | 先诊断物理冲突与连续性，再给修订版 |
| 关键信息不足 | 从场景里的**可见光源**做保守推断；只有两种选择会明显改变结果时才问 |

不要因为"没写光源"就拒绝——场景里几乎总有可用的光源（窗、路灯、天光、月光）。

## 三、建立光源层级

**默认一到两个主光 + 一层克制补光。** 每增加一束光，必须说清它来自哪里、承担什么工作。

1. **环境光或主光**：负责主体与空间的基础曝光；
2. **补光**（可选）：只负责暗部结构与眼神光，强度低；
3. **轮廓光 / 强调光 / 道具光**（谨慎）：只在需要把主体从背景剥离，或场景有明确实景灯时加。

## 四、每个光源写八属性

按场景需要写，不必机械凑齐——不会改变结果的属性直接省略。

1. **身份**：阴天天光、窗光、路灯、烛火、晶体内光……
2. **位置**：左前方四十五度、右后方、正上方、胸前偏下
3. **色彩**：冷灰、蓝白、暖金、橙红、中性白
4. **质地**：大面积柔光、窄束硬光、漫射环境光
5. **强弱关系**：环境光占主导 / 道具光只做局部强调
6. **受光表面**：左眼、鼻梁一侧、发丝、肩线、指尖、瓶身边缘
7. **衰减范围**：只影响五到十厘米，超出迅速变暗
8. **时间状态**：恒定 / 火焰轻微跳动 / 车辆掠过 / 逐渐熄灭

### 位置、功能、质地是三组可组合的描述

不是互斥风格。例：**侧后方的窄束硬光**同时描述了位置（侧后）、质地（硬）、可作主光，
并在人物一侧产生轮廓光（功能结果）。

## 五、把光映射到表面（用可见结果替代抽象词）

- 写清先照到哪一侧脸、哪几缕头发、哪一块衣料；
- **暗区要写保留哪些结构**，不要用「暗部有细节」这种笼统收尾；
- 按材质分别写反射：玻璃、金属、皮肤、湿地、雪、烟雾、织物各不相同；
- **影子方向与光源方向相反**；
- 近身小光源快速衰减，**禁止无理由照亮远景**；
- 只有空气中真有雾、烟、雨、雪或尘埃时，才让光束可见——否则光束是假的。

## 六、视频的时间与连续性

单张图只需交代当前受光关系；**视频还要锁定光线随时间怎么变**。

跨镜头固定的不变量（写进合同，多镜必锁）：

- 环境光方向、色温、相对亮度
- 实景灯 / 发光道具的颜色、强度、作用半径
- 阴影方向与主要反射面
- 曝光基准与白平衡倾向
- 闪烁、跳动、渐变的节奏

## 七、诊断表（看到现象先查这里）

| 现象 | 常见病因 | 修法 |
|---|---|---|
| 平均发亮、没重点 | 光源太多太平均 | 压低补光，只留一个主光 |
| 不知道光从哪来 | 只写氛围词不写身份与位置 | 补全八属性，至少给身份+位置 |
| 曝光跳变 | 时间状态没锁 | 锁曝光基准与白平衡倾向 |
| 阴影方向混乱 | 多光源未指定主次 | 明确哪盏是主光，其余只做强调 |
| 发光物照亮范围失真 | 忽略衰减 | 写清衰减范围，近身光源限定半径 |
| 主体与背景糊在一起 | 缺分离手段 | 加轮廓光或压暗背景 |
| 光束可见但无雾 | 空气里没有介质 | 补雾/烟/尘埃，否则删掉光束 |
| 多镜光线不连续 | 未锁不变量 | 按第六节锁跨镜头项 |

## 八、验收清单

- [ ] 每个光源写清了身份与位置（至少这两项）
- [ ] 主体被明确指定：有几盏主光、各自承担什么
- [ ] 写清受光表面，不是只写"照亮主体"
- [ ] 暗区写明保留的结构，不用笼统一句收尾
- [ ] 影子方向与光源方向相反
- [ ] 近身光源写了衰减范围，没有无理由照亮远景
- [ ] 光束可见的地方确有雾/烟/雨/雪/尘
- [ ] 多镜头任务锁定了跨镜头不变量
- [ ] 材质反射按材质分别写，不是通用一句
