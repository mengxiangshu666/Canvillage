# Village Infinite Canvas 表演执行工艺

这个 Skill 只解决一件事：把“难过、震惊、克制、心虚”之类抽象词，翻译成模型能画出来、
剪辑能接得上、验收能判定的可见动作。它不负责改剧情，不创建第二套表情面板，也不把生成
计划说成已经出片。

## 一、何时加载

- 角色表情僵、每镜都像同一张脸；
- 情绪只有标签，没有起点、变化和收回；
- 动作轻飘、身体像没有重量；
- 特写里微表情和眼神不成立；
- 强情绪导致脸漂、手崩或身体畸形；
- 需要把对白或沉默拆成逐拍表演。

一般表演方向和镜头合同优先加载 `village-canvas-expression-director`；本 Skill 用于进一步
降低粒度，不替代该导演规程。

## 二、事实边界

接受以下输入：

- 剧本中已确认的角色目标、障碍、对白和事件；
- 角色正式设定、身份图与服装状态；
- 镜头景别、时长、机位、轴线；
- 上一镜结束姿态和下一镜开始姿态；
- 用户明确要求的表演强度或参考。

缺动机时只输出“可见动作方案 + 待确认潜台词”，不替角色编造心里话。画布已有
“角色表情控制 · 50 锚点”时，只引用真实输出；没有该能力时，用本 Skill 的可见动作描述
补齐，不伪造锚点编号、Morph 权重或工具调用。

## 三、情绪到可见信号

同一情绪必须至少落到三个通道，避免只写眉、眼或嘴其中之一。

| 内在状态 | 眼与眉 | 呼吸与喉部 | 身体与手 | 节奏特征 |
|---|---|---|---|---|
| 压抑愤怒 | 视线锁住目标，眼睑压低，眉内侧下压 | 鼻息变重，短吸气后停顿 | 下颌紧、手指收拢、重心前压 | 爆发前更慢，出口时突然加速 |
| 恐惧但强撑 | 瞳孔与眨眼频率变化，视线短暂逃离再拉回 | 吸气浅，吞咽后屏息 | 肩颈抬起、手找支撑或抓紧物件 | 反应快，恢复慢，台词易断句 |
| 克制爱意 | 视线停留后先移开，眼周先松再收 | 呼气轻，笑意被喉部压住 | 手指无意识整理衣角或物件 | 停顿长于对白，接近时动作变慢 |
| 心虚掩饰 | 先看对方再看别处，眨眼后盯住一点 | 呼吸节奏与解释速度不一致 | 手势过多、摸脸、整理不存在的灰 | 解释过度，停顿出现在编造处 |
| 震惊未回神 | 焦点失焦瞬间，眼睑和眉头来不及完成表情 | 吸气停在半途，声音迟一拍 | 全身短暂定住，随后只有单一小动作 | 先静后动，反应延迟明确 |
| 疲惫麻木 | 上眼睑下垂，视线不追焦 | 呼气长，常以鼻音结束句子 | 肩背塌、动作省力、拖步 | 节奏均匀，几乎无峰值 |
| 勉强释怀 | 眼周松开但不完全，嘴角上扬后迅速回落 | 深吸气后长呼气 | 肩落下，手指从紧握变为松开 | 先降强度，再留一个反悔小动作 |
| 决意形成 | 视线从游移变为固定，眉与下颌趋于稳定 | 一次完整吸气后不再多解释 | 重心落定，手停止寻找 | 前面犹豫，最后一个明确动作收口 |

这些是观察模板，不是强制统一答案。角色年龄、性格、关系和镜头语境优先。

## 四、四拍调制

每段表演按下面四拍写，时长不足时删次要动作，不压缩触发与余波。

```text
基准状态
  -> 触发
  -> 抑制或策略动作
  -> 峰值反应
  -> 收回与余波
```

写具体时间时使用比例而不是猜测帧数：

| 镜头类型 | 触发落点 | 峰值 | 余波 |
|---|---|---|---|
| 1-3 秒反应镜 | 0-15% | 35-60% | 最后 20-30% |
| 4-6 秒对白镜 | 10-20% | 50-70% | 最后 20% |
| 6 秒以上长镜 | 明确两次变化，不只有一个峰值 | 分阶段 | 至少保留一次呼吸回收 |

台词镜遵循：

```text
听到 -> 处理 -> 想说的 -> 真正说出的 -> 说完后的反应
```

对白前的准备动作属于表演，不应被台词盖掉。

## 五、物理真实

动作要带重量、阻力和环境反馈：

- **重心**：起动前先有支撑或预压，停下后保留惯性；
- **摩擦**：转身、坐下、拾取、推拉要有阻力，不瞬移；
- **惯性**：头发、衣摆、雨滴、灰尘和道具延迟跟随；
- **互作用**：手握物件会限制手指，湿衣会改变肩背，风会改变步幅；
- **疲劳**：连续动作要累积呼吸、姿态和反应延迟；
- **恢复**：强动作后必须有呼吸、视线或姿态余波。

不要用“很真实、电影感、大师级表演”替代物理事实。写成：

```text
她先握住杯柄，指节收紧，杯底轻碰桌面后才抬眼；吸气停在半途，
目光没有完全聚焦，肩背比上一镜低半寸。
```

## 六、景别适配

| 景别 | 可承载 | 不要依赖 |
|---|---|---|
| 大远景 / 全景 | 重心、走位、方向、轮廓、群体关系 | 眼睑、瞳孔、嘴角微颤 |
| 中景 | 姿态、手势、肩颈、头部转向、呼吸幅度 | 过细的泪膜和肌肉抽动 |
| 近景 | 视线、眉眼下压或松开、下颌、喉部 | 全身大动作同时完整发生 |
| 特写 / 大特写 | 一次情绪变化、眨眼、呼吸停顿、嘴角收回 | 多线程手势和复杂走位 |

微表情不可见时，把情绪挪到身体、道具或反应延迟，不硬塞进远景。

## 七、提示词编译

按固定顺序写：

```text
角色与身份引用
  -> 当前目标的可观察动作
  -> 抑制方式
  -> 视线对象与转移
  -> 呼吸 / 身体 / 手部
  -> 环境物理反馈
  -> 镜头与时长
  -> 连续性约束
  -> 失败模式负向约束
```

示例：

```text
保持角色身份与服装一致。她坐在桌边，右手握住杯柄，原本要解释，
却在开口前停住；视线先看对方，再落到杯口，随后重新抬头。
呼吸变浅，肩背先绷紧再缓慢落下；杯底轻碰桌面，没有夸张动作。
中近景固定机位，四秒，承接上一镜低头姿态，结束时视线停在对方脸上。
避免脸形变化、手指数量错误、同时出现哭和笑、无原因快速转头。
```

## 八、返修矩阵

| 问题 | 首选修复 | 禁止做法 |
|---|---|---|
| 表情僵硬 | 增加触发、延迟和收回，减少单帧情绪标签 | 继续堆“极度悲伤”等形容词 |
| 表情跳变 | 固定基准状态，只保留一个峰值，前后各留过渡 | 同镜塞入多个相反情绪 |
| 过演 | 降低面部幅度，让身体和道具承担情绪 | 增加更多手势和泪光 |
| 看不出来 | 调整景别或把动作前移到可见层 | 在远景依赖微表情 |
| 脸漂 | 降低大幅表情，强化正式身份引用，减少转头 | 用新风格描述替换角色设定 |
| 动作轻飘 | 加上重心、摩擦、惯性和环境反馈 | 用慢动作掩盖物理缺失 |
| 手部崩坏 | 让手有明确目标、接触物和遮挡 | 无意义地让双手张开入镜 |
| 呼吸不连续 | 延续上一镜呼吸、姿态和手中物件 | 每镜重新摆一个标准姿势 |

## 九、验收清单

- [ ] 情绪至少落入眼、呼吸、身体三个通道。
- [ ] 有基准、触发、策略、峰值和余波。
- [ ] 视线对象与转移时机明确。
- [ ] 动作有重心、阻力或环境反馈。
- [ ] 表演细节适配景别和时长。
- [ ] 对白前后都有反应空间。
- [ ] 起止姿态可承接上下镜。
- [ ] 没有伪造画布表情锚点、工具回执或生成完成状态。

## 来源与边界

本 Skill 是对历史技能归档中 `micro-expression-master`、
`character-expression-decomposer`、`realistic-cinema-performance-engine`
三条通用方法的去模板化蒸馏。它不复制旧运行链，不引入外部框架依赖。
