# AIGC视频导演通用框架 v2.0

**换剧本不换框架。从零到成片，不管拍什么。**
基于：238个LibTV公开画布深度学习 + 《等不到的老汉儿》17镜翻车全量分析

## 导演方法清单

本清单来自历史案例，不覆盖用户要求、当前模型输入合同或付费授权。
参考图、语言、音频、分辨率和提示词格式以当前项目与模型能力为准。

### 提示词铁律

**铁律A：物理行为描述（因果链升级版）**
格式：`主体 + 身体部位 + 物理动作 + 方向 + 做完后的位置`

三层对比：
| 层级 | 写法 | AI理解 |
|------|------|--------|
| ❌ 事件级 | "他出门了" | 人凭空消失 |
| ⚠️ 动作级 | "他跨出门槛，转身关门" | 动作模糊，方向不明 |
| ✅ 物理级 | "他抬起右脚跨出门槛，身体重心前移，上半身探出门外，左脚跟上——现在整个身体在门外。他转身面向门，身体转了180度。他伸出右手，抓住门把手，手臂向后拉，门向自己靠近，直到门框完全贴合。门关上了。" | 可逐帧生成 |

**铁律B：禁止概括词**
用资产表中的具体角色名，不用"孩子/父亲/警察/男人/女人"。

**铁律C：中文写中文场景**
优先保持用户语言和场景事实；模型要求的提示词语言以其当前合同为准。

**铁律D：@主体标注**
画面描述中标注`@角色名`，不是只在台词里标。

**铁律E：负面约束**
按用户声音与字幕要求和模型能力编译，不统一禁止BGM或强制原生配音。

**规则F：按内容和当前模型能力定时长**
单镜保持一条清晰动作链；15秒只是历史案例参数，不是全产品硬上限。

**铁律G：提示词一体**
摄影系统+灯光+胶片+动作+台词+负面约束→全塞一个prompt字段，不分节点。

### 流程铁律

**铁律H：先看资产再写剧本**
流程：逐张看人物→逐张看场景→写剧本→资产映射表

**铁律I：先跑一镜再全量**
选一镜代表性镜头先跑→看效果→通过后再全量跑。

**铁律J：先480p后高清**
只有当前模型支持低清预览和后续高清路径时才提案分阶段生成，先核对两阶段总费用；
不能承诺“一键高清”，也不因试探计划自动启动付费任务。

### 内容铁律

**铁律K：台词要有潜台词**
需要潜台词时检查“表面说什么、实际想达成什么”；直接说明事实的台词不必强加第二层。

**规则L：按叙事需要交代背景**
- 30s→5-10s铺垫
- 60s→10-15s
- 90s→20-30s
- 以上仅作历史方案示例；允许直接进入动作或对白，不默认补旁白或强制铺垫时长。

**铁律M：旁白讲故事不是念档案**
有具体细节（时间/地点/事件/场景）。

**铁律N：台词信息密度**
按实测语速、停顿、动作和用户时长分配；不以固定句数填满镜头。

## 剧本写作通用流程

### 第一步：资产盘点
```
1. 逐个看人物资产 → 记录：外貌/衣着/年龄/气质
2. 逐个看场景资产 → 记录：灯光/色调/构图/道具
3. 逐个看道具资产 → 记录：用途/象征意义
4. 输出：资产清单表
```

### 第二步：故事大纲
```
1. 用一句话说清楚：谁+要什么+障碍是什么
2. 拆成N个大段：每段一个核心情绪/事件
3. 定每段时长：按内容密度，不按模板
4. 输出：段落概要表
```

### 第三步：写剧本
```
1. 开头介绍段（旁白+空镜，铺垫背景）
2. 主体段落（每段贴着资产图写）
3. 每段标注：用哪个场景、哪个人物
4. 结尾段（余味，不总结）
```

### 第四步：资产映射
```
1. 人物 → 段号（哪些段出现）
2. 场景 → 段号（哪个段用哪个场景）
3. 道具 → 段号
4. 备用资产 → 标注
```

### 第五步：台词审查
```
1. 需要潜台词的段落是否有动机依据？直接信息句是否清楚且无多余重复？
2. 台词、停顿和动作是否适配镜头时长，是否有多余重复？
3. 角色说话符合身份/地域/时代吗？
4. 声线库配好了吗？（年龄+性别+质感+口音+状态）
```

## 9维分镜提示词模板

| 维度 | 填什么 | 说明 |
|------|--------|------|
| **摄像系统** | 机身+传感器+镜头+胶片+画幅比 | 按风格选 |
| **灯光** | 主光源+光质+方向+光比+色温 | 按情绪选 |
| **景别** | 大远景/全景/中景/中近景/近景/特写 | 按距离选 |
| **焦段光圈** | 24/35/50/85mm + f值 | 按情感选 |
| **运镜** | 固定/横摇/手持/推近/下摇 | 按节奏选 |
| **站位** | 角色在画面的哪里 | 画左/画右/画中/前景/背景 |
| **@主体动作** | `@角色 做了什么→导致什么` | 因果链 |
| **台词** | `【台词（@角色，声线，语气，情绪）："内容"】` | 见音画同步章节 |
| **负面约束** | 全局指令+项目专属禁止项 | 每镜必加 |

## 省积分策略

1. **按能力提案预览**：支持时比较低清试探与直出目标分辨率的总费用
2. **先跑一镜**：选代表镜头验证后全量
3. **单图→批量**：先单张验证角色/场景，通过后再批量
4. **复用参考图**：同一角色的镜头复用同一参考图
5. **同场拼接**：同一场景的多镜头连续跑，减少环境切换
