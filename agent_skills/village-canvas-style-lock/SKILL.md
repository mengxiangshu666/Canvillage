# Village Infinite Canvas 视觉风格锁定

风格不是一串形容词，而是一组必须稳定重复、允许有限变化、能够被验收的视觉关系。
`village-canvas-visual-style` 负责选择画风；本 Skill 负责把选定参考变成可执行的风格合同，
并检查后续镜头有没有漂移。

## 一、何时加载

- 用户给出参考图、样片或已批准镜头，希望全片统一；
- 多镜生成后色温、对比、材质、镜头感或美术逐渐漂移；
- 需要把一个风格应用到新主体、场景或角色；
- 需要在写实、动画、3D、漫画或混合风格之间迁移；
- 需要定义哪些东西必须不变、哪些东西可以随剧情变化；
- 需要判断“风格像不像”而不是只看单张图好不好看。

只有一个尚未批准的视觉方向时，先加载 `village-canvas-visual-style` 选型。

## 二、参考素材准入

参考素材分为：

| 类型 | 用途 | 限制 |
|---|---|---|
| 风格参考 | 提取色彩、光线、材质、镜头语言 | 不照抄标志性构图和独特角色 |
| 角色参考 | 锁定主体身份 | 由角色资产合同管理 |
| 场景参考 | 锁定空间、年代、材质 | 不把新故事写成原场景复刻 |
| 技术参考 | 说明镜头、焦段、运动或后期 | 不推断模型没有声明的参数 |

多个参考优于单张参考。若只有一张参考，必须主动区分“可迁移规则”和“原图独有元素”。

## 三、Style Contract

所有创作先建立唯一风格合同：

```yaml
style_id:
reference_refs: []
intent:
invariants: []
variables: []
forbidden_drift: []
shot_checks: []
evidence_refs: []
```

三类内容不能混：

### 1. Invariants

全片必须稳定：

```text
色彩关系
主光方向与软硬
明暗对比
色温倾向
材质颗粒
镜头畸变与景深习惯
构图密度
人物与空间的视觉关系
```

### 2. Variables

允许随剧情变化：

```text
时间与天气
机位和景别
角色情绪
服装状态
场景功能
受控的色彩偏移
```

变化必须有叙事原因，并写清允许范围。

### 3. Forbidden Drift

明确禁止：

```text
新增主色或霓虹色
从写实跳到卡通描边
从硬光跳到全柔光
镜头质感突变
高光溢出、塑料皮肤、过度锐化
每镜重新定义艺术方向
复制参考作品的可识别角色或标志性画面
```

## 四、七层提取

从参考中按顺序拆解，不能只写“电影感、高级、氛围”：

| 层 | 提取内容 |
|---|---|
| 媒介 | 实拍、2D、3D、定格、混合媒介 |
| 色板 | 主色、辅色、强调色、肤色与阴影偏移 |
| 光 | 光源方向、软硬、色温、光比、高光行为 |
| 材质 | 皮肤、布料、金属、纸张、颗粒、噪点 |
| 镜头 | 焦段感、景深、畸变、运动模糊、曝光习惯 |
| 构图 | 对称/偏心、前中后景、留白、遮挡、人物尺度 |
| 后期 | 对比、曲线、色彩分离、辉光、暗角、锐度 |

每层都要写成可观察关系。例如：

```text
“冷青阴影 + 少量暖肤色高光，主光从左后方进入，阴影边缘偏硬”
```

不要只写：

```text
“电影级赛博朋克风”
```

## 五、四镜探针

正式锁定前至少做四类探针：

| 探针 | 检查 |
|---|---|
| 身份探针 | 角色在新风格中仍能一眼认出 |
| 极端光探针 | 夜景、逆光或高对比下风格不崩 |
| 景别探针 | 特写、中景、远景都有同一视觉关系 |
| 动态探针 | 运动、动作或视频转换后材质与色彩稳定 |

每项记录：

```text
期望规则
实际画面证据
是否漂移
漂移发生在哪一层
最小修复动作
```

没有真实生成或参考画面时，只能写计划，不能判定通过。

## 六、提示词编译

提示词按优先级写：

```text
故事主体与动作
  -> 风格不变项
  -> 当前镜头允许变量
  -> 媒介与材质
  -> 光线与色板
  -> 镜头与构图
  -> 连续性引用
  -> 负向漂移
```

不要把整张参考图逐元素复述。只描述要迁移的视觉关系，并明确新主体、新场景和新构图。

若模型支持 style/reference 参数，只使用当前能力目录声明的字段；不得伪造风格代码、
权重或不可验证的“锁定等级”。

## 七、跨镜与视频迁移

视频风格迁移比静态图多检查四件事：

1. **时间一致性**：相邻帧的线条、材质和色板不闪烁；
2. **运动一致性**：风格不改变动作结构、重量和空间方向；
3. **身份一致性**：角色脸、服装和道具不被风格吞掉；
4. **背景一致性**：动态背景不因风格化而液化或漂移。

输入视频的结构和节奏属于上游事实；风格迁移不应顺手重剪、改动作或改剧情。

## 八、漂移修复阶梯

按从低风险到高风险修复：

1. 删除互相冲突的风格词；
2. 把抽象词改成可观察关系；
3. 减少同时变化的变量；
4. 加强已批准参考的职责，不新增更多参考；
5. 调整光线和色板后重测一镜；
6. 确认是模型能力不匹配后再换模型；
7. 仍失败时重做风格探针，不继续批量生成。

身份漂移与风格漂移同时出现时，先保身份，再保场景，再调风格。不能用换脸换取统一色调。

## 九、输出合同

```text
style_brief
style_contract
extraction_layers
reference_policy
probe_results
prompt_contract
drift_findings
repair_plan
evidence_refs
unverified_items
```

## 十、验收清单

- [ ] 不变项、变量和禁止漂移已分开。
- [ ] 风格描述落到光、色、材质、镜头和后期，而非只有形容词。
- [ ] 参考作品的结构可借鉴，独特表达没有被复制。
- [ ] 四类探针有真实画面或视频证据。
- [ ] 跨镜差异有位置和层级，不只说“感觉不统一”。
- [ ] 修复优先减少冲突和变量，不盲目增加提示词。
- [ ] 模型参数来自真实能力，不伪造参考锁定。
- [ ] 未验证的静态图、视频和跨帧一致性明确标记。

## 来源与边界

本 Skill 蒸馏自历史技能归档中的 `unified-aesthetic-film-generator`、
`style-transfer-extractor`、`multi-style-video-stylizer`、
`video-style-transfer`。只保留风格提取、合同化、探针与漂移修复方法，
不绑定 Liblib、Seedance、ControlNet 或其它单一平台能力。
