# AIGC 提示词铁律

> 来源：兄弟 AIGC 知识包 v2 · 2026-06-22
> 调用时机：每次输出生图/视频提示词前，自动过这3关

---

## 铁律1：hex色值禁区

**规则：**
- ✅ hex色值和材质描述 → 只用于**环境/场景物体**（道具、建筑、天气特效）
- ❌ 人物身上 → **零hex色值、零色块标注**
- 人物外观由**参考图锁定**，提示词只写动作、位置、气色

**原因：** AI 把 hex 当材质指令，写在人物上会把脸/皮肤涂成色块

**违规示例：**
- ❌ `skin="#F5D0C5", eye_color="#4A90D9"`
- ❌ `dress="#8B0000", hair="#2C1810"`

**正确做法：**
- ✅ 参考图锁定身份外观
- ✅ 提示词只写：`气色苍白`、`皮肤黝黑`、`面部潮红`

---

## 铁律2：精准锚点 > 越详细越好

**规则：**
- 关键词少但精准 → 每个词**高注意力** → 画面质量高
- 关键词多但互相竞争 → 每个词**低注意力** → 画面融化变形
- 关键不是字数，是**精准的注意力锚点**

**AI注意力预算（固定）：**
| 区域 | 占比 |
|------|------|
| 主体 | 50-60% |
| 风格/光线 | 20-30% |
| 细节/环境 | 10-20% |

**违规示例：**
- ❌ 写50个词，主体/风格/细节混杂 → 注意力稀释
- ❌ 一句话塞入多个相互竞争的修饰词

**正确做法：**
- ✅ 主体精准（身份、姿态、视线）→ 放第一句
- ✅ 风格单独一段（光线、色调、质感）→ 放第二句
- ✅ 环境细节精练 → 最多3个关键词

---

## 铁律3：实战验证 > 理论

**规则：**
- 精简理论在**复杂多物体场景**下失效
- 详细描述的控制力远强于精简描述
- **任何规则遇上实战翻车，以实战为准**

**实战优先 checklist：**
1. 出片效果 vs 理论规则 → 效果优先
2. 复杂场景（3+角色/物体）→ 用详细描述，详细>精简
3. 单一主体/简单场景 → 用精准精简，精准>堆砌
4. 风格冲突时 → 选最接近参考风格的描述

---

## 使用流程

每次输出提示词前：

```
[ ] 铁律1：提示词里有人身上的hex色值吗？→ 有则删除
[ ] 铁律2：关键词是否精准？是否在50词以内？注意力锚点是否靠前？
[ ] 铁律3：本场景复杂吗？→ 复杂用详细，简单用精简
```
