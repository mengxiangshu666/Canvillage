### 用途
本 Skill 旨在将现有的真人视频、图像或分镜稿件，根据用户指定的风格（如动漫、写实 3D、卡通 2D 等）进行重绘转换，实现高质量的画风迁移。

### 适用输入
- **原始素材**：真人成片、单帧图像或分镜草图。
- **风格要求**：目标画风描述（如：新海诚风、皮克斯 3D、赛博朋克、水墨画等）。
- **核心元素**：需保留的角色特征与场景关键点。

### 操作步骤
1. **解析素材**：分析原始视频/图像中的动作结构、深度信息及角色轮廓。
2. **匹配风格**：根据用户提供的“风格圣经”或描述词，提取色彩、笔触及渲染逻辑。
3. **一致性处理**：锁定关键角色与场景特征，确保转绘过程中帧与帧之间、画面与原图之间的一致性。
4. **渲染输出**：生成符合预期的风格化序列，并进行光影微调。

### 输出要求
- **风格高度还原**：准确呈现目标风格的视觉特征。
- **结构准确**：保留原视频/图像的动态结构与空间逻辑。
- **画质清晰**：输出无明显噪点、连贯性强的风格化视频。

### 注意事项
- 复杂的动态背景可能需要在提示词中额外强调稳定性。
- 如需极高的一致性，建议配合角色参考图（ControlNet）使用。
