# AIGC 提示词框架核心（7模块 + 铁律 + 决策矩阵）

> 来源：兄弟 AIGC 知识包 v2 · 2026-06-22
> 核心原则：不可傻瓜式套模板，必须具体情况具体分析

## 一、7 模块提示词结构

### 文生图七段（仙剑4）
```
[画面构图：景别，视角]
+ [角色完整描述+空间位置]
+ [人物空间与互动关系]
+ [微表情与面部特写]
+ [场景环境元素与前景/背景道具]
+ [光影几何与大气效果]
+ [视觉风格/胶片质感：镜头，光圈]
```

### 图生视频五段
```
[运镜轨迹与速度]
+ [主体物理动作细节]
+ [环境物理动态]
+ [音效与音乐氛围]
+ [时长：X.Xs]
```

### MiniMax H3 专属编译分支（当前直连 H3）

这不是把五段模板机械拼起来，而是把用户创意编译成模型能在一个短片段里执行的导演稿：

```
[镜头职责 + t=0 起始状态]
+ [主体/服装/道具/空间/光向锁定]
+ [按节点时长切分的 2–5 个因果动作段]
+ [每段一个主动作 + 一个主运镜]
+ [接触/发力/重心变化/环境反馈]
+ [结束状态 + 精简负面约束]
```

- 当前 H3 运行合同是 4–15 秒；节点时长是硬预算。8 秒以内最多 3 段，9–15 秒最多 5 段。用户给出 30 秒、多地点或整套武打招式时，保留叙事主线并报告需要拆镜，不把不可能的内容硬塞进一个短片段。
- 角色外观、服装、道具、站位和光向只锁用户真实提供的事实；动作必须写成“准备 → 接触 → 受力传导 → 身体/环境反馈 → 收束”，效果必须由接触或运动触发。
- 运镜写起始景别、方向、速度、与主体的关系和终点构图；单段只选一个主运镜，禁止“推近+拉远+环绕”并列。
- 优先具体可拍的身体、材质和空间细节；“8K、AAA、电影感、震撼”只能作为弱风格标签，不能替代动作、镜头和物理因果。不要添加未列出的 `@参考`、API 参数或模型不支持的能力。

## 二、3 条铁律（不可违反）

### 铁律1：hex色值禁区
- ✅ hex色值和材质描述只用在**环境/场景物体**上
- ❌ 人物身上**零hex色值、零色块标注**
- 人物外观由参考图锁定，提示词只写**动作、位置、气色**

### 铁律2：交叉注意力 = 精准锚点 > 越详细越好
- 关键词少但精准 → 每个词高注意力 → 画面质量高
- 关键词多但互相竞争 → 每个词低注意力 → 画面融化变形
- 关键不是字数，是**精准的注意力锚点**

### 铁律3：实战验证 > 理论
- 精简理论在复杂多物体场景下失效
- 详细描述控制力远强于精简描述
- 理论必须服从实际出片效果

## 三、决策矩阵速查

### 影调叙事决策矩阵（何止维）

| 影调 | 暗部占比 | 叙事功能 | 典型场景 |
|------|---------|---------|---------|
| **低长调** | 70-85% | 悬疑/危险/戏剧性 | 犯罪片/惊悚片/毒贩家 |
| **低中调** | 60-75% | 压抑/忧郁/内敛 | 文艺片/家庭剧 |
| **中长调** | 35-55% | 自然/真实/生活化 | 纪录片/日常剧 |
| **中中调** | 35-50% | 平和/舒适/日常 | 生活片/喜剧 |
| **高长调** | 10-25% | 明亮/开阔/希望 | 结尾段落/公路片 |
| **高中调** | 10-30% | 温馨/浪漫/甜蜜 | 爱情片/家庭片 |
| **高短调** | 5-15% | 纯净/空灵/天堂 | 天堂场景/童话 |

### 布光叙事决策矩阵（何止维）

| 想表达的情绪 | 光源选择 | 色温倾向 | 构图配合 |
|-------------|---------|---------|---------|
| 疏离/孤独 | Rimlight为主 | 偏冷（5000K+） | 偏侧/留白 |
| 坦然/真诚 | Key Light正面 | 中性偏暖（3500-4500K） | 正面/对称 |
| 荒诞/自嘲 | 强明暗对比+冷暖对比 | 冷暖双色温 | 中心对称 |
| 暧昧/不安 | 分割光/半张脸明暗 | 暖色低光 | 偏侧/紧凑 |
| 压迫/威胁 | 顶光/底光/逆光剪影 | 冷色硬光 | 低角度仰拍 |

### 景别黄金律（大黑耗子）

| 景别 | 占比 | 叙事功能 |
|------|------|---------|
| 全景（含远景） | 30% | 空间坐标、世界观 |
| 中景 | 50% | 日常叙事、对话 |
| 特写（含近景） | 20% | 关键信息、情绪冲击 |

### 运镜稳定性优先级（大黑耗子）
```
定机位 > 缓慢推镜 > 轻微拉远 > 平移跟拍 > 环绕
```
- 优先单一运镜，不要叠加
- 运镜服务叙事，不是炫技

## 四、MyElc 三大底层方法

### 1. 主体 vs 条件
- **主体**（谁/什么）= 20个字就够，但要精准
- **条件**（怎么拍/什么风格）= 辅助，不要堆砌
- 主体不明确，条件写得再好也没用

### 2. 动作原子步骤法
```
[原子步骤1] → [停顿/蓄力X秒] → [原子步骤2]
```
规律：准备→停顿→完成（3拍）

### 3. 时间描述独立维度
```
[速度] + [节奏] + [关键停顿] + [时间质感] + [时间膨胀点]
```
例：监控录像感 vs 大片感 = 时间描述决定

## 五、导演思维 7 条通用规律

1. **景别是情绪的标尺** — 小=压迫，大=自由，中=关系。交替=呼吸感
2. **运镜是叙事的语法** — 推=靠近/亲密，拉=远离/释放，环绕=审视，上升=升华
3. **光影是叙事的第二语言** — 暖=安全，冷=危险，逆光=剪影，光在两人之间=关系
4. **声音是类型的开关** — 同一画面+不同音乐=不同类型
5. **视点转移是叙事的推进** — A视角→B视角→交汇=叙事推进一步
6. **环境不是背景，是角色** — 红叶=韩菱纱的"和世界不同"
7. **微表情是人物的真相** — 表情弧线=人物揭示

## 六、AI 注意力预算

### 图片（4维）
- 主体：50-60%
- 风格/光线：20-30%
- 细节/环境：10-20%
- 超出会被稀释 → 不要写超长描述（>50词）

### 视频（5维）
- 空间（单帧内）：30%
- 时间（帧间）：25%
- 主体（角色）：20%
- 运动（相机/主体）：15%
- 音频（同步）：10%

### 视频4秒段原则（Luma官方）
> "Each 4-second clip = 1 subject + 1 action + 1 camera movement"
- 不要在4秒段塞2个动作
- 不要在15秒段塞5个场景
- 每段时间只干一件事
