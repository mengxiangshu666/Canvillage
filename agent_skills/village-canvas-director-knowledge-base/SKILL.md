# 顶级AI导演能力框架

## 核心定位
村长 Agent要成为一个"懂电影的AI"，底座是电影知识体系，输出是精准的生成提示词。不是客服，是导演。

---

## 一、电影语言体系（视听思维）

### 1. 视觉叙事核心元素
- **构图 (Composition)**: 三分法、黄金比例、框架内框架、对称与平衡、前中后景深度
- **光线 (Lighting)**: 硬光/软光、三点布光、伦勃朗光、碟形柔光、情绪光（冷/暖）、剪影
- **色彩 (Color)**: 色轮理论、互补色、邻近色、饱和度与明度、色彩情绪（蓝=冷峻/冷=怀旧/红=激情）
- **景别 (Shot Scale)**: 大特写→特写→中近景→中景→中全景→全景→远景→大远景
- **角度 (Camera Angle)**: 平视/俯视/仰视/倾斜角，每种都带情绪倾向
- **运动 (Camera Movement)**: 推/拉/摇/移/跟/升降，每种运动改变观众与角色的心理距离

### 2. 镜头语法
- **180度轴线规则**: 保持空间方向感
- **30度规则**: 避免相似角度跳切
- **视线匹配 (Shot/Reverse Shot)**: 建立双人对话感
- **正反打 (O.S. / O.L.)**: 内心反应镜头
- **建立镜头 (Establishing Shot)**: 交代空间
- **蒙太奇 (Montage)**: 用压缩时间、并列叙事

### 3. 短片独特性
- 短片没有标准答案，短片是"想法"的证明
- 适合说什么 + 这个故事适合怎么说，内容与规格互为因果
- 短片自由度高，可以更大胆
- 商业委托也可以有创作突破

## 二、导演思维模型

### 1. 导演的核心职责
- 给方向，不是给答案
- "如何做"远比"做什么"困难
- 表达方式与内容要平起平坐
- 想法最贵也最便宜

### 2. 视觉叙事思维
- 每帧都是视觉论证 (visual argument)
- 在台词到达之前，观众已经在读画面了
- 用画面说"为什么"而不是"发生了什么"
- 转场是情绪的延续，不是简单的切换

### 3. AI导演prompt公式（来自Sora官方指南）
```
[Scene] + [Subject] + [Action] + [Camera] + [Mood] + [Lighting] + [Style]
```
场景 → 主體 → 動作 → 鏡頭 → 氛圍 → 光線 → 風格

### 4. AI视频生成prompt结构
- Text-to-Video: `Subject + Action + Scene + Camera Movement + Lighting + Style`
- Image-to-Video: `Subject 1 + Action 1 + Action 2`（动作链）
- 核心原则：描述而非指令，要像导演的分镜头脚本
- 时长控制：短时长相一致性更好，长内容分段生成再剪辑

## 三、AI导演prompt工程

### 1. 好的prompt特征
- **具体 (Specific)**: 主体外观、表情、动作精确描述
- **具象 (Visual)**: 用视觉语言而非抽象概念
- **有氛围 (Mood-driven)**: 光线、色调、情绪关键词
- **有镜头意识 (Cinematic)**: 指定景别、角度、运动方式

### 2. prompt迭代思维
- 不要追求一次完美
- AI是协作者，通过追问迭代优化
- 描述能力比背诵咒语更重要

### 3. 常见失败模式
- 提示词模糊，AI自由发挥空间过大
- 镜头语言与叙事内容不匹配
- 忽略光线方向和质量
- 缺少主体与背景的关系描述
