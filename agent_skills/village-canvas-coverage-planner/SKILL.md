# Village Infinite Canvas 镜头覆盖规划

分镜回答“故事怎么拍”，本 Skill 回答“剪辑时手里有哪些素材”。目标不是镜头越多越好，
而是用最小覆盖量保证动作完整、情绪可切、空间不跳、后期能救。

## 一、何时加载

- 一个 beat 只有一张主图，没有可剪反应或细节；
- 有对白，却没有倾听者、手部、道具或环境镜；
- 动作没有中间过程，无法匹配剪辑；
- 需要为短片、广告、Vlog 或产品片设计 B-roll；
- 需要火柴人 PREVIS、动作分解或联系表式镜头索引；
- 成片节奏平，缺少建立、推进、停顿和转场素材。

主叙事镜头合同仍以 `village-canvas-storyboard` 为准；本 Skill 只扩充覆盖层，不另造剧情。

## 二、输入事实

- 场景目标、角色与核心动作；
- 主轴、屏幕方向、主光方向和空间地标；
- 角色正式身份、服装、道具状态；
- 目标画幅、片段时长和剪辑节奏；
- 已批准分镜和已有媒体；
- 用户指定的参考风格，只作为锚点，不作为剧情事实。

缺少动作起点、终点或空间关系时，先补镜头合同，不直接生成大量素材。

## 三、六槽覆盖模型

一个完整段落至少检查以下六槽，按叙事需要删减，不机械全拍。

| 槽位 | 任务 | 常见构图 | 剪辑价值 |
|---|---|---|---|
| 建立镜 | 交代地点、时间、人物和关系 | 全景/大远景，方向明确 | 开场、转场、重置空间 |
| 主镜 | 完整承载本段核心动作或对白 | 中景/中近景，轴线稳定 | 成片主轴与表演验收 |
| 过程镜 | 展示动作起点、过程、终点 | 近景/特写/侧向跟拍 | 避免动作瞬移，提供匹配点 |
| 反应镜 | 接收者听到或看到后的变化 | 近景/特写，视线有对象 | 情绪转场、权力变化 |
| 细节插入 | 手、眼、道具、屏幕、证据 | 微距/特写，浅景深 | 强调信息、修补节奏 |
| 空镜 / B-roll | 环境、材质、光影、空间余韵 | 远中近组合，带方向 | 转场、画外音、删减缓冲 |

## 四、B-roll 五镜法

需要一组风格统一的空镜时，按“空间、动作、细节、感官、离开”规划：

1. **空间建立**：地点与天气，交代光源和地标；
2. **动作关联**：人物经过、门开合、车流、光切换；
3. **关键细节**：物件纹理、手部、水汽、灰、屏幕或食物变化；
4. **感官强调**：近景或运动镜头展示声音来源、风、雨、温度感；
5. **收束 / 离开**：视线终点、空场景、远景或物件归位。

每条 B-roll 必须写：

```text
叙事用途 + 景别 + 机位 + 运动 + 光源方向 + 时长 +
进入/离开画面 + 与主镜的剪接关系 + 负向约束
```

不要只写“唯美空镜”。空镜也必须服务信息、节奏或空间。

## 五、动作 PREVIS

复杂动作先做低保真预演，不先追求角色质感。

### 2x4 八格法

```text
1 准备 / 起始姿态
2 起步 / 重心变化
3 攻击或主动作一
4 防守 / 受击
5 过渡 / 位移
6 主动作二
7 结果 / 动作终点
8 余波 / 可切点
```

每格只写一个决定性姿态：

- 人物关节位置、重心脚、朝向；
- 与对手的距离和方向；
- 道具接触点和轨迹；
- 镜头轴线、景别和摄影机位置；
- 下一格从哪里接上。

若画布支持把预演图排成联系表，索引必须清晰可读；不能读清时不得声称已完成
“索引驱动视频”。预演图是动作和空间的证据，不等于最终角色媒体。

## 六、覆盖矩阵输出

每个段落输出一张表：

| ID | 槽位 | 叙事用途 | 景别/机位 | 动作起止 | 镜头运动 | 时长 | 剪接点 |
|---|---|---|---|---|---|---|---|
| C01 | 建立 | 交代地点 | 大远/俯视 | 无人物动作 | 缓慢横移 | 3s | 接主镜 |
| C02 | 主镜 | 核心对白 | 中近/平视 | A抬头/B停笔 | 固定 | 5s | 动作匹配 |
| C03 | 过程 | 放下杯子 | 特写/侧俯 | 手指松开到杯底落桌 | 微推 | 1.5s | 硬切 |

表后追加：

- **轴线地图**：人物左右、主轴、摄影机不可越过的区域；
- **动作接力**：每个切点前后动作状态；
- **光与道具接力**：光向、手中物件、液位、开合和破损；
- **节奏预算**：总时长、长镜与短切分布；
- **缺口**：缺哪些覆盖会导致无法剪辑。

## 七、联系表 / 网格镜头

只有在需要把一个长动作切成多个内切镜时，才考虑联系表式网格：

- 每格索引清晰、布局统一；
- 格与格之间的角色身份、光向和空间方向一致；
- 索引代表时间或动作顺序，不混入无关备用图；
- 若模型不能稳定读取索引，降回逐镜提示词或 PREVIS，不伪造成功。

## 八、画布执行边界

使用真实工具读取脚本、beat、节点和已有媒体；镜头节点和连线通过允许的
`freezone_emit_canvas_command` 或原生 canonical capability 落地。草图、首帧、视频仍按
各自工具和当前 `task_authorization` 启动。

本 Skill 不创建新工具，不绕过画布回执，不直接生成媒体。

## 九、修剪原则

覆盖不足会卡剪辑，覆盖过量会浪费预算。按以下顺序删：

1. 删除叙事任务重复的镜头；
2. 删除与主轴冲突或方向不成立的镜头；
3. 删除无法在时长内完成的复杂动作；
4. 把远景承载不了的微表情挪到反应近景；
5. 保留至少一个动作过程和至少一个可切反应；
6. 对白段至少保留主动者、接收者和一个环境/细节缓冲。

## 十、验收清单

- [ ] 六槽覆盖缺口已列出，而不是机械全拍。
- [ ] 主镜完整承载核心动作或对白。
- [ ] 动作有过程镜和可匹配的切点。
- [ ] B-roll 有明确叙事用途、方向与剪接关系。
- [ ] 动作 PREVIS 的顺序、重心和道具接触成立。
- [ ] 所有镜头遵守主轴、屏幕方向、光向和道具状态。
- [ ] 画布写入有真实回执，媒体生成符合当前授权。
- [ ] 没有把预演图、联系表或计划当成最终成片。

## 来源与边界

本 Skill 蒸馏自历史技能归档中的 `b-roll-coverage-designer`、
`cinematic-camera-director`、`grid-index-video-director`、
`action-previs-stickman-generator`，只保留可跨题材复用的覆盖方法。
