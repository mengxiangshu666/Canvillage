# 剧本创作方法论

## 第1章：4大支柱（任何剧本的起点）

### 支柱1：立意哲学——剧本要回答什么哲学命题？

**5部经典剧本的"立意基因"**：

| 基因 | 经典剧本 | 核心命题 |
|------|---------|---------|
| 进步 vs 回归 | Zima Blue | 升级了千次万次，最大的进步是回到起点 |
| 真实 vs 模拟 | Beyond Aquila Rift | 善意的谎言 vs 残酷的真相 |
| 信任 vs 背叛 | Bad Travailing | 当敌人也懂同情，你还能相信谁 |
| 爱与背叛 | Jibaro | 被不被爱，比不被爱更可怕 |
| 暴力循环 | The Witness | 目击者即凶手——暴力是无限循环 |

**5大哲学命题**：
1. 进步不是线性的——升级不等于更好
2. 真实不等于美好——真相不一定是恩赐
3. 信任是双刃剑——同情心是武器
4. 吸引不等于爱——物化是背叛的极致
5. 暴力是无限循环——证人即共犯

### 支柱2：叙事诡计——90%铺垫+10%揭示

**核心公式**：
```
90%时间：让观众以为这是A
10%揭示：原来是B（颠覆观众认知）
```

**任何剧本创作**：先定10%的"揭示"，再倒推90%的"铺垫"。

### 支柱3：视觉哲学——用什么视觉语言表达？

| 视觉哲学 | 适用剧本 | 关键特征 |
|---------|---------|---------|
| 极简主义 | 科幻/哲学 | 蓝白主色、极简线条、大量留白 |
| 颜色对比 | 悬疑/恐怖 | 蓝白=模拟/橙黑=现实 |
| 感官即叙事 | 艺术片 | 听不见=不被诱惑 |
| 视角即命运 | 惊悚/犯罪 | 视角切换=暴力循环 |

### 支柱4：长度节奏

| 时长 | 适用 | 节奏 |
|------|------|------|
| 6分钟 | 极简禅意 | 极慢 |
| 10分钟 | 完整短片 | 标准 |
| 12分钟 | 中等节奏 | 快剪 |
| 17分钟 | 复杂叙事 | 慢→快→慢 |
| 22分钟 | 长篇悬念 | 持续紧绷 |

## 第3章：5段结构（6-22分钟通用）

| 段 | 时长占比 | 情绪 | 任务 |
|----|---------|------|------|
| 1.建立 | 15% | 平静/建立 | 介绍人物、空间、关系 |
| 2.升级 | 20% | 紧张/挑战 | 引入矛盾、铺垫 |
| 3.觉醒 | 20% | 震撼/哲学 | 揭示核心命题 |
| 4.抉择 | 25% | 悲悯/庄严 | 主角做出关键决定 |
| 5.回归 | 20% | 释怀/收束 | 故事收束、主题深化 |

# 角色心理学与对话深度

## 第1章：角色弧线

### 3种基本弧线

| 弧线 | 定义 | 终点 | 案例 |
|------|------|------|------|
| 正向弧 | 角色克服缺陷，成长 | 更好的自己 | 《肖申克》Andy |
| 负向弧 | 角色堕落/毁灭 | 更糟的自己 | 《教父》Michael |
| 平坦弧 | 角色不变，改变世界 | 坚守信念 | 《疯狂的麦克斯》Max |

### 正向弧5阶段
```
1. 初始状态：角色有致命缺陷（flaw），但不自知
2. 催化剂：外部事件打破舒适区
3. 挣扎期：新旧自我拉锯（最长的阶段）
4. 顿悟时刻：意识到缺陷，做出选择
5. 新平衡：成为更好的自己（但不完美）
```

### 负向弧3种类型
| 类型 | 机制 | 案例 |
|------|------|------|
| 堕落弧 | 好→坏 | 《绝命毒师》Walter White |
| 幻灭弧 | 理想→破灭 | 《了不起的盖茨比》 |
| 腐败弧 | 受害者→施害者 | 《闪灵》Jack Torrance |

## 第2章：5种基本冲突

| 冲突 | 定义 | AIGC适用性 |
|------|------|-----------|
| 人 vs 自我 | 内心矛盾、身份危机、道德选择 | ⭐⭐⭐⭐⭐ 短片最优 |
| 人 vs 人 | 两个角色的对抗 | ⭐⭐⭐⭐ 需要强对话 |
| 人 vs 社会 | 个体对抗体制/规范 | ⭐⭐⭐ 需要世界观建立 |
| 人 vs 自然 | 对抗自然力量 | ⭐⭐ 视觉冲击力强 |
| 人 vs 超自然 | 对抗不可解释的力量 | ⭐ 需要特效支撑 |

## 第3章：对话3层结构

```
表层：字面意思
中层：社交意图（礼貌、威胁、调侃）
深层：真实欲望（往往与表层相反）
```

### 潜台词7种技术

| 技术 | 机制 | 例子 |
|------|------|------|
| 回避 | 不回答真正的问题 | "你今天去哪了？" → "外面天气不错" |
| 转移 | 用反问回避 | "你爱她吗？" → "什么叫爱？" |
| 重复 | 机械复述对方的话 | "你撒谎。" → "我没有撒谎。" |
| 沉默 | 不回答=最强烈的回答 | 对方问背叛→沉默 |
| 过度解释 | 说太多=在掩饰 | 被问去哪，给出详细到可疑的回答 |
| 说反话 | 表面批评=深层关心 | "你就不能照顾好自己？" |
| 替代表达 | 拿别的事说真正的事 | 吵家务=在吵"你不重视我" |

### 对话权力动态

| 权力位 | 特征 | 对话模式 |
|--------|------|---------|
| 高权力 | 提问者、打断者、沉默者 | 短句、命令式、不解释 |
| 低权力 | 回答者、解释者、请求者 | 长句、试探性、过多解释 |
| 平等 | 互相倾听 | 对话节奏对称 |

**权力翻转=戏剧高潮**（低权力方突然沉默/反问/离开）

## 第4章：沉默的5种功能

| 沉默类型 | 时长 | 情绪 | 视觉配合 |
|---------|------|------|---------|
| 认知沉默 | 1-3秒 | 思考、消化信息 | 眼神微动、嘴唇轻抿 |
| 情感沉默 | 3-6秒 | 被触动、说不出话 | 眼眶红、喉结滚动 |
| 权力沉默 | 2-5秒 | 施压、等待对方崩溃 | 直视、不动 |
| 毁灭沉默 | 5-15秒 | 关系终结、无话可说 | 避开眼神、起身离开 |
| 仪式沉默 | 10-30秒 | 哀悼、致敬、神圣 | 静帧、远景、慢镜头 |

# 叙事诡计分类学

## 9大类叙事诡计

### 类型1：不可靠叙述者

| 亚型 | 机制 | AIGC适用 |
|------|------|---------|
| 天真型 | 叙述者不理解自己看到的事 | ✅ 短片佳 |
| 疯狂型 | 叙述者精神异常 | ⚠️ 需视觉区分 |
| 说谎型 | 叙述者故意撒谎 | ✅ |
| 失忆型 | 叙述者记忆受损 | ✅ 非线性必须 |
| 傲慢型 | 叙述者自以为是 | ✅ |

### 类型2：非线性叙事

| 亚型 | 机制 | 代表 |
|------|------|------|
| 倒叙框架 | 结局→回溯→回到结局 | 《公民凯恩》 |
| 双线交织 | 两条时间线交替 | 《教父2》 |
| 反向叙事 | 从结局往前推 | 《记忆碎片》 |
| 环形叙事 | 结尾回到开头 | 《低俗小说》 |
| 碎片/拼图 | 多个碎片非时序 | 《巴别塔》 |
| 分叉叙事 | 同一事件的不同可能性 | 《罗拉快跑》 |

### 类型3：视角反转

| 亚型 | 机制 |
|------|------|
| 好人=坏人 | 主角/盟友实为反派 |
| 坏人=好人 | 反派实为保护者 |
| 现实=幻觉 | 全部或部分为幻觉/模拟 |
| 受害者=施害者 | 受害者其实是加害者 |

### 类型4：信息差（Dramatic Irony）

| 亚型 | 机制 | 代表 |
|------|------|------|
| 观众知道 | 观众比角色多知道 | 希区柯克"桌子下的炸弹" |
| 角色知道 | 某个角色知道但其他人不知 | 《无间道》卧底 |
| 无人全知 | 所有人都是盲人摸象 | 《罗生门》 |

### 类型5：红鲱鱼（Red Herring）
故意误导线索，将注意力引向错误方向。
- 用构图权重（大特写）放大误导物件
- 真正的线索藏在画面边缘或焦点外

### 类型6：麦高芬（MacGuffin）
推动情节但本身不重要的物件/目标。
《低俗小说》手提箱、《公民凯恩》"玫瑰花蕾"

### 类型7：元叙事
故事意识到自己是故事。

| 亚型 | 机制 | 代表 |
|------|------|------|
| 直接对话 | 角色对观众说话 | 《死侍》 |
| 嵌套结构 | 故事中的故事 | 《盗梦空间》 |
| 形式自反 | 揭示"这是虚构" | 《趣味游戏》倒带 |

### 类型8：时间诡计

| 亚型 | 代表 |
|------|------|
| 慢镜头揭示 | 《黑客帝国》子弹时间 |
| 快镜头压缩 | 《梦之安魂曲》嗑药蒙太奇 |
| 时间循环 | 《土拨鼠之日》 |
| 冻结时间 | 《X战警》快银 |

### 类型9：沉默揭示（AIGC短片最优选择）
不用台词，纯画面揭示真相。
- 一个物件=揭示一切（照片、纸条、伤疤）
- 一个表情变化=角色领悟
- 一个镜头运动=观众认知升级

# 文化与讽刺语法

## 讽刺7种形式

| 形式 | 机制 | 语气 |
|------|------|------|
| 伏尔泰式 | 温和调侃，假装天真 | 微笑的刀 |
| 斯威夫特式 | 极端夸张到荒谬 | 愤怒的冷笑 |
| 奥威尔式 | 体制的语言腐败 | 冰冷的恐惧 |
| 黑色幽默 | 用笑声面对恐怖 | 苦笑、荒诞 |
| 荒诞主义 | 揭示存在的无意义 | 虚无的笑 |
| 反讽 | 表面说A，实际是B | 多层意味 |
| 戏仿 | 模仿形式，颠覆内容 | 致敬中的批判 |

## 讽刺的视觉化

| 视觉技术 | 效果 | 例子 |
|---------|------|------|
| 并置 | 两个矛盾元素同一画面 | 豪华餐厅里有人翻垃圾桶 |
| 比例错位 | 放大/缩小某个元素 | 巨大手机屏幕vs渺小的人 |
| 重复循环 | 同样动作无限循环 | 上班族永远在同一电梯里 |
| 无声呐喊 | 张大的嘴没有声音 | 被消音的抗议者 |
| 反向仪式 | 正常仪式的荒诞版本 | 葬礼上的人在笑 |

## 文化叙事传统

### 东方叙事（留白与循环）
- 中国：意象堆叠、意在言外、情景交融
- 日本：物哀（mono no aware）——为转瞬即逝的美而感动
- 韩国：恨（Han）——积压的悲愤与韧性的共生

### 拉美魔幻现实主义3大本体论原则
| 原则 | 定义 | AIGC提示词实现 |
|------|------|----------------|
| 本体论平等 | 超自然事件与日常事件享有同等地位 | 不用magical/supernatural，用中性日常动词 |
| 去熟悉化 | 用陌生语言描述熟悉事物 | prompt用文学化比喻 |
| 反讽性并置 | 神迹被当作"令人分神的琐事" | 不强调超自然，让超自然被忽略 |

**AIGC双模板**：
```
lo real maravilloso模板：用于拉美/原住民/非洲题材
  → "ancient geography itself is miraculous"

magical realism模板：用于全球后殖民/创伤题材
  → "everyday life contains inexplicable events, treated as ordinary"
```

**反奇观提示词模板**：
```
禁用：magical, fantasy, supernatural, enchanted, mystical, surreal
必用：中性日常动词 + 文学化比喻

错误：magical woman floats in the air with sparkling lights
正确：a woman rises three inches from the floor, laundry still hanging on the line, no one looks up
```
