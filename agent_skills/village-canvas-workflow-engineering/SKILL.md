# ComfyUI工作流体系

本技能提供方法参考，不表示村长已安装这些本地节点或模型。下文参数、硬件占用、
排期和质量比例都是待验证的历史示例；按实际版本、硬件、素材、当前能力目录与
用户要求核对，不把计划完整或模型评分当作媒体通过。

## 核心概念

ComfyUI = 节点式工作流引擎，AI图像/视频/音频生成的全链路编排工具。
相当于电影行业的Nuke或Avid。

**工作流 = 有向无环图（DAG）**：
```
[模型加载器] → [条件器] → [采样器] → [解码器] → [保存器]
     ↑           ↑
  [提示词]   [参考图]
```

## 20个工作流阶梯（4阶成熟度）

### 第1阶：基础生成（Workflows 1-5）

| # | 工作流 | 说明 | 关键节点 |
|---|--------|------|---------|
| 1 | Text-to-Image | 最简基线 | CLIPTextEncode + KSampler + VAE Decode |
| 2 | Image-to-Image | 带降噪控制 | LoadImage → VAEEncode → KSampler(denoise) |
| 3 | Inpainting | 带蒙版局部重绘 | VAEEncodeForInpaint + mask |
| 4 | Outpainting | 画布扩展 | PadImageForOutpainting → Inpaint |
| 5 | ControlNet | 条件控制 | 深度/边缘/姿态 -> ControlNetApply |

**生产注意事项**：
- Flux和SDXL的采样器不同，不要盲目复制
- 降噪强度的含义与范围以当前采样器实现为准；先固定其余条件比较保留程度，不承诺通用甜区
- ControlNet数量按各条件的职责与兼容性选，发现互相冲突时逐项停用做对照，不设固定数量上限
- 扩图按边界结构、目标画幅与单次结果决定是否分步，不强制固定扩图比例或追加任务

### 第2阶：身份与风格一致（Workflows 6-10）

| # | 工作流 | 关键 | 强度建议 |
|---|--------|------|---------|
| 6 | LoRA堆叠 | 分清身份与风格职责 | 强度与数量按具体实现对照，不默认另行训练 |
| 7 | IP-Adapter参考 | 参考图嵌入注入 | 强度按当前节点文档和目标保留程度测试 |
| 8 | InstantID面部保留 | 专用面部编码器 | 显存和耗时按实际硬件与模型实测 |
| 9 | 风格迁移 | 结构参考+风格参考 | 风格参考选纹理重、主体轻的 |
| 10 | 多LoRA角色+风格 | 逐项比较角色、风格与姿态影响 | 训练LoRA时用风格中立数据 |

**关键原则**：LoRA组合效果依赖模型与注入实现，不能用强度相乘推算身份保留率。
需要诊断时固定素材、种子和其余参数，比较单项与组合的实际结果；额外运行先核对授权。

### 第3阶：生产级管线（Workflows 11-15）

| # | 工作流 | 说明 | 为什么重要 |
|---|--------|------|-----------|
| 11 | 面部修复链 | GFPGAN / CodeFormer按需选 | 可能改写身份细节，逐镜与锚点复核，不承诺出片率 |
| 12 | 放大链 | Real-ESRGAN(2-4x) + SUPIR(细节增强) | SUPIR会幻觉（造扣子/造文字） |
| 13 | 背景替换 | SAM分割 → Inpaint → 重打光 | 蒙版质量决定一切 |
| 14 | 质量诊断与局部返工 | CLIP / FaceMatch / LLM仅作辅助信号 | 具体问题与证据决定返工，重试需有效授权 |
| 15 | 批量处理 | 元数据传递 | 8-16张以后分开队列 |

**Real-ESRGAN vs SUPIR选择**：
- Real-ESRGAN → 忠实放大（产品目录、法律文档）
- SUPIR → 创意增强（英雄镜头、艺术输出）
- **绝对不要**在电商/法律相关场景用SUPIR

### 第4阶：视频与多模型（Workflows 16-20）

| # | 工作流 | 模型 | VRAM需求 |
|---|--------|------|---------|
| 16 | Image-to-Video | Wan 2.2 / Kling API / Hunyuan | 24-40GB |
| 17 | AnimateDiff | 风格化动画（非写实） | 适中 |
| 18 | 多模型路由 | Switch节点+编排层 | 实际路由在编排层做 |
| 19 | Audio-to-Video | 口型同步（LatentSync/MuseTalk） | 音频需要降噪预处理 |
| 20 | Agent工作流 | LLM控制子工作流选择和参数 | 测试阶段已可行，调试还在痛点 |

# AI电影全工作流

## 核心原则：导演笔记 ≠ 剧本

对每场戏（8-15场）记录：

| 维度 | 要求 | 示例 |
|------|------|------|
| **Subject** | 谁在场、穿什么 | 穿旧皮衣的侦探，肩上有雨水 |
| **Action** | 现在时、单一动作/镜头 | 他推开生锈的铁门 |
| **Camera** | 景别+运动 | 中景，轨道慢推 |
| **Mood/Style** | 色调+灯光+风格 | 高对比黑色电影，冷调 |
| **Audio** | 对白+环境+音乐 | 雨声，远处警笛渐弱 |

**提示词公式（每场2-3句）**：
```
[Subject] + [Action] + [Environment] + [Camera] + [Mood] + [Audio]
```

## 15分钟短片生产时间线

| 阶段 | 时间 | 关键交付物 |
|------|------|-----------|
| Phase 1 剧本与镜头规划 | Day 1 | 镜头清单（40-80个，各5-10s） |
| Phase 2 参考资产生成 | Day 1-2 | 主角色10-15张/配角5-8张/场景3-5张 |
| Phase 3 批量生成 | Day 2-4 | 每镜头2-3个变体，共120-180条原始素材 |
| Phase 4 一致性与重制审核 | Day 4-5 | 重制15-25%有漂移的镜头 |
| Phase 5 剪辑与编辑 | Day 5-6 | DaVinci Resolve调色+过渡+音轨 |
| Phase 6 音频与最终细化 | Day 6-7 | 配音+环境音+配乐+最终输出 |

单人solo 5-7天，双人团队3-4天。有预建角色包的话，60-90秒短片=1-2小时。

## 4层角色一致性锁

### Layer 1 — Character DNA（蓝图文档）

```yaml
CHARACTER NAME: 老陈 / Detective Chen
AGE + VIBE: 45岁，疲惫但警觉
SILHOUETTE: 窄肩，旧风衣，微驼背
FACE ANCHORS: 深眼窝、高颧骨、左眉疤痕、灰色胡茬
HAIR ANCHORS: 灰白短发、偏分、鬓角整齐
SKIN: 暗沉、毛孔粗糙、略微晒伤
SIGNATURE PROP: 旧皮夹、永远叼着烟（不点）
BASE OUTFIT: 深灰三件套西装 + 棕色旧皮鞋
STYLE LOCK: 电影现实主义 / 颗粒感
COLOR PALETTE: #2D2D2D #4A4A4A #8B7355 #C4A882
CAMERA RULES: 近景允许、避免特写手指、全身镜头锁中景
DO NOT ALLOW: smile, bald, hat, leather jacket (different), glasses
```

### Layer 2 — 角色照片包（视觉锚点）

6-12张参考图：
- 全身正面、3/4侧面、侧面
- 中性表情近景
- 6种表情（愤怒、悲伤、警觉、疲惫、微笑、沉默）
- 3种常见姿态（站立、行走、坐下）

新项目做一套约20-40分钟。

### Layer 3 — 镜头关键帧（每场锁定）

每个具体镜头之前，先生成一张静态参考帧：
- 锁定画面构图
- 锁定角色角度和状态
- 然后用它做图生视频

### Layer 4 — 生成+精修

关键帧输入图生视频模型，输出后在剪辑软件里：
- 统一调色（选最满意的一场作为颜色参考）
- 匹配剪辑淡化过渡
- 小漂移用转场/插入镜头掩盖

## 模型选择决策（历史参考，不是当前目录）

按当前模型目录核对多镜输入、参考数量、身份保持、原生音频、时长、分辨率和报价。
模型排名、身份保留百分比和最优口型结论没有本仓实测依据，不用于默认路由。

## 成本参考（不得直接用于报价）

村长只能采用当前能力返回的有效报价和 `task_authorization`。明确计价单位、
时长、分辨率、必要任务数与可选返工；缺报价记为未知，不把历史美元价或积分换算
写入任务或对用户承诺。批量变体与试探本身也需计入授权范围。
