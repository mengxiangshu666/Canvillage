# AI注意力机制权威指南

## 核心原理

扩散模型的本质：在噪声中逐步恢复与文本描述匹配的图像。

### 提示词如何影响生成

```
提示词 → Token化 → 交叉注意力映射 → 空间引导
```

**使用边界**：词序和提示词长度可能影响结果，但不同模型实现不同；
不要把“前30% token”或某种权重语法当作跨模型定律。先按当前模型合同编译。

## 词权重语法

以下仅是部分提示词解析器的示例；当前模型未声明支持时，使用自然语言，不发送这些权重符号。

| 语法 | 效果 | 示例 |
|------|------|------|
| (word) | 权重×1.1 | (dog) 轻微增强 |
| (word:1.5) | 权重×1.5 | (dog:1.5) 明显增强 |
| [word] | 权重×0.9 | [dog] 轻微减弱 |
| (word:0.5) | 权重×0.5 | (dog:0.5) 明显减弱 |

## 交叉注意力优化

**交叉注意力 = 精准锚点 > 堆砌**
- 关键词少但精准 → 每个词高注意力 → 画面精准
- 关键词多但分散 → 注意力稀释 → 随机编造

**注意力陷阱**：
- "一个穿着红色衣服的女人站在草地上" → 红衣服可能被稀释
- "一个女人。(red clothing:1.3)" → 红色被精准锚定

# 上下文工程4大支柱

## 支柱1：记忆（Memory）

**核心问题**：AI如何记住跨对话的信息？

**4种记忆类型**：
| 类型 | 机制 | 适用场景 |
|------|------|---------|
| 短期 | 单次对话内 | 一次性任务 |
| 场景 | 任务相关上下文 | 项目内 |
| 长期 | 跨会话持久化 | 偏好/风格 |
| 零样本 | 无上下文 | 全新任务 |

## 支柱2：检索（Retrieval）

**核心问题**：如何从海量知识中找到最相关的？

**RAG（检索增强生成）**：
```
用户问题 → 检索 → 上下文 → LLM生成
```

**检索质量三要素**：
1. 向量化质量（embedding model）
2. 向量数据库质量
3. 重排（rerank）质量

## 支柱3：上下文窗口（Context Window）

**核心问题**：LLM能看到多少信息？

上下文长度以当前所选模型的实际配置为准，不按厂商品牌或历史版本推断。

**上下文窗口优化**：
- 摘要压缩（prose summary）
- 重点提取（key extraction）
- 分块（chunking）

## 支柱4：提示词工程（Prompt Engineering）

### 3大高级技巧

#### 1. 链式提示（Chain of Thought）
```
问题 → 分解 → 逐步推理 → 答案
```

#### 2. 多示例提示（Few-Shot）
```
示例1 → 示例2 → 示例3 → 新问题
```

#### 3. 元提示（Meta-Prompting）
```
"你是一个顶级的AIGC导演...
先分析这个剧本的核心冲突是什么..."
```

# 画布深度学习——238项目7个核心发现

以下为来源材料的历史统计说法，本仓没有复算其分母或质量结论。
它们不能用作镜头配额、默认时长、模型排名或验收阈值。

## 核心发现1：段长分布

| 段长 | 占比 | 使用场景 |
|------|------|---------|
| 4秒 | 35% | 快速切换/节奏紧张 |
| 6秒 | 40% | 标准节奏 |
| 8秒 | 15% | 情感/特写 |
| 10秒+ | 10% | 重场戏 |

## 核心发现2：景别使用频率

| 景别 | 频率 | 说明 |
|------|------|------|
| 中景 | 45% | 叙事主力 |
| 特写 | 25% | 情感强调 |
| 近景 | 15% | 对话/反应 |
| 全景 | 10% | 建立镜头 |
| 大远 | 5% | 氛围/留白 |

## 核心发现3：运镜模式

| 运镜 | 频率 | 典型应用 |
|------|------|---------|
| 固定 | 50% | 稳定叙事 |
| 推近 | 25% | 聚焦/强调 |
| 横摇 | 15% | 跟拍/空间 |
| 环绕 | 10% | 动态强调 |

## 核心发现4：Prompt平均长度

- 英文提示词：150-200词（最优质项目）
- 中文提示词：80-120词
- 超长提示词（300词+）效果反而下降

## 核心发现5：失败模式Top5

1. 身份丢失（跨帧脸崩）
2. 运动过度（变形/闪烁）
3. 手部崩溃（手指数量）
4. 环境漂移（背景变形）
5. 风格不匹配（灯光/色调）

## 核心发现6：成功模式Top5

1. 单一主体+清晰动作
2. 灯光描述具体（方向+色温+光比）
3. 构图精确（三分/对角线）
4. 参考图质量高
5. 负面约束使用得当

## 核心发现7：模型选型规律

| 任务目标 | 选择依据 | 备注 |
|---|---|---|
| 真人写实 | 当前目录中支持参考图和身份保持的能力 | 以实际合同为准 |
| 3D/动漫/水墨 | 当前目录中的风格与参考输入能力 | 不凭历史模型名猜测 |
| 通用高质量 | 当前目录、质量证据、报价和授权 | 不宣称“综合最强” |

# AI声音设计与台词体系

## 音画同步台词公式

```
【台词/旁白（@角色名，声线描述，语气描述，情绪描述）："具体台词内容"】
```

## 声线公式

**公式**：年龄 + 性别 + 质感（沙哑/粗粝/虚弱/浑厚）+ 口音 + 状态

| 元素 | 示例 |
|------|------|
| 年龄 | 三十多岁/五十多岁/七岁 |
| 性别 | 男性/女性 |
| 质感 | 沙哑/粗粝/虚弱/圆润/清脆 |
| 口音 | 四川话/东北话/普通话/粤语 |
| 状态 | 压抑/激动/疲惫/兴奋 |

## 环境音设计体系

| 环境音类型 | 占比要求 | 用途 |
|-----------|---------|------|
| 对话场景 | ≥40%非台词 | 呼吸/沉默/动作音 |
| 紧张追逐 | ≥60% | 呼吸/脚步/碰撞 |
| 重场戏情感 | ≥30% | 背景/空镜/沉默 |

## 音效层级

| 层级 | 音量 | 用途 |
|------|------|------|
| 对白 | 0dB（基准） | 核心信息 |
| 近景音效 | -3dB | 动作/反应 |
| 背景环境 | -6dB | 氛围/空间 |
| 远景环境 | -12dB | 远处回声 |

## 声音指令示例

只在用户要求无BGM、无字幕且当前模型支持原生音频时采用，不能作为全局默认。

```
不要生成台词字幕
不要BGM
生成环境音和台词配音
同期声
```
