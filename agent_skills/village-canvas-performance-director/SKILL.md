# 角色表演母版

**不要让模型"表现悲伤"。** 摄影机拍不到悲伤，只拍得到"这个人想要什么、被什么挡住、
做了什么"。情绪是这场争夺的结果，不是你要写的东西。

> 与相邻技能的分工：`village-canvas-performance-craft` 是**已有方向后的微表演执行**
> （眼、呼吸、重心、余波）；本技能是**表演层从零设计**——目标、阻碍、节拍、
> 母版与声音设定。两者串起来用：先用本技能定表演母版，再用 performance-craft 逐项复验。

## 一、核心原则

> 角色**想要**什么，**有什么挡着**，于是**采取行动**去拿到。
> 情绪是这场挣扎的副产品，绝不是直接书写的东西。

这条是整个技能的判据。出现"表演出紧张/喜悦/悲伤"这类写法，一律重写。

## 二、需要什么输入

**至少**：角色身份与年龄、当前场景、**角色此刻想从谁那里得到什么**。

> 第三项缺了就先问——没有目标的表演必然变成表情堆砌。

**可选**：人物关系与背景、台词、场景时长、参考角色标签、人物固定习惯或声音、
当前想改善的表演问题。

## 三、怎么做（十步）

1. **明确三件事**：角色目标、阻碍、失败代价（拿不到会怎样）。
2. **拆表演节拍**：整场拆成 **2–4 个节拍**，每次变化都要通过**停顿、姿态、语速、
   视线或距离**的变化体现——不能只靠表情。
3. **安排真实的身体任务**：修理、整理、擦拭、握住、放下、挪开。
   手里有事做的人不会"演"情绪，他在忙。
4. **写身体状态**：重心、呼吸、步态、手部动作、人物距离、地位变化
   （谁在靠近、谁在后退）。
5. **保持眼神生命**：自然眨眼、微小扫视、先看后转头、随节拍变化的凝视状态。
   眼神必须是持续的、活的，不是"看着对方"。
6. **反应要早**：让反应在对方**说完之前**开始；让困难回答之前出现**可见的思考**。
7. **建立表演母版**：固定角色做一份母版；**具体镜头按姿势和情境重写，不机械复制**。
8. **声音**：角色说话时，额外输出固定声音提示词；**没有台词就不输出声音设定**。
9. **只写可拍可观察的行为**：表演段落里**不出现**服装、摄影、灯光、调色
   （那些是别的技能的活）。
10. **写"正在发生的动作状态"**，而不是复杂的连续动作过程——模型把过程做碎。

## 四、产出什么

按任务输出以下之一或多种：

- 角色**表演母版**（固定角色的稳定设定，150–220 词量级的中文描述）
- 当前镜头的**表演段落**
- 角色的**固定声音提示词**（仅有台词时）
- 现有提示词的**表演问题诊断 + 改写版本**

**通用纪律**：犹豫的时候就**减**。少演一点更接近真实；演得满反而假。

## 五、表演母版 vs 镜头段落

| | 表演母版 | 镜头段落 |
|---|---|---|
| 何时定 | 角色确定后定一次 | 每镜重写 |
| 内容 | 说话方式、身体习惯、反应延迟、眼神习惯、声音 | 本镜的目标/阻碍/节拍/动作 |
| 关系 | 母版是**约束** | 镜头在母版**边界内**变化 |

母版不是模板，镜头段落不是复制品。**每个镜头都要按当下姿势和情境重写**。

## 六、验收清单

- [ ] 写清了目标、阻碍、失败代价三件事
- [ ] 全篇没有"表现出 X 情绪"这类直接指令
- [ ] 表演节拍 2–4 个，每个都有停顿/姿态/语速/视线/距离的变化
- [ ] 人物有真实的身体任务，不是空手站着演
- [ ] 写了重心、呼吸、步态、手部、距离与地位变化
- [ ] 眼神有生命（眨眼/扫视/先看后转头/随节拍变化）
- [ ] 反应早于对方台词结束，困难回答前有可见思考
- [ ] 固定角色有母版，且镜头段落不是照抄母版
- [ ] 有台词才输出声音设定
- [ ] 表演段落里没有服装/摄影/灯光/调色
- [ ] 写的是"正在发生"的动作状态，不是复杂连续过程

## 来源与边界

- 方法论来源：`libtv AI影视角色表演导演`（上游 178 次使用，原文写明面向
  Seedance 2.0）。**上游的模型绑定已剥离**——本技能模型无关，产出是提示词文本，
  用到哪个模型由当前可用模型目录决定，不在技能里写死。
- 照抄：核心原则（目标/阻碍/代价）、十步流程、母版与镜头段落的关系、
  "犹豫就减"的纪律。
- **刻意不抄**：上游的英文产出格式（150–220 词英文母版）改为本仓口径——
  产出语言跟随对话语言，词数是量级参考不是硬指标；上游的分 PART 阅读结构
  不沿用。
- 不写服装（`village-canvas-casting-design`）、不写镜头与光影
  （`village-canvas-cinematography` / `village-canvas-lighting-director`）、
  不改角色长相（`village-canvas-character-consistency`）。
